# Docs agent; FAQs

Purpose

- Answer common questions in user language.

Authoring rules

- One question; one answer.
- Answers under 120 words.
- Link out when deeper explanation is needed.

Question style

- How do I; Why does; What happens if.
- Avoid internal jargon.

Maintenance

- Remove or rewrite FAQs that duplicate main content.
- Reorder by frequency of support tickets.
