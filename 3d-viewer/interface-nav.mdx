The 3D viewer arranges its tools in dockable panels around the canvas. This page covers the
layout, how to rearrange it, how to select and inspect objects, and how to move the camera. For an
overview, see [Open and explore models in the 3D viewer](/3d-viewer/introduction).

## Layout

{/* IMAGE_PLACEHOLDER: Viewer chrome — top bar with breadcrumb and Share; left sidebar Models Filters Views Issues; Selection under the left tabs; Elements in the bottom dock; toolbar; status bar; navigation cube bottom-right. */}

- **Top bar:** the breadcrumb (project, **Models**, model name) and **Share**. **Share** offers
  **Share model...**, **Embed model...**, **Copy ID**, and **Download image**. See [Share your
  models](/3d-viewer/sharing). When Speckle Intelligence is available, the sparkle sits next to
  **Share**.
- **Left sidebar:** the workspace switcher at the top, then the **Models**, **Filters**,
  **Views**, and **Issues** tabs. **Selection** sits under those tabs by default. On a first
  visit, **Selection** is open so the canvas is not empty. On narrower widths the left sidebar
  becomes a slide-over.
- **Bottom dock:** **Elements**, a table of every object in the loaded models.
- **Toolbar:** fit to view (or zoom to selection), **Section**, **Sketch**, **Measure**, **Save
  view**, and **Copy view link**. **Show all** appears when objects are hidden or isolated, and
  **Reset filters** appears when filters are active.
- **Status bar:** panel icons, undo, redo, fit, **Screenshot** (downloads a PNG of the canvas,
  including sketches and measurements), keyboard shortcuts, and **Settings**.
- **Navigation cube:** at the bottom-right of the canvas, for standard camera directions.

## Arrange panels

Panels are dockable. Drag a panel icon onto another panel to make a labelled tab group, split it
into the bottom dock, collapse it, or resize it.

The status bar **Settings** menu holds **Orthographic**, **Grid**, and **Reference points**.
**Layout** in that menu lists every panel as a checkbox. **Models** stays on. **Lock layout**
stops accidental drags. **Reset layout** restores the default arrangement after you unlock.

Right-click a panel icon in the tab strip or status bar to move it. The menu lists only slots that
panel can occupy: **Move to sidebar**, **Move to sidebar bottom**, **Move to bottom panel**, or
**Move to bottom right**. **Remove panel** hides it; turn it back on from **Layout**. **Models**
has no **Remove panel**. With **Lock layout** on, the move options are omitted.

{/* IMAGE_PLACEHOLDER: Settings Layout — Orthographic Grid Reference points; Layout checkboxes with hidden Materials Browse SQL Inspector; Lock layout Reset layout. */}

These panels start hidden. Turn them on from **Settings** → **Layout**:

- **Materials** lists materials and colours in the loaded models. Select the usage count to pick
  the objects that use that material.
- **Browse** pages through tables in the published data.
- **SQL** runs a query against the attached models.
- **Inspector** shows relations and the raw property table for the selected object.
- **Health** lists Revit warnings and Revit links that were not included, where the published model carries them. See [Model health](/3d-viewer/exploration#model-health).

For what you can do with these, see [Inspect raw data and
relations](/3d-viewer/exploration#inspect-raw-data-and-relations).

## Right-click the canvas

Right-click the canvas for **Hide** or **Show**, **Isolate** or **Un-isolate**, **Fit to view**,
**Copy application ID**, **Add to chat**, and **Clear selection**.

- With more than one object selected, the options read **Hide selection**, **Isolate selection**
  (or **Show selection** and **Un-isolate selection**), and **Add selection to chat**.
- Right-clicking a selected object keeps the whole selection. Right-clicking an unselected object
  replaces the selection with that pick.
- **Add to chat** pins the pick for [Speckle Intelligence](/analytics/intelligence). If too many
  objects are selected to pin individually, right-click a group in the **Models** tree instead; the
  option then reads **Add "…" to chat** with the group's name.

Right-click a row in **Models** for the same options except **Copy application ID**.

## Use the Models panel

**Models** shows the loaded models as a tree. Click a row to select that object in the scene, and
the scene highlights it. Select an object in the scene and its row is revealed in the tree.

The panel header holds **Add model to scene** (**+**), search, **Expand one level**, **Collapse one
level**, and **Follow 3D selection**. To add more models to the scene, see [Model
federation](/3d-viewer/federation).

Right-click a model card header, or use **⋯**, for:

- **Expand one level** and **Collapse one level**
- **Group by…** — opens the grouping editor (see below). While it is open, the option reads **Hide
  grouping options**.
- **Search this model** — opens a search field on the card.
- **Model placement** — see [Inspect model placement](#inspect-model-placement).
- **Use published hierarchy** — appears when the model carries the hierarchy it was published
  with and the tree is currently grouped another way.

When several models are loaded, the same menu also offers **Isolate model** (or **Un-isolate
model**), **Hide model** (or **Show model**), and **Remove from scene**. Glyphs in the card header
show isolate and hide at a glance and toggle the same state.

{/* IMAGE_PLACEHOLDER: Models card ⋯ menu open — Expand one level, Collapse one level, Group by…, Search this model, Model placement. Several models loaded shows a second group: Isolate model, Hide model, Remove from scene. */}

### Group objects in the tree

**Group by…** opens the grouping strip and its editor. A collapsed strip shows **Grouped by** plus
the current levels joined with ›. Select that summary to reopen the editor.

The editor lists one row per tree level. Drag the grip to reorder levels. Each row is a searchable
picker: options show a label, a coverage count, and the full property path. Relationships such as
**Level**, **Collection**, **Model**, and **Network** appear first when those relations exist;
properties such as **Family** or **Category** follow. The default grouping is a spatial
relationship (**Collection** or **Level**) over the highest-coverage property.

**Add grouping** appends a level. **Done** collapses the editor. If a grouping is too fine to
precompute, the deepest level loads when you expand it.

{/* IMAGE_PLACEHOLDER: Models grouping editor — Grouped by summary or expanded strip, property pickers, Add grouping, Done. */}

### Inspect model placement

**Model placement** opens a dialog that shows the published placement, geometry storage, Project
True North, and translation. **Inspect placement option** previews Internal Origin, Project Base
Point, Survey Point origin, or Shared Coordinates.

<Note>
  **Model placement** in the viewer is inspect-only. You cannot change how a model is placed from
  the viewer. How Revit stores placement on publish is on [Revit](/connectors/revit/revit).
</Note>

## Select and inspect

Click geometry, or click rows in **Models**. Open **Selection** with Shift+O.

**Selection** shows properties for the pick. The title uses the first non-blank of **name**,
**type**, or **category**. Property groups auto-expand. A **Pinned** group stays at the top when you
pin a path. Revit material quantity blocks are condensed into readable rows named like
**Concrete Area** or **Concrete Volume**, using the material name. A **Relations** group at the bottom lists related
objects by relation kind. Search the list with **Filter properties**. When nothing is selected,
**Selection** shows **No properties**.

The panel header has **Zoom**, **Isolate**, and **Hide** for the selected object.

{/* IMAGE_PLACEHOLDER: Selection panel — single object with Pinned group, condensed Material Quantities rows, Relations group, and right-click menu on a property. */}

Right-click a property to:

- **Add to filters** — open an empty **Filters** card for that property. The scene does not narrow
  until you set the condition.
- **Filter to this value** — add a card already set to this value. The scene narrows immediately.
  Relation rows skip this action.
- **Add as table column** — add the path to **Elements**. If it is already a column, the option
  reads **Shown as a table column** and opens **Elements**.
- **Pin property** or **Unpin property**.
- **Copy value** — copies the raw value, not the rounded display string.
- **Copy path**.
- **Copy all properties** — one `path: value` line per row.
- **Copy group path** — from a group header that has a real path. **Pinned** and **Relations** have
  no path to copy.
- **Expand all groups** or **Collapse all groups**.

When you select several objects, **Selection** shows one card per object. Each card can zoom,
isolate, or hide that element. The count reads **N selected**. Selections larger than 1,000
objects start folded; you can still open one card at a time.

The properties you see depend on the application the model was published from. Connectors keep
the structure as consistent as they can, but the available attributes vary by host.

## Move the camera

- **Orbit, pan, and zoom** with the mouse or trackpad.
- **Fit:** the toolbar fit control frames everything, or zooms to the selection when something is
  selected. Shift+Space does the same.
- **Standard views:** select a face of the navigation cube, or press Alt+1–5 for Top, Front, Left,
  Back, and Right.
- **Projection:** Shift+P, or **Orthographic** in the status bar **Settings**, toggles orthographic
  projection.
- **Fly:** W A S D or the arrow keys move; E or Page Up moves up; Q or Page Down moves down. Hold
  Shift for faster, Alt for slower.

## Keyboard shortcuts

Open the cheat sheet from the status bar or with `?`. Bindings use Cmd on macOS and Ctrl
elsewhere. Shortcuts are off in embedded viewers.

- Panels: Shift+M **Models**, Shift+F **Filters**, Shift+V **Views**, Shift+I **Issues**, Shift+T
  **Elements**, Shift+O **Selection**.
- Tools: Shift+R **Measure**, Shift+B **Section**, Shift+K **Sketch**. Esc leaves a tool or clears
  the selection.
- Selection: Shift+H hides or shows the selection.
- Camera: Shift+Space **Fit view / zoom to selection**, Shift+P **Orthographic projection**,
  Alt+1–5 standard views.
- Display: Shift+G **Grid**, Shift+X **Reference points**.
- History: Cmd/Ctrl+Z **Undo**, Cmd/Ctrl+Shift+Z **Redo**.

## FAQ

<AccordionGroup>
  <Accordion title="Can I open a single object in a new window?">
    No. Select it and use **Isolate** in **Selection**, or **Isolate** from the canvas right-click
    menu, to focus on it.
  </Accordion>
  <Accordion title="Where did Dev mode go?">
    The viewer has no Dev mode. To see an object's raw property rows and its relations, turn on
    **Inspector** from **Settings** → **Layout**. See [Inspect raw data and
    relations](/3d-viewer/exploration#inspect-raw-data-and-relations).
  </Accordion>
  <Accordion title="I moved panels around and want the default back. How?">
    Open **Settings** → **Layout** in the status bar, turn off **Lock layout** if it is on, then
    select **Reset layout**.
  </Accordion>
  <Accordion title="Can I reposition federated models in the viewer?">
    No. **Model placement** lets you inspect the published datum. Changing placement on publish is
    documented for Revit on [Revit](/connectors/revit/revit).
  </Accordion>
</AccordionGroup>
