## What are saved views?

A saved view stores the look of the 3D viewer — camera, filters, visibility, section planes,
sketches, and measurements — so you and your team can return to it for repeatable review. Saved
views and viewpoints published from your design application both live in the **Views** panel.
Open it with Shift+V.

## Who can create saved views?

Saved views are available on all Speckle plans, including Free. Creating and managing views
requires the **Editor** role or higher on the project. Without it, **Save view** and **New group**
are disabled. Learn more in [Roles and Permissions](/workspaces/roles-and-seats).

<Note>
  On a self-hosted server, saved views are available only on Speckle Enterprise Server. For
  deployment setup, see [Enterprise license — Saved
  Views](/developers/server/deployment/enterprise-license#optional-saved-views).
</Note>

## Create a view

<Steps>
  <Step title="Set the look">
    Frame the camera, set filters and visibility, and add any section planes, sketches, or
    measurements you want stored.
  </Step>
  <Step title="Save the view">
    Select **Save view** in the **Views** panel header, or the bookmark control on the toolbar.
  </Step>
  <Step title="Name it">Give the view a name. You should see the new view in the panel.</Step>
</Steps>

Until the first view is saved, the panel shows **No views yet**.

## Model views from your design application

When a connector publishes viewpoints from the source application, they appear under **Model
views**. Select a row to move the camera there. An orthographic published view can show a
**Parallel / orthographic (isometric)** cue.

To keep a published viewpoint as a saved view, select **Save as view** on its row, or drag the row
into a saved-view group. The row stays in **Model views**. Dragging into a group needs at least one
named group and permission to create views.

## Manage a view

Open the **⋯** menu on a view card (or right-click the card) for:

- **Rename**
- **Copy link**
- **Make private** or **Make public**
- **Set as home view** or **Remove as home view**
- **Delete…** — this also deletes the view's sketches and measurements; the confirmation dialog
  says so.

Cards show the author and a relative date. Use the eye control on a card to show or hide that
view's sketches and measurements.

{/* IMAGE_PLACEHOLDER: Saved view card ⋯ menu — Rename Copy link Make private or Make public Set as home view Delete; eye control for sketches and measurements. */}

To change what a view shows, set up the new look and save it as a new view, then delete the old
one.

## View visibility: shared vs. private

Views are shared by default: anyone with access to the project sees them in the **Views** panel.
Choose **Make private** to keep a view to yourself — private views show a lock with the tooltip
**Only visible to you**. You can change visibility at any time from the card menu.

## Group views

Select **New group** to create a group, name it, then drag views into it. Group by discipline,
review round, or topic.

On a group the **⋯** menu offers **Rename**, **Make all private** or **Make all public**, and
**Delete group…**. The eye on a group header shows or hides the sketches and measurements of every
view in the group.

Views saved before you used groups sit under **Ungrouped**. You can drag views out of it, but not
into it. Its menu offers **Delete all views…**.

Anyone who has permission to create views can also move and group views, including views made by
other users. An empty group shows **Drop views here**. Search the panel with **Search views**; when
nothing matches, it shows **No matching views**.

## Set a home view

A home view is applied when anyone opens the model. Choose **Set as home view** from a view's
**⋯** menu. Only a public view saved on a single model can be a home view.

## Share a link to a view

Select **Copy link** on a view card to copy a direct link to that view. Anyone with access to the
model who opens the link lands on that view. To share the current look without saving a view, use
**Copy view link** on the toolbar.

Sharing a link does not change a view's visibility: private views stay private, and shared views
are only visible to people with project access.

## Views saved in the earlier viewer

A view saved in the viewer before 2026.9 can show **This view is being upgraded** until Speckle
converts it. If you need that viewpoint now, set up the look again and save a new view.

## FAQ

<AccordionGroup>
  <Accordion title="Can I replace a view or edit its description?">
    No. You can rename a view. To change what it shows, save a new view with the new look and delete
    the old one.
  </Accordion>
  <Accordion title="Do saved views work after a new version is published?">
    The panel lists views whose models are loaded. A view saved on an older version of a loaded
    model still applies, but what you see can differ from when the view was saved.
  </Accordion>
  <Accordion title="Why can't I set this view as the home view?">
    Only a public view saved on a single model can be a home view. Make the view public, or save a
    view with one model loaded.
  </Accordion>
</AccordionGroup>
