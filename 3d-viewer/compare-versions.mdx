Speckle keeps every change you publish. Each time you publish data, a new
[version](/workspaces/versions) is created. You can review the whole history of a model and open an
earlier version when you need it.

## How version tracking works

Whenever you publish from a Speckle-enabled application (like Revit, Rhino, or Grasshopper), Speckle
stores that data as a new version. Each version is:

- Timestamped
- Tagged with metadata (for example message, source application, and publisher)
- Linked to previous versions, so the history is traceable

Learn more about versions on [Versions](/workspaces/versions).

## See what changed between two versions

Ask [Speckle Intelligence](/analytics/intelligence) in Chat or the viewer sparkle, for example
**Compare the two most recent versions and summarise what was added, removed, or changed**.
Intelligence finds the versions, explains the differences, and can filter and colour the model by
how significant each change is. To keep the comparison, save it as a
[Report](/analytics/reports#compare-versions).

Comparing versions with Intelligence needs both versions in the data format introduced in 2026.9.

## Tips

<Tip>
  Write meaningful messages when you publish so the version history is easier to read, and keep
  separate models for project phases or design options so changes stay organised.
</Tip>
