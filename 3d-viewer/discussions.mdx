---
title: Discussions (self‑hosted servers)
description: 'How model feedback works on self‑hosted Speckle servers that do not use workspace Issues.'
---

On Speckle Cloud workspaces (hosted Speckle), model‑centric feedback, review items, and decisions are captured with **Issues** and issue comments. See the [Issues](/3d-viewer/issues) page for current, fully supported workflows.

On **self‑hosted Speckle servers** that do not use workspace‑level infrastructure, you may instead see the older **Discussions** and comments experience in the 3D viewer. In that case:

- Discussions act as the primary way to keep feedback tied to specific objects or views.
- Comments inside a discussion thread behave similarly to replies on Issues in Speckle Cloud.

<Note>
  If you are using Speckle Cloud or an Enterprise workspace, treat Discussions as historical and use
  Issues instead. If you are using an open source self‑hosted server without Issues, use Discussions
  and comments as your main feedback mechanism.
</Note>
