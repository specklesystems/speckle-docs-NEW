The 3D viewer has no separate presentation or slideshow mode. To walk people through a model, save
each viewpoint as a [saved view](/3d-viewer/saved-views), keep the views in a group in the order you
want to show them, and select them one by one in **Views**. To let people explore on their own,
share a link or embed the model.

<Note>
  For a decision guide across inspection, feedback, and stakeholder delivery, see [Review
  Workflows](/workflows/review-workflows).
</Note>

## Prepare each viewpoint

Set up the look you want before you save it:

- **Camera:** select a face of the navigation cube, or press Alt+1–5, for a standard view. Shift+P
  toggles orthographic projection. See [Move the camera](/3d-viewer/interface-nav#move-the-camera).
- **Cuts:** add [section planes](/3d-viewer/exploration#cut-with-section-planes), then select
  **Hide plane handles** for a clean view.
- **Focus:** hide or isolate objects from the canvas right-click menu, or narrow and colour the scene
  with [Filters](/3d-viewer/exploration#filter-and-color).
- **Annotations:** draw with [Sketch](/3d-viewer/markups) or add a
  [measurement](/3d-viewer/exploration#measure) to point out what matters.

## Save the views in running order

<Steps>
  <Step title="Save each viewpoint">
    Select **Save view** on the toolbar or in the **Views** panel header, and give the view a name.
  </Step>
  <Step title="Group the views">
    Select **New group** in **Views**, name it, and drag your views into it.
  </Step>
  <Step title="Order the views">
    Drag the views within the group into the order you will present them. You should see the group
    list them in that order.
  </Step>
</Steps>

Saving views needs the **Editor** role or higher on the project. To choose where the model opens for
everyone, set one public view as the home view. See [Set a home view](/3d-viewer/saved-views#set-a-home-view).

<Note>
  On a self-hosted server, saved views are available only on Speckle Enterprise Server. For
  deployment setup, see [Enterprise license — Saved
  Views](/developers/server/deployment/enterprise-license#optional-saved-views).
</Note>

## Walk through the views

Open **Views** with Shift+V and select each view in turn. The viewer restores the camera, filters,
visibility, section planes, sketches, and measurements saved with it. Use the eye control on a view
card to show or hide its sketches and measurements.

## Export images for slides

Select **Screenshot** in the status bar, or **Download image** from **Share**. Both download a PNG
of the canvas, including sketches and measurements.

## Share with people who can't attend

- **A saved view:** select **Copy link** on the view card. People with access to the project open
  the model on that view.
- **The current look:** select **Copy view link** on the toolbar. You do not need to save a view
  first.
- **People outside the project:** use **Share** → **Share model...** for a link that opens without
  signing in, or **Embed model...** to place the model on another site. See [Share your
  models](/3d-viewer/sharing).

## FAQ

<AccordionGroup>
  <Accordion title="Where did view modes, lighting, explode, and the section box go?">
    The viewer has no view modes (such as Pen or Arctic), lighting controls, or explode. It cuts
    with individual [section planes](/3d-viewer/exploration#cut-with-section-planes) instead of a
    box. Orthographic projection, the grid, and reference points are in the status bar **Settings**.
  </Accordion>
  <Accordion title="What happens to presentation links I shared before?">
    Old presentation links no longer open a presentation; the current web app has no presentation
    viewer for them. They still work as view links to the project's data until they expire or you
    revoke them in project **Settings** → **Links**. Revoke presentation links you no longer need.
    To share the same viewpoints, copy a link from each saved view.
  </Accordion>
</AccordionGroup>
