title: Share your models
description: 'Share a model with a link, protect the link with a password or expiry date, or embed the 3D viewer in another site.'
---

Model sharing in Speckle means sharing model access with links or embeds so others can view and
interact in a browser. Because Speckle is a web app, people open your model on a desktop, tablet, or
phone. **No special software or licenses are required to view and interact with models;** everything
runs in the browser.

<Tip>
  Looking to create advanced analytics and dashboards from your model data? Check out [Speckle
  Intelligence Dashboards](/analytics/intelligence-dashboards) for interactive dashboards and
  insights.
</Tip>

## Share a link

{/* IMAGE_PLACEHOLDER: Viewer top bar — Share menu open with Share model..., Embed model..., Copy ID, Download image. */}

There are two ways to share a model by link:

1. **Copy the page address.** Copy the URL from your browser's address bar. It works for people who
   already have access to the project.
2. **Create a view link.** Select **Share** → **Share model…**, then **Create view link** and
   **Copy link**. Anyone with this link can view the model without signing in.

With several models in the scene, the menu item reads **Share models...**. The **Share** menu also
offers **Copy ID** (with a single model loaded) and **Download image**, which saves a PNG of the
canvas.

<Warning>
  If someone can't open a copied page address, check your project's permissions. You may need to
  give them access to your workspace or project first, or create a view link instead. See [Managing
  Access and Permissions](/workspaces/roles-and-seats).
</Warning>

### Protect a view link

Before you select **Create view link**, select **Options** to:

- **Set an expiry date** in **Expires at**: the link stops working after that date.
- **Turn on Password protect**: recipients enter the password on an unlock page before the model
  loads.

The full link address shows only once, right after you create it. Copy it then.

### Manage view links

Project owners see the model's links in the **Share model** dialog. Select the pencil icon to change
a link's label or expiry date, or the **×** icon to revoke it. Project **Settings** → **Links** lists
every link and embed in the project, with its activity and **Revoke all**. See [Edit or revoke a
link](/3d-viewer/share-folders-and-files#edit-or-revoke-a-link).

Creating view links and embeds needs the **Editor** role or higher on the model. To share folders
and files, or to give people a role on one model, see [Share folders, files and
models](/3d-viewer/share-folders-and-files).

## Embed the 3D viewer

{/* IMAGE_PLACEHOLDER: Embed model dialog — option switches, Remove Speckle branding, Advanced options, Copy link and Copy iframe code. */}

<Steps>
  <Step title="Open the embed dialog">Select **Share** → **Embed model...**.</Step>
  <Step title="Choose the options">
    Turn on the options you want. Open **Advanced options** to add a password or expiry date.
  </Step>
  <Step title="Copy the embed">
    Select **Copy iframe code** to paste the viewer into a web page, or **Copy link** for a direct
    link to the embedded viewer.
  </Step>
</Steps>

The embed options are:

- **Transparent background**
- **Hide viewer controls**
- **Remove link to project** — the model name in the embed footer no longer links to the model in
  Speckle.
- **Disable camera zoom**
- **Manual model load** — the embed shows a preview with a play button, and the model loads when
  someone selects it.
- **Remove Speckle branding** — depends on your workspace plan. If your workspace hides branding
  for all embeds, the option is on and locked.

<Note>
  Inside another site, an embed shows the 3D scene only. The model tree, **Filters**, selection
  details, and toolbar do not appear, whichever options you choose.
</Note>

## If sharing does not work

Check these first:

- User cannot open a copied page address -> confirm project visibility and role permissions, or
  send a view link.
- User cannot open a view link -> check whether it expired or was revoked in project **Settings** →
  **Links**.
- Embed does not load -> confirm the iframe code is complete and the host site allows iframes.
- Private view still hidden -> sharing a link does not change a saved view's visibility.

## FAQ

<AccordionGroup>
  <Accordion title="Does sharing a link make a private project public?">
    No. The project's visibility does not change. A view link gives access to the shared model only,
    and you can revoke it at any time.
  </Accordion>
  <Accordion title="Can recipients view models without installing Speckle connectors?">
    Yes. Recipients can open shared model links in a browser without connector installation.
  </Accordion>
  <Accordion title="When should I use Copy link vs Copy iframe code?">
    Use **Copy link** when you need a direct URL to the embedded viewer. Use **Copy iframe code**
    when placing the viewer inside another product or page.
  </Accordion>
  <Accordion title="Can I share a model privately without adding users to a workspace?">
    Yes. Create a view link with **Share model…**. You can optionally add an expiry date and
    password. Anyone with the link can view the shared model without signing in.
  </Accordion>
  <Accordion title="What happens when a view link expires?">
    The link stops working. Recipients can no longer access the shared model with it. Create a new
    view link if access is still needed.
  </Accordion>
  <Accordion title="Can I revoke a view link before it expires?">
    Yes. Revoke it from the **Share model** dialog, or from project **Settings** → **Links**.
  </Accordion>
  <Accordion title="Why does my embed show no filters or toolbar?">
    Embeds on another site show the 3D scene only. Open the model in the web app to filter, select,
    or measure.
  </Accordion>
</AccordionGroup>
