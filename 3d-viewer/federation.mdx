Model federation shows models from different teams and tools — Revit, Rhino, AutoCAD, and more —
together in one 3D viewer scene. Nobody sends files back and forth: each team publishes its own model
to the same Speckle project, and you combine them when you view.

## Open several models together

{/* IMAGE_PLACEHOLDER: Project Models page — two model checkboxes selected, selection bar with Open in viewer; a folder row showing View all. */}

<Steps>
  <Step title="Open the project's models">Open the project and go to its **Models** page.</Step>
  <Step title="Select the models">Select the checkbox on each model you want to view.</Step>
  <Step title="Open them in the viewer">
    Select **Open in viewer** in the selection bar. You should see every selected model in one
    scene, each with its own card in **Models**.
  </Step>
</Steps>

To open every model in a folder, select **View all** on the folder row.

## Add a model to the scene

{/* IMAGE_PLACEHOLDER: Models panel header — Add model to scene (+) picker open with Search models… and the project's other models. */}

In the viewer, select **Add model to scene** (**+**) in the **Models** panel header, search, and pick
a model. It loads alongside the models already in the scene. The picker lists models from the same
project.

The page address updates as you add models, so copying the URL shares the whole federated scene
with people who have access to the project.

## Remove, hide, or isolate a model

With several models loaded, right-click a model card header in **Models**, or use **⋯**, for:

- **Isolate model** or **Un-isolate model**
- **Hide model** or **Show model**
- **Remove from scene**

Glyphs in the card header show isolate and hide at a glance and toggle the same state. See [Use the
Models panel](/3d-viewer/interface-nav#use-the-models-panel).

## FAQ

<AccordionGroup>
  <Accordion title="Can I remove a model after opening a folder or a selection?">
    Yes. Use **Remove from scene** on that model's card. The other models stay in the scene.
  </Accordion>
  <Accordion title="Why don't my models line up?">
    Each model keeps the placement it was published with. The viewer can show how a model is placed
    but cannot move it. See [Inspect model
    placement](/3d-viewer/interface-nav#inspect-model-placement).
  </Accordion>
  <Accordion title="Can I combine models from different projects?">
    No. **Add model to scene** lists models in the same project. Publish the models you want to
    combine to one project.
  </Accordion>
</AccordionGroup>
