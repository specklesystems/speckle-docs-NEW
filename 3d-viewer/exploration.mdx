## Filter and color

**Filters** is a stack of cards, not a single search box. A property card has operators that match
the property type. A SQL card shows a query instead — see [Narrow a SQL
filter](#narrow-a-sql-filter). Applied filters stay in place when you change selection or close
and reopen panels. Open **Filters** with Shift+F.

{/* IMAGE_PLACEHOLDER: Filters panel — two property cards, All/Any tabs, Color by values on a string card, empty state No filters yet. */}

<Steps>
  <Step title="Add a filter">
    Open **Filters** and select **Add filter**. Choose a property. An empty card appears in the
    stack. The scene does not change yet.
  </Step>
  <Step title="Set the condition">
    Choose an operator and the values to include or exclude. The scene then narrows to matches. If
    nothing matches, **Filters** shows **No objects match — everything is hidden**.
  </Step>
  <Step title="Color by values">
    On a text, relation, or SQL card, select **Color by values**. Matching objects take colours.
    Only one card colours the scene at a time. For a SQL card, see [Narrow a SQL
    filter](#narrow-a-sql-filter).
  </Step>
</Steps>

You can also start from a property in **Selection**: right-click it and choose **Add to filters**
or **Filter to this value**. See [Select and inspect](/3d-viewer/interface-nav#select-and-inspect).

### Operators

- Text: **is one of**, **is not one of**, **contains**, **does not contain**, **has value**,
  **is set**, **is not set**.
- Number: **equals**, **is not equal**, **in range**, **has value**, **is set**, **is not set**.
  Numeric **equals** and **is not equal** accept more than one value, and equals tolerates small
  floating-point differences.
- Yes/no: **is** (**True** / **False**), **has value**, **is set**, **is not set**.
- Relation (for example a level or network): **is one of**, **is set**, **is not set**.

**Has value** matches objects where the property has a non-empty value. **Is set** matches objects
where the property exists. **Is not set** matches objects where it is missing.

A SQL filter narrows the model to the objects a query returns. It is not in **Add filter**, and it
has no operator menu. [Speckle Intelligence](/analytics/intelligence) adds one from Chat, or a
[saved view](/3d-viewer/saved-views) restores one. The card shows the query, and you cannot edit
the statement there. Its title is the filter's name, or **SQL filter**.

When the query returns a `bucket` column, each bucket is a checkbox with a count. Search and
select all work as they do on a text card. The list follows the current value sort (**A–Z** unless
you changed it on another card). This card has no sort menu of its own.

Leave every box unchecked to keep every object the query matches, including objects with no bucket
value. Those objects are not in the list. With **Color by values** on, each listed bucket is
coloured and the objects with no bucket value stay uncoloured. Check one or more buckets to keep
only those buckets. Objects with no bucket value then drop out of the view, and **Color by
values** colours only the checked buckets.

When the query has no `bucket` column, the card still filters the scene. **Color by values**
colours every match as one group. The group uses the card's name, or **Matches** when the title is
**SQL filter**.

### Combine and manage filters

With two or more cards, **All** keeps objects that match every card. **Any** keeps objects that
match at least one. With **All**, each card's value list is scoped to the enabled cards above it.
With **Any**, the cards are independent. Drag the grip, or use Alt+↑ / Alt+↓, to reorder.

Right-click a card for **Change property…**, **Collapse** or **Expand**, **Color by values** or
**Stop coloring**, **Disable filter** or **Enable filter**, **Move up**, **Move down**,
**Duplicate**, and **Remove filter**. A disabled card stays in the stack but does not hide objects.

**Clear all filters** is in the panel header. **Reset filters** on the toolbar clears the same
stack without undoing hide and isolate. **Show all** on the toolbar brings back hidden and isolated
objects.

While a model is still being attached, the panel shows **Attaching model…**. If it shows **Failed
to load properties** or **Failed to resolve filter matches**, reload the page.

<Tip>
  Speckle Intelligence can also filter and colour the model from Chat, including a SQL filter. See
  [Narrow a SQL filter](#narrow-a-sql-filter) and [Ask questions about your models with Speckle
  Intelligence](/analytics/intelligence).
</Tip>

## Browse objects in Elements

**Elements** is a table of the objects in the loaded models. It follows the active **Filters**
stack. When several models are loaded, a scope control can limit the table to one model or to the
current selection.

{/* IMAGE_PLACEHOLDER: Elements bottom dock — object table with count, Update parameters, Export view to Excel. */}

<Steps>
  <Step title="Open Elements">
    Select **Elements** in the bottom dock, or press Shift+T. You should see a table of objects and
    a count.
  </Step>
  <Step title="Inspect a row">
    Select a row. **Selection** shows that object's properties. Double-click the row to frame it in
    the scene.
  </Step>
  <Step title="Add columns">
    In **Selection**, right-click a property and choose **Add as table column**. The column appears
    in **Elements**.
  </Step>
</Steps>

**Export view to Excel** downloads the current columns, filter scope, and sort. If grouping or
search is too large, a warning reads **Showing the first … elements — narrow the scope (filters or
selection) for a complete view**.

To batch-edit parameter values from this table, turn on **Update parameters**. See [Parameter
Updater](/beta/parameter-updater).

## Inspect raw data and relations

These panels start hidden; turn them on from the status bar **Settings** → **Layout**.

- **Inspector** shows the selected object's relations as a diagram or as rows, plus a raw table of
  its properties. When nothing is selected it reads **Select an object in the viewer to inspect its
  rows**.
- **SQL** runs a query against the attached models. **$selected** inserts the current pick's
  application IDs.
- **Browse** pages through tables in the published data.
- **Materials** lists materials and colours in the loaded models. Select the usage count to pick
  the objects that use that material.
- **Health** lists model warnings, where the published model carries them.

{/* IMAGE_PLACEHOLDER: Inspector panel — Relations diagram and raw Properties table for a selected object. */}

For working with the underlying data in your own code, see the [developer
documentation](/developers/introduction).

## Cut with section planes

The viewer cuts with individual **section planes**, not a six-sided box. Open **Section** from the
toolbar, or press Shift+B. Press Esc to leave the tool.

{/* IMAGE_PLACEHOLDER: Section tool — Plane, XY, XZ, YZ controls, plane list with Stop cutting Flip Hide plane handles Remove all planes, cutting plane handle in the scene. */}

<Steps>
  <Step title="Turn Section on">
    Select **Section** on the toolbar. The tool options appear above the toolbar.
  </Step>
  <Step title="Add a plane">
    Select **Plane**, then click a surface, or select **XY**, **XZ**, or **YZ** to cut at the scene
    centre. The model is clipped on one side of the plane.
  </Step>
  <Step title="Adjust the cut">
    Select a plane in the list to show its handle. Drag the handle, flip which side is cut away, or
    stop cutting without removing the plane. **Stop cutting** and **Resume cutting** toggle the cut.
  </Step>
</Steps>

**Hide plane handles** keeps the cut for a cleaner screenshot. **Remove all planes** clears the
list. If **Plane** is disabled, all plane slots are in use.

## Measure

Use **Measure** to verify dimensions, check clearances, and validate design details. Open it from
the toolbar, or press Shift+R. Press Esc to leave the tool, and Cmd/Ctrl+Z to undo.

{/* IMAGE_PLACEHOLDER: Measure tool — Point to point, Perpendicular, Angle, Area options and unit dropdown; a measurement on the model. */}

Measurement types:

- **Point to point** — the straight-line distance between two points.
- **Perpendicular** — the shortest distance from a point to a line or plane.
- **Angle** — an angle between points you pick on the model.
- **Area** — the area of a polygon you click out on the model.

Choose the display unit from the unit dropdown in the tool options. To remove one measurement,
select it and press Delete.

Measurements stay on the canvas for the session. If you can save views, they are stored on the
saved view with sketches, and the eye control on a view card shows or hides them. Without that
permission the unit choice reads **Session only**, and measurements disappear when you leave the
model. See [Saved views](/3d-viewer/saved-views).

## FAQ

<AccordionGroup>
  <Accordion title="Why does a filter hide the whole model?">
    When no objects match, **Filters** shows **No objects match — everything is hidden**. Change the
    values, switch **All** to **Any**, enable a disabled card, or use **Reset filters**.
  </Accordion>
  <Accordion title='Why do I see "Too many objects selected to add individually"?'>
    Your selection is too large to add to Chat object by object. Right-click a group in the scene
    tree instead to add it as a whole.
  </Accordion>
  <Accordion title="Can I color the model from a numeric filter?">
    No. A number card does not colour the scene. **Color by values** is on text, relation, and SQL
    cards. Ask [Speckle Intelligence](/analytics/intelligence) if you want to colour by a number.
  </Accordion>
  <Accordion title="Can I filter by a property that doesn't exist?">
    No, the property must exist in the model. **Is not set** finds objects where it is missing.
  </Accordion>
  <Accordion title="Where did the section box go?">
    The viewer cuts with section planes. Add **XY**, **XZ**, or **YZ**, or place a plane on a
    surface, then flip or hide individual planes.
  </Accordion>
  <Accordion title="Where did Dev mode go?">
    The viewer has no Dev mode. **Inspector** shows the raw property rows and relations for the
    selected object; see [Inspect raw data and relations](#inspect-raw-data-and-relations).
  </Accordion>
</AccordionGroup>
