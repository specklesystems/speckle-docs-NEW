## Web app

### AI Chat

- **Feature:** AI chat can draft a reusable skill from a conversation.

- **Feature:** AI conversations can be shared by link without sharing attached models.

- **Fix:** AI-generated viewer legends use the colors shown in the model.

- **Fix:** Running AI conversations survive a frontend restart.

- **Fix:** AI chat reliably records requested answers and uses attached models.

- **Fix:** AI chats interrupted by a page reload recover once the response finishes.

### Reports

- **Fix:** The report-cell toolbar no longer covers chart actions.

- **Fix:** Workspace administrators can update and delete member reports.

- **Fix:** Incomplete quantity calculations are no longer presented as totals.

- **Fix:** Report input defaults persist after the report is reopened.

- **Fix:** Reports identify model sources that have been deleted.

- **Fix:** A slow report cell no longer consumes the query budget of other cells.

### Projects, Models and Versions

- **Feature:** Model subtrees can be moved to another location.

### Workspace administration

- **Fix:** The workspace menu and close control fit and work on mobile screens.

### Identity and access

- **Fix:** Access errors offer a sign-in route when authentication can resolve them.

### Billing and Usage

- **Feature:** Workspace usage reports can export a full year of user and project activity as CSV.

### Model Viewer

- **Feature:** Shift+H hides or shows the current selection.

- **Feature:** Selected models can be opened together in the viewer.

- **Improvement:** Filter values keep a stable sorted order while more values load.

- **Fix:** Viewer bottom panes can display more than three tabs.

- **Fix:** Filter search can find values beyond the initially loaded list.

- **Fix:** Show all, saved views and visibility counts work with realized model objects.

### Issues and Markups

- **Fix:** Opening an issue uses the model version pinned to that issue.

### Presentations and Sharing

- **Fix:** Opening a saved view uses its pinned model version.

- **Fix:** Recalling saved views restores their viewer state consistently.

- **Fix:** The viewer share menu and embed dialog are available again.

### Dashboards

- **Feature:** Dashboard model management supports federated models.

- **Feature:** Dashboards use the new query-native dashboard experience.

- **Feature:** Calculated fields can extract values with regular expressions.

- **Fix:** Widget titles update after a model is renamed.

- **Fix:** Shared dashboards include working links back to their project.

- **Fix:** Table cells remain aligned with their columns while data reloads.

- **Fix:** Dashboard viewers limit active rendering contexts to avoid WebGL overload.

- **Fix:** Small values remain visible in doughnut charts.

### Data Validation

- **Fix:** AI edits a validation check only when matching validation evidence is available.

- **Fix:** Validation check drafts persist across follow-up AI responses.

- **Fix:** Filtering validation results by pass or fail no longer stops the query engine.

## Integrations

### Navisworks

- **Deprecation:** The Navisworks connector installer is deprecated. Version 2026.9.1.

### Power BI

- **Fix:** AddProperties accepts objects linked to more than one type. Version 2026.9.2.

## Developer platform

### Bundle specification

- **Feature:** The bundle specification publishes generated domain records for each object kind and row-shaped table. Version 1.2.0.

### SpecklePy SDK

- **Improvement:** Large meshes upload more efficiently through the server transport. Version 2026.9.0b3.

### Viewer library

- **Fix:** Loading and unloading models no longer corrupts viewer buffers. Version 2026.9.22.
