## Web app

### AI Chat

- **Fix:** Files attached to a shared skill are listed only for members who can read them.

- **Fix:** Markdown in chat messages, shared conversations, skills and Automate function READMEs renders without running embedded scripts, and validation rule descriptions display as text.

### Reports

- **Fix:** Insights link, preview and return only data files the user can read, and stored insights resolve lookup tables only from files in their own workspace.

### Projects, Models and Versions

- **Improvement:** Shift-clicking a model's checkbox in the project models list selects or clears every model shown between it and the previous one clicked.

### Identity and access

- **Fix:** The admin user query no longer returns the ids of a user's active password-reset tokens.

### Configuration and Metadata

- **Feature:** Workspace admins can add several [Databricks](/connectors/cloud-integrations/databricks), Snowflake or Fabric connections per workspace and manage every kind through one flow.

### Model Viewer

- **Improvement:** Camera navigation is held within a bounding sphere around the loaded models.

- **Fix:** Federations of many models load every model's interactions, placements and filter properties instead of failing when the viewer's request queue fills.

### Dashboards

- **Fix:** The issues list widget shows issue descriptions as text instead of rendering embedded HTML.

## Server

### File conversion

- **Feature:** Revit uploads and ACC Revit syncs have an opt-in **Extract room relations** setting that publishes [room membership and room-to-room connections](/developers/object-model/relations#containment-and-grouping).

### File sync

- **Fix:** ProjectWise sync connection URLs are accepted only as HTTPS addresses on bentley.com hosts.

- **Fix:** A saved ProjectWise login can be used only by the member who saved it, in its own workspace, and Trimble Connect syncs use only their workspace's connection.

### File uploads

- **Feature:** Point cloud files (LAS, LAZ, E57, PLY, PCD, PTS, PTX, XYZ and ReCap) can be uploaded on app.speckle.systems, as a preview.

## Developer platform

### SpecklePy SDK

- **Feature:** SpecklePy's IFC importer brings in line geometry for elements that have no 3D representation. Version 2026.9.2.

- **Improvement:** SpecklePy's IFC importer no longer triangulates opening elements. Version 2026.9.2.

- **Improvement:** SpecklePy's IFC importer converts elements outside the spatial structure and respects each quantity's own units. Version 2026.9.2.

### Viewer library

- **Improvement:** Camera controls clamp navigation to the world bounds sphere. Version 2026.10.9.

- **Fix:** The camera settles when a pivot pick lands during WASD flight; merged, not yet in a viewer release.
