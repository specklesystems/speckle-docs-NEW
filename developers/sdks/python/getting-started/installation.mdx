## Requirements

specklepy requires:

- **Python 3.10 or higher** (Python 3.10, 3.11, 3.12, 3.13, 3.14 supported)

<Check>specklepy works on Windows, macOS, and Linux.</Check>

## Install with pip

Install specklepy with the `bundle` extra:

```bash
pip install "specklepy[bundle]==2026.9.0b3"
```

The `bundle` extra installs pyarrow, which specklepy needs to load and publish versions with `operations.receive3` and `operations.send3`.

<Warning>
  An older specklepy gets a 404 when it loads a version published by a 2026.9 connector. Install
  **2026.9.0b3** or later with the `bundle` extra. See [Who's
  affected](/developers/migration/data-model-migration#whos-affected).
</Warning>

<Note>
  2026.9.0b3 is a prerelease; a plain `pip install specklepy` installs 2026.8, which has no
  `operations.receive3`. A later stable 2026.9.0 replaces the pin without changing the calls.
</Note>

### Upgrade an existing installation

Run the same command. pip replaces the installed specklepy with 2026.9.0b3.

Moving a script from `operations.receive` to `operations.receive3`? See [Migrate to 2026.9](/developers/sdks/python/migrate-to-2026-9).

## Virtual Environments (Recommended)

It's best practice to use a virtual environment to avoid dependency conflicts.

<Tabs>
  <Tab title="uv (Recommended)">
    ```bash
    # Install uv if you don't have it
    pip install uv

    # Create a new project with virtual environment
    uv init my-speckle-project
    cd my-speckle-project

    # Add specklepy
    uv add "specklepy[bundle]==2026.9.0b3"

    # Run your script
    uv run python main.py
    ```

  </Tab>

  <Tab title="venv (Built-in)">
    ```bash
    # Create virtual environment
    python -m venv speckle_env

    # Activate it
    # On Windows:
    speckle_env\Scripts\activate
    # On macOS/Linux:
    source speckle_env/bin/activate

    # Install specklepy
    pip install "specklepy[bundle]==2026.9.0b3"
    ```

  </Tab>

  <Tab title="conda">
    ```bash
    # Create conda environment
    conda create -n speckle_env python=3.11

    # Activate it
    conda activate speckle_env

    # Install specklepy
    pip install "specklepy[bundle]==2026.9.0b3"
    ```

  </Tab>
</Tabs>

## Verify Installation

Confirm which specklepy version is installed:

```python lines icon="python"
from importlib.metadata import version

print(f"specklepy version: {version('specklepy')}")
```

You should see `specklepy version: 2026.9.0b3`. Then check that the modules you need import:

```python lines icon="python"
from specklepy.api import operations
from specklepy.api.client import SpeckleClient
from specklepy.bundle import Model

print("specklepy installed successfully")
```

If the last import raises `ModuleNotFoundError: No module named 'pyarrow'`, install specklepy again with the `bundle` extra.

## Dependencies

specklepy automatically installs these dependencies:

| Package                    | Purpose                                                   |
| -------------------------- | --------------------------------------------------------- |
| `gql[requests,websockets]` | GraphQL client for Speckle Server API                     |
| `httpx`                    | HTTP downloads and uploads                                |
| `pydantic`                 | Data validation and serialization                         |
| `pydantic-settings`        | Settings for Automate function tests                      |
| `attrs`                    | Object traversal helpers                                  |
| `ujson`                    | Fast JSON parsing                                         |
| `deprecated`               | Deprecation warnings                                      |
| `pyarrow`                  | Loads and publishes 2026.9 versions (with `bundle` extra) |

<Info>You don't need to install these manually - pip handles them automatically.</Info>
