## What You'll Build

In this quickstart, you'll learn how to:

1. Authenticate with Speckle Server
2. Create a project and model
3. Describe a wall and a door in code
4. Publish them as a new version
5. Load the version back and query it

Let's get started!

## Prerequisites

1. **Install specklepy with the `bundle` extra.** It adds the parquet support that publishing and loading need:

```bash
pip install "specklepy[bundle]==2026.9.0b3"
```

2. **Get a personal access token.** In the web app, open the workspace switcher (the workspace name at the top of the left sidebar), select your name, then open **Developer** and create a token. See [Authentication](/developers/sdks/python/getting-started/authentication).

<Note>
  Updating a script written for `operations.send` and `operations.receive`? See [Migrate to
  2026.9](/developers/sdks/python/migrate-to-2026-9).
</Note>

## Full Workflow

### Step 1: Authentication

First, let's authenticate with Speckle Server:

<Tabs>
  <Tab title="Using Token">
    ```python lines icon="python" focus={4,7-8}
    from specklepy.api.client import SpeckleClient

    # Create client
    client = SpeckleClient(host="app.speckle.systems")

    # Authenticate with token
    token = "your_token_here"  # Replace with your token
    client.authenticate_with_token(token)

    print(f"✓ Authenticated as {client.account.userInfo.name}")
    ```

  </Tab>

  <Tab title="Using Local Account">
    ```python lines icon="python" focus={5,8-9}
    from specklepy.api.client import SpeckleClient
    from specklepy.api.credentials import get_default_account

    # Get account stored by desktop connector
    account = get_default_account()

    # Create and authenticate client
    client = SpeckleClient(host="app.speckle.systems")
    client.authenticate_with_account(account)

    print(f"✓ Authenticated as {client.account.userInfo.name}")
    ```

  </Tab>
</Tabs>

<Check>If this works, you'll see your name printed!</Check>

### Step 2: Create a Project and Model

Projects are the top-level containers for your data. A model holds the versions you publish.

```python lines icon="python"
from specklepy.api.enums import ProjectVisibility
from specklepy.api.inputs.model_inputs import CreateModelInput
from specklepy.api.inputs.project_inputs import ProjectCreateInput

project = client.project.create(ProjectCreateInput(
    name="My First Speckle Project",
    description="Learning specklepy",
    visibility=ProjectVisibility.PRIVATE
))
model = client.model.create(CreateModelInput(
    name="My first model",
    description="This is my first model",
    project_id=project.id
))

print(f"✓ Created project {project.id} and model {model.id}")
```

<Note>
  If project creation fails because your workspace can't take another project, skip the create call
  and use an existing project's ID instead.
</Note>

### Step 3: Describe Objects

A `BundleBuilder` collects objects, their properties, their geometry, and the relations between them. Each object is identified by an application id you choose.

```python lines icon="python"
from specklepy.bundle import BundleBuilder, Producer
from specklepy.objects.geometry import Mesh

builder = BundleBuilder(Producer("quickstart", "1.0.0"), "m")
walls = builder.get_or_add_container_path(["Level 1", "Walls"])

wall = builder.get_or_add_object("wall-1").set_properties(
    {"Constraints": {"Base Offset": 0.5}}, name="Basic Wall"
)
wall.collection = walls
wall.add_geometry(Mesh(vertices=[0, 0, 0, 1, 0, 0, 0, 1, 0], faces=[3, 0, 1, 2], units="m"))

door = builder.get_or_add_object("door-1").set_properties({"Width": 0.9}, name="Door")
door.collection = walls
door.host = wall

print("✓ Described a wall and a door")
```

Nested property dictionaries become dotted paths: the wall's offset is stored as `Constraints.Base Offset`. `door.host = wall` records a typed relation instead of nesting the door inside the wall. See [Object model](/developers/object-model/overview) and [Relations](/developers/object-model/relations).

### Step 4: Publish a Version

Use `operations.send3()` to upload the objects. The server then processes them and creates the version, so wait for it before you load it:

```python lines icon="python"
import time

from specklepy.api import operations
from specklepy.logging.exceptions import GraphQLException

sent = operations.send3(client.account, project.id, model.id, builder)
print(f"✓ Uploaded. Reserved version id: {sent.version_id}")

version = None
while version is None:
    try:
        version = client.version.get(sent.version_id, project.id)
    except GraphQLException:
        time.sleep(2)

print(f"✓ Version ready: {version.id}")
print(f"View it: https://app.speckle.systems/projects/{project.id}/models/{model.id}")
```

<Check>Go to that URL to see the new version in the web app.</Check>

<Tip>
  In a long-running script, add a timeout to the wait loop. If processing fails, the version is
  never created and you should publish again — see [Publish through model
  ingestions](/developers/migration/publish-through-ingestions).
</Tip>

### Step 5: Load and Query the Version

Now let's load the version back:

```python lines icon="python"
with operations.receive3(client.account, project.id, model.id, version.id) as received:
    received_wall = received.object_by_application_id("wall-1")
    received_door = received.object_by_application_id("door-1")

    print(f"✓ Loaded {len(received.objects)} objects")
    print(f"Wall offset: {received_wall.get_double('Constraints.Base Offset')}")
    print(f"Door is hosted by: {received_door.host.name}")
```

<Info>
  `receive3` downloads the version's bundle to a scratch directory and returns a `Model`. The `with`
  block deletes the files when you are done.
</Info>

<Note>You've now completed your first full Speckle workflow with Python.</Note>

## Complete Example

Here's the complete script:

```python lines icon="python" expandable
import time

from specklepy.api import operations
from specklepy.api.client import SpeckleClient
from specklepy.api.enums import ProjectVisibility
from specklepy.api.inputs.model_inputs import CreateModelInput
from specklepy.api.inputs.project_inputs import ProjectCreateInput
from specklepy.bundle import BundleBuilder, Producer
from specklepy.logging.exceptions import GraphQLException
from specklepy.objects.geometry import Mesh

# 1. Authenticate
client = SpeckleClient(host="app.speckle.systems")
client.authenticate_with_token("your_token_here")  # Replace with your token
print(f"✓ Authenticated as {client.account.userInfo.name}")

# 2. Create project and model
project = client.project.create(ProjectCreateInput(
    name="My First Speckle Project",
    description="Learning specklepy",
    visibility=ProjectVisibility.PRIVATE
))
model = client.model.create(CreateModelInput(
    name="My first model",
    description="This is my first model",
    project_id=project.id
))

# 3. Describe objects
builder = BundleBuilder(Producer("quickstart", "1.0.0"), "m")
walls = builder.get_or_add_container_path(["Level 1", "Walls"])
wall = builder.get_or_add_object("wall-1").set_properties(
    {"Constraints": {"Base Offset": 0.5}}, name="Basic Wall"
)
wall.collection = walls
wall.add_geometry(Mesh(vertices=[0, 0, 0, 1, 0, 0, 0, 1, 0], faces=[3, 0, 1, 2], units="m"))
door = builder.get_or_add_object("door-1").set_properties({"Width": 0.9}, name="Door")
door.collection = walls
door.host = wall

# 4. Publish and wait for the version
sent = operations.send3(client.account, project.id, model.id, builder)
version = None
while version is None:
    try:
        version = client.version.get(sent.version_id, project.id)
    except GraphQLException:
        time.sleep(2)
print(f"✓ Version ready: {version.id}")
print(f"View: https://app.speckle.systems/projects/{project.id}/models/{model.id}")

# 5. Load it back
with operations.receive3(client.account, project.id, model.id, version.id) as received:
    door = received.object_by_application_id("door-1")
    print(f"✓ Loaded {len(received.objects)} objects; the door is hosted by {door.host.name}")
```
