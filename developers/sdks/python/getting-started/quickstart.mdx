## What You'll Build

In this quickstart, you'll learn how to:

1. Authenticate with Speckle Server
2. Create a project and model
3. Send geometry data to Speckle
4. Receive geometry data from Speckle
5. Create a version (commit)

Let's get started!

## Step 1: Authentication

First, let's authenticate with Speckle Server:

<Tabs>
  <Tab title="Using Token">
    ```python lines icon="python" focus={8}
        from specklepy.api.client import SpeckleClient

        # Create client
        client = SpeckleClient(host="app.speckle.systems")

        # Authenticate with token
        token = "your_token_here"  # Replace with your token
        client.authenticate_with_token(token)

        print(f"✓ Authenticated as {client.account.userInfo.name}")
        ```
  </Tab>
  
  <Tab title="Using Local Account">
    ```python lines icon="python" focus={9}
        from specklepy.api.client import SpeckleClient
        from specklepy.api.credentials import get_default_account

        # Get account stored by desktop connector
        account = get_default_account()

        # Create and authenticate client
        client = SpeckleClient(host="app.speckle.systems")
        client.authenticate_with_account(account)

        print(f"✓ Authenticated as {client.account.userInfo.name}")
        ```
  </Tab>
</Tabs>

If this works, you'll see your name printed!

## Step 2: Create a Project

Projects are the top-level containers for your data:

```python lines icon="python" focus={3-7}
from specklepy.core.api.inputs.project_inputs import ProjectCreateInput

# Create a new project
project = client.project.create(ProjectCreateInput(
    name="My First Speckle Project",
    description="Learning specklepy"
))

print(f"✓ Created project: {project.id}")

# Get the project details
project = client.project.get(project.id)
print(f"Project name: {project.name}")
```

<Info>
Projects replace what used to be called "Streams" in Speckle 1.0.
</Info>

## Step 3: Create Geometry

Now let's create some geometry objects:

<Warning>
**Important:** Sending geometry primitives (Point, Line, Mesh) directly will NOT make them visible in the 3D viewer! You must wrap them in a container object. This is why we use `Base()` below to group the geometry.
</Warning>

```python lines icon="python" focus={5-8,11,14-16,19-22}
from specklepy.objects.geometry import Point, Line, Polyline
from specklepy.objects import Base

# Create some points
p1 = Point(x=0, y=0, z=0)
p2 = Point(x=10, y=0, z=0)
p3 = Point(x=10, y=10, z=0)
p4 = Point(x=0, y=10, z=0)

# Create a line
line = Line(start=p1, end=p2)

# Create a polyline (closed rectangle)
polyline = Polyline()
polyline.points = [p1, p2, p3, p4, p1]  # Close the shape
polyline.closed = True

# ✅ IMPORTANT: Wrap geometry in Base object for viewer visibility
data = Base()
data.line = line
data.rectangle = polyline
data.points = [p1, p2, p3, p4]

print("✓ Created geometry objects")
```

<Tip>
The `Base` class is the foundation of all Speckle objects. You can attach any properties to it dynamically! Wrapping geometry in Base ensures it's visible in the 3D viewer.
</Tip>

## Step 4: Send Data to Speckle

Use `operations.send()` to send your data:

```python lines icon="python" focus={8}
from specklepy.api import operations
from specklepy.transports.server import ServerTransport

# Create a transport (the vehicle for sending data)
transport = ServerTransport(stream_id=project_id, client=client)

# Send the data and get the object ID
object_id = operations.send(base=data, transports=[transport])

print(f"✓ Sent data! Object ID: {object_id}")
```

<Note>
The `object_id` is a unique hash that represents your data. You'll use this to create a version.
</Note>

## Step 5: Create a Version

Versions (formerly "commits") capture a snapshot of your data:

```python lines icon="python"
from specklepy.core.api.inputs.version_inputs import CreateVersionInput

# Get the main model (branch) - it's created automatically
models = client.model.list(project_id)
model_id = models[0].id

# Create a version
version_input = CreateVersionInput(
    project_id=project_id,
    model_id=model_id,
    object_id=object_id,
    message="My first version!"
)
version = client.version.create(version_input)

print(f"✓ Created version: {version.id}")
print(f"View it: https://app.speckle.systems/projects/{project_id}/models/{model_id}")
```

<Check>
Go to that URL to see your data in the 3D viewer!
</Check>

## Step 6: Receive Data

Now let's receive the data back:

```python lines icon="python"
# Receive the data using the object_id
received_data = operations.receive(
    obj_id=object_id,
    remote_transport=transport
)

print(f"✓ Received data!")
print(f"Line start: ({received_data.line.start.x}, {received_data.line.start.y}, {received_data.line.start.z})")
print(f"Rectangle points: {len(received_data.rectangle.points)}")
print(f"Number of points: {len(received_data.points)}")
```

You've completed your first full Speckle workflow! 🎉
</Success>

## Important: Receiving Data from Versions

<Warning>
**Critical concept:** When you get a version, you only get its **metadata and object ID reference**, not the actual data!
</Warning>

To receive data from an existing version, you need a two-step process:

### Step 1: Get the Version and Extract Object ID

```python lines icon="python"
# Get a specific version
version = client.version.get(project_id, version_id)

# The version contains a reference to the root object
root_object_id = version.referencedObject  # This is just an ID string!

print(f"Version created: {version.createdAt}")
print(f"Message: {version.message}")
print(f"Root object ID: {root_object_id}")
```

### Step 2: Receive the Actual Data

```python lines icon="python"
# Now use operations.receive to get the actual data
transport = ServerTransport(stream_id=project_id, client=client)

received_data = operations.receive(
    obj_id=root_object_id,  # Use the referencedObject from the version
    remote_transport=transport
)

# Now you have the actual data!
print(f"Received: {type(received_data)}")
```

<Info>
**Why two steps?**

Versions store metadata (author, timestamp, message) separately from the actual object data. This keeps version lists fast and lightweight. You only download the full data when you explicitly `receive()` it.
</Info>

### Complete Example: Receive Latest Version

```python lines icon="python"
# Get the latest version from a model
versions = client.version.list(project_id, model_id, limit=1)
latest_version = versions[0]

print(f"Latest version: {latest_version.message}")
print(f"Created: {latest_version.createdAt}")
print(f"By: {latest_version.authorUser.name}")

# Get the root object ID
root_obj_id = latest_version.referencedObject

# Receive the actual data
transport = ServerTransport(stream_id=project_id, client=client)
data = operations.receive(obj_id=root_obj_id, remote_transport=transport)

print(f"✓ Received data from latest version!")
```

## Complete Example

Here's the complete script:

```python lines icon="python"
from specklepy.api.client import SpeckleClient
from specklepy.api import operations
from specklepy.objects.geometry import Point, Line, Polyline
from specklepy.objects import Base
from specklepy.transports.server import ServerTransport
from specklepy.core.api.inputs.project_inputs import ProjectCreateInput
from specklepy.core.api.inputs.model_inputs import CreateModelInput
from specklepy.core.api.inputs.version_inputs import CreateVersionInput

# 1. Authenticate
client = SpeckleClient(host="app.speckle.systems")
token = "your_token_here"  # Replace with your token
client.authenticate_with_token(token)
print(f"✓ Authenticated as {client.account.userInfo.name}")

# 2. Create project
project = client.project.create(ProjectCreateInput(
    name="My First Speckle Project",
    description="Learning specklepy"
))
print(f"✓ Created project: {project.id}")

# 3. Create geometry
p1 = Point(x=0, y=0, z=0)
p2 = Point(x=10, y=0, z=0)
p3 = Point(x=10, y=10, z=0)
p4 = Point(x=0, y=10, z=0)

line = Line(start=p1, end=p2)

polyline = Polyline()
polyline.points = [p1, p2, p3, p4, p1]
polyline.closed = True

data = Base()
data.line = line
data.rectangle = polyline
data.points = [p1, p2, p3, p4]
print("✓ Created geometry")

# 4. Send data
# Send to server
transport = ServerTransport(stream_id=project.id, client=client)
object_id = operations.send(base=data, transports=[transport])
print(f"✓ Sent data: {object_id}")

# 5. Create version
models = client.model.list(project.id)
model_id = models[0].id
</parameter>

version_input = CreateVersionInput(
    project_id=project.id,
    model_id=model_id,
    object_id=object_id,
    message="My first version!"
)
version = client.version.create(version_input)
print(f"✓ Created version: {version.id}")
print(f"View: https://app.speckle.systems/projects/{project.id}/models/{model_id}")
</parameter>

# 6. Receive data
received_data = operations.receive(obj_id=object_id, remote_transport=transport)
print(f"✓ Received data: {len(received_data.points)} points")
```

## Common Next Steps

### Working with Existing Projects

```python lines icon="python"
# List your projects
projects = client.project.list()
for project in projects:
    print(f"{project.name}: {project.id}")

# Get a specific project
project = client.project.get("project_id_here")
```

### Working with Models

```python lines icon="python"
from specklepy.core.api.inputs.model_inputs import CreateModelInput

# List models in a project
models = client.model.list(project_id)

# Create a new model
model = client.model.create(CreateModelInput(
    project_id=project_id,
    name="Design Option A"
))
```

### Getting Version History

```python lines icon="python"
# List all versions in a model
versions = client.version.list(project_id, model_id)

for version in versions:
    print(f"{version.message} - {version.createdAt}")
    print(f"  Object ID: {version.referencedObject}")
```

### Using Different Transports

```python lines icon="python"
from specklepy.transports.sqlite import SQLiteTransport
from specklepy.transports.memory import MemoryTransport

# Use local SQLite cache (default)
local_transport = SQLiteTransport()

# Use in-memory transport (for testing)
memory_transport = MemoryTransport()

# Send to multiple transports
object_id = operations.send(
    base=data,
    transports=[transport, local_transport]
)
```
