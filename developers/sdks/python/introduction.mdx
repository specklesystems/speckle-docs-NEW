## What is specklepy?

specklepy is a Python library that provides:

- **Model loading** - Load a version as a queryable `Model`: objects, path-keyed properties, and typed relations (`operations.receive3`)
- **Publishing** - Describe objects and geometry in code and publish them as a new version (`operations.send3`)
- **GraphQL API client** - Full access to Speckle Server's API: projects, models, versions, and more
- **Geometry support** - Geometric primitives (Point, Line, Mesh, Brep, and more)
- **Object-graph tools** - `Base` objects and transports for versions published before 2026.9

<Info>specklepy requires **Python 3.10+** and supports Windows, macOS, and Linux.</Info>

## Key Features

### Query models, not files

Speckle stores model data as objects with properties and relations, not files. Load a version and query it directly.

```python lines icon="python"
with operations.receive3(account, project_id, model_id, version_id) as model:
    walls = [o for o in model.objects_with("category") if o.get_string("category") == "Walls"]
    print(f"{len(walls)} walls on {len({w.level.name for w in walls if w.level})} levels")
```

<Note>
  Speckle stores sets of objects in Models. Models are contained within Projects. Projects are
  contained within Workspaces. Learn more about organising your data in Speckle in the [User
  Guide](/workspaces/projects). How the data inside a version is shaped: [Object
  model](/developers/object-model/overview).
</Note>

### Version Control for AEC Data

Every publish creates a new **version**, giving you full history and traceability.

```python lines icon="python"
# List the five most recent versions of a model
versions = client.version.get_versions(model_id, project_id, limit=5)
for version in versions.items:
    print(version.id, version.message)
```

### Real-Time Collaboration

Subscribe to changes and get notified when new data arrives.

```python lines icon="python" focus={2-5}
# Subscribe to project updates
client.subscribe.project_versions_updated(
    project_id=project_id,
    callback=on_version_created
)
```

<Warning>
  Subscriptions may not make sense if the script is not running continuously. Consider using a
  webhook or a scheduled task instead.
</Warning>

## Installation

Install specklepy with the `bundle` extra:

```bash
pip install "specklepy[bundle]==2026.9.0b3"
```

<Warning>
  An older specklepy gets a 404 when it loads a version published by a 2026.9 connector. Install
  **2026.9.0b3** or later with the `bundle` extra. See [Who's
  affected](/developers/migration/data-model-migration#whos-affected).
</Warning>

<Note>
  2026.9.0b3 is a prerelease; a later stable 2026.9.0 replaces the pin without changing the calls.
  For virtual environments and other options, see the [Installation
  Guide](/developers/sdks/python/getting-started/installation).
</Note>

## Quick Example

Load the latest version of a model and count its objects by category:

```python lines icon="python"
from specklepy.api import operations
from specklepy.api.client import SpeckleClient

# Authenticate
client = SpeckleClient(host="app.speckle.systems")
client.authenticate_with_token("your_token_here")  # Replace with your token

project_id = "your_project_id"
model_id = "your_model_id"

# Find the latest version
latest = client.version.get_versions(model_id, project_id, limit=1).items[0]

# Load it and count objects by category
with operations.receive3(client.account, project_id, model_id, latest.id) as model:
    counts = {}
    for obj in model.objects:
        key = obj.get_string("category") or obj.name or "Unknown"
        counts[key] = counts.get(key, 0) + 1

print(counts)
```
