When you receive a Speckle model and need to find walls, extract parameters, or build lookups by category, you traverse the object graph — flat with `Flatten`, or rule-based with `GraphTraversal`. Platform traversal patterns (Collections, DataObjects, proxies): [Traversal Recipes](/developers/data-schema/traversal-recipes). This guide covers the .NET APIs and performance patterns.

## Prerequisites

- [Objects, detachment, and traversal](/developers/sdks/dotnet/concepts/objects-and-traversal)

<Note>
Property names like "walls" or "floors" in examples are illustrative. Connector-produced BIM data often uses **proxy collections** — see [Working with Proxies](/developers/sdks/dotnet/guides/working-with-proxies).
</Note>

<Note>
Examples filter with `obj["category"]` for readability. On `DataObject` instances, semantic fields live in `properties`: `((DataObject)obj).properties.GetValueOrDefault("category")`. Same traversal patterns — only property access changes.
</Note>

## Complete Example


```csharp Complete example lines icon="/images/developers/sdks/csharp.svg" expandable
using Speckle.Sdk.Models;
using Speckle.Sdk.Models.Extensions;

var walls = root.Flatten()
    .Where(obj => obj["category"] as string == "Walls")
    .ToList();

var byCategory = root.Flatten()
    .GroupBy(obj => obj["category"] as string ?? "Unknown")
    .ToDictionary(g => g.Key, g => g.ToList());
```

## Flatten vs GraphTraversal

`Flatten` returns every `Base` in the graph — the right default for filtering and indexing:

```csharp Example lines icon="/images/developers/sdks/csharp.svg"
foreach (var obj in root.Flatten())
{
    Console.WriteLine(obj.TryGetName() ?? "unnamed");
}
```

`GraphTraversal` adds **context** (parent, property name) and custom walk rules:

```csharp Example lines icon="/images/developers/sdks/csharp.svg"
using Speckle.Sdk.Models.GraphTraversal;

var traversal = DefaultTraversal.CreateTraversalFunc();
foreach (TraversalContext ctx in traversal.Traverse(root))
{
    var obj = ctx.Current;
    var parentName = ctx.Parent?.Current.TryGetName() ?? "root";
    Console.WriteLine($"{obj.TryGetName()} (from {parentName}.{ctx.PropName})");
}
```

<Tip>
`DefaultTraversal.CreateTraversalFunc()` is what Rhino, Grasshopper, Revit, AutoCAD, Tekla, and Navisworks use for receive. Prefer it unless you need to walk different properties.
</Tip>

<Warning>
`new GraphTraversal()` with no rules traverses nothing beyond the root. Always pass at least one rule.
</Warning>

Custom rule example — walk dynamic members but skip `displayValue`:

```csharp Example lines icon="/images/developers/sdks/csharp.svg"
var skipDisplayValue = TraversalRule
    .NewTraversalRule()
    .When(_ => true)
    .ContinueTraversing(obj => obj.GetDynamicMemberNames().Where(n => n != "displayValue" && n != "@displayValue"))
    .ShouldReturnToOutput();

var traversal = new GraphTraversal(skipDisplayValue);
```

<Note>
`CreateTraversalFunc()` does **not** descend into `displayValue`. `Flatten` does — exclude `displayValue`/`@displayValue` in custom rules if you're extracting geometry separately.
</Note>

## Finding Objects by Criteria

```csharp Example lines icon="/images/developers/sdks/csharp.svg"
List<Base> FindByProperty(Base root, string key, object? value) =>
    root.Flatten().Where(obj => Equals(obj[key], value)).ToList();
```

## Building Indexes for Repeated Lookups

Each `Flatten()` is O(n). Build a dictionary once for multiple lookups:

```csharp Example lines icon="/images/developers/sdks/csharp.svg"
var byCategory = root.Flatten()
    .GroupBy(o => o["category"] as string ?? "Unknown")
    .ToDictionary(g => g.Key, g => g.ToList());

var walls = byCategory.GetValueOrDefault("Walls", new());
```

An `applicationId` index resolves [proxies](/developers/sdks/dotnet/guides/working-with-proxies):

```csharp Example lines icon="/images/developers/sdks/csharp.svg"
var byAppId = root.Flatten()
    .Where(o => o.applicationId is not null)
    .ToDictionary(o => o.applicationId!);
```

For hierarchy depth and paths, use `TraverseWithPath`:

```csharp Example lines icon="/images/developers/sdks/csharp.svg"
foreach (var (path, obj) in root.TraverseWithPath(_ => false))
{
    var indent = new string(' ', path.Length * 2);
    Console.WriteLine($"{indent}{obj.TryGetName()} ({string.Join("/", path)})");
}
```

## Common Pitfalls

<AccordionGroup>
  <Accordion title="Traversal never terminates">
    Hand-written recursion can loop on circular references. `Flatten` and `GraphTraversal` guard against this.
  </Accordion>
  <Accordion title="Rebuilding an index inside a loop">
    Build the dictionary once outside your query loop.
  </Accordion>
  <Accordion title="Property value is a List<object>, not a typed collection">
    Dynamic properties deserialize as JSON-native shapes. Cast or pattern-match at read time.
  </Accordion>
  <Accordion title="Duplicate results from displayValue">
    Exclude `displayValue` and `@displayValue` from custom traversal rules if you're extracting geometry separately.
  </Accordion>
</AccordionGroup>
