**Speckle.Sdk** is the C# .NET SDK for Speckle, enabling you to interact with Speckle Server, send and receive geometry, and build custom integrations for the AEC industry.

[GitHub Repository](https://github.com/specklesystems/speckle-sharp-sdk)

<Info>
Compatible with **Speckle Object Model v3**
</Info>

<Warning>
Speckle.Sdk and Speckle.Objects are reliable for production use, but the public API may not be wholly stable between releases. Pin a specific NuGet version and review release notes before upgrading.
</Warning>

## What is Speckle.Sdk?

Speckle.Sdk is a .NET library that provides:

- **Object-based data exchange** — send and receive geometry and BIM data without files
- **GraphQL API client** — full access to Speckle Server's API through typed resources (`client.Project`, `client.Model`, `client.Version`, and more)
- **Extensible object model** — create custom object types that inherit from `Base`
- **Multiple transport options** — store data locally (SQLite), in-memory, or on Speckle Server
- **Geometry support** — the companion `Speckle.Objects` package adds geometry primitives (Point, Line, Mesh, Brep, and more)

<Info>
Speckle.Sdk targets **netstandard2.0**, **net8.0**, and **net10.0**, so it runs in both modern .NET applications and older host apps (such as Revit on .NET Framework).
</Info>

## Key Features

### Object-Based, Not File-Based

Forget about files. Speckle uses **objects** as the fundamental unit of data exchange.

```csharp
var myData = new Base
{
    ["name"] = "My first object",
    ["count"] = 42
};
```

<Note>
Instead of files, Speckle stores sets of objects in Models. Models are contained within Projects. Projects are contained within Workspaces. Learn more about organising your data in Speckle in the [User Guide](https://docs.speckle.dev/workspaces/projects).
</Note>

### Version Control for AEC Data

Every change creates a new **version** (commit), giving you full history and traceability.

```csharp
var versionInput = new CreateVersionInput(objectId, model.id, project.id, "Updated geometry");
var version = await client.Version.Create(versionInput);
```

<Note>
The `objectId` here is of a **Speckle object** that has already been sent to the Speckle server. Sending registers it in the database, but visibility of it is scoped to a **version**.
</Note>

<Note>
Objects not associated with a **Model** **Version** are considered "zombie objects" or "orphans." Other than a record of `objectId`, they are effectively irretrievable.
</Note>

### One-Time Setup (Not "Dependency Injection" as a Skill)

Speckle.Sdk resolves its services through `Microsoft.Extensions.DependencyInjection` because desktop connectors and services share the same SDK. **For scripts and notebooks, you do not need to learn DI** — paste a short bootstrap once and resolve `IOperations` and `IClientFactory` from it.

```csharp
var services = new ServiceCollection();
services.AddSpeckleSdk(new Application("My App", "my-app"), "1.0.0");
var provider = services.BuildServiceProvider();
```

## Quick Example

Here's a complete example of sending geometry to Speckle:

```csharp
using Microsoft.Extensions.DependencyInjection;
using Speckle.Sdk;
using Speckle.Sdk.Api;
using Speckle.Sdk.Api.GraphQL.Inputs;
using Speckle.Sdk.Credentials;
using Speckle.Sdk.Models;
using Speckle.Sdk.Transports;

// Bootstrap the SDK
var services = new ServiceCollection();
services.AddSpeckleSdk(new Application("My App", "my-app"), "1.0.0");
var provider = services.BuildServiceProvider();

// Authenticate with a personal access token
var account = await provider.GetRequiredService<IAccountFactory>()
    .CreateAccount(new Uri("https://app.speckle.systems"), "your_token_here");
using var client = provider.GetRequiredService<IClientFactory>().Create(account);

// Create a project
var project = await client.Project.Create(new ProjectCreateInput("My First Speckle Project", null, ProjectVisibility.Private));

// Build a Speckle object
var myData = new Base { ["greeting"] = "Hello Speckle" };

// Send it to the project
using var transport = provider.GetRequiredService<IServerTransportFactory>().Create(client.Account, project.id);
var (objectId, _) = await provider.GetRequiredService<IOperations>().Send(myData, transport, true);

// Create a model and a version pointing at the sent object
var model = await client.Model.Create(new CreateModelInput("My first model", null, project.id));
var version = await client.Version.Create(new CreateVersionInput(objectId, model.id, project.id, "My first version"));

Console.WriteLine($"Created version: {version.id}");
```
