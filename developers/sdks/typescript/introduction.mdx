**speckle.js** is the Javascript/TypeScript SDK for Speckle, enabling you to interact with Speckle Server, send and receive geometry, and build custom integrations for the AEC industry.

<Info>
  For platform concepts shared across SDKs, see the [SDK
  introduction](/developers/sdks/introduction).
</Info>

<Note>This SDK is currently in development and is not yet available.</Note>

<Warning>
  **Building directly on the Viewer package, or on `@speckle/objectloader` /
  `@speckle/objectloader2`?** Your app stops getting data as soon as a version you load was
  published in 2026.9: the objects endpoints return 404 for it. Start from [Building
  applications](/developers/building-apps), which routes rendering apps and data-only apps to the
  right load path.
</Warning>

For rendering 2026.9 versions with the Viewer package, see the [Viewer developers guide](/developers/viewer/introduction) and [Load a bundle in your Viewer app](/developers/viewer/loading-bundles).
