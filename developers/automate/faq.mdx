## FAQ

<AccordionGroup>
  <Accordion title="How much does Speckle Automate cost? Is it included in enterprise plans?">
    Automate is available on the **Enterprise** plan, which includes custom automation support by
    Speckle engineers. On other plans, contact sales@speckle.systems.
  </Accordion>
  <Accordion title="Is Speckle Automate faster than desktop workflows?">
    Not always for a single task, but it saves time across a team. Functions run on cloud
    infrastructure, so local machines stay free. They run automatically on each new version, so
    results are ready without a manual step. And a reusable function puts a workflow in reach of
    people who don't know the software it replaces.
  </Accordion>
  <Accordion title="What programming languages and SDKs are supported by Speckle Automate?">
    Speckle provides Automate SDKs for Python and C#. Automate can also run any command-line
    executable, so you can bring another stack, though support for it is limited.
  </Accordion>
  <Accordion title="Is Speckle Automate part of the Speckle Server? How do I install or access it?">
    Automate is a separate service that works alongside a Speckle Server, built into the web app. On
    app.speckle.systems it runs on Speckle-hosted infrastructure. Speckle Enterprise Server
    deployments can run it on their own infrastructure; see [Enterprise
    Automate](/developers/server/deployment/enterprise-license-automate). The open-source server
    does not include Automate.
  </Accordion>
  <Accordion title="What do I need to get started with Speckle Automate?">
    An Enterprise workspace and at least one Function repository connected through GitHub or another
    VCS.
  </Accordion>
  <Accordion title="How does Speckle Automate compare to Hypar, Viktor, or ShapeDiver?">
    Automate runs time-consuming tasks when a model gets a new version; it is not a real-time
    parametric modelling tool like Hypar or ShapeDiver. It works on data from any Speckle connector,
    such as Revit, Rhino, SketchUp, or Blender, and functions can be written in any language.
  </Accordion>
  <Accordion title="Who can create Functions in Speckle Automate?">
    Creating Functions needs an Enterprise workspace. Functions live at workspace level; see [Create
    a function](/developers/automate/create-function).
  </Accordion>
  <Accordion title="Can I use Automate on a personal project?">
    No. Automate runs only on projects in a workspace with Automate enabled. Project Owners create
    and configure automations, and Contributors can also trigger runs.
  </Accordion>
  <Accordion title="Who can view automation results in Speckle Automate?">
    Every project member, including Reviewers, can open project **Settings → Automations** and see
    each automation's runs, their status, and their logs. The results a function recorded show in
    the Dashboards **Automate results** widget, not in the 3D viewer. See [Viewing Automation
    Results](/developers/automate/viewing-results).
  </Accordion>
  <Accordion title="Where can I get help or support for Speckle Automate?">
    Visit the [Community Forum](https://speckle.community/c/automate) to get help or share feedback
    about Automate.
  </Accordion>
  <Accordion title="Is there a clash detection function?">
    Not a public one. You can write your own: a function receives the triggering version, can load
    other models in the project through its Speckle client, and can attach each clash as a result on
    the objects involved.
  </Accordion>
</AccordionGroup>
