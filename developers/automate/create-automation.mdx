## What is an Automation?

- Automations allow you to perform a wide variety of tasks efficiently.
- Automations apply a function to a Speckle model.
- Automations enable you to configure a function to meet your specific requirements.

For example, a function might render a photograph-quality image of a model. Automation allows you to specify parameters such as the camera position, lighting, and other settings to customise the output for your particular Speckle model.

<Note>
  Speckle Automate is available only on Speckle Enterprise Server. For deployment setup, see
  [Enterprise license —
  Automate](/developers/server/deployment/enterprise-license#optional-automate).
</Note>

## Create an automation

Automations are created from the project's **Settings → Automations** page. Each automation ties one function to one trigger model.

{/* IMAGE_PLACEHOLDER: Project Settings → Automations — search, View functions, New Automation, table with Disabled and Test badges, Triggered by or Connected to. */}

<Steps>
  <Step title="Open project Automations">
    Open the project, then **Settings → Automations**. You should see the automations table, or **No
    automations yet.**
  </Step>
  <Step title="Start a new automation">
    Select **New Automation**. The **Create automation** dialog opens.
  </Step>
  <Step title="Choose a function and its parameters">
    Select a function in **Function**, then fill in the parameter form that appears below it. A
    function without parameters shows **No parameters**.
  </Step>
  <Step title="Choose the trigger model and name">
    Select the model whose new versions should start a run in **Trigger model**, then enter an
    **Automation name**.
  </Step>
  <Step title="Create the automation">
    Select **Create**. The automation's page opens, showing its function, its model trigger, and an
    empty **Runs** list.
  </Step>
</Steps>

{/* IMAGE_PLACEHOLDER: Create automation dialog — Function, parameter form, Trigger model, Automation name; Create test automation control. */}

<Tip>
  The **Function** list shows the functions available to the project's workspace. To add one, see
  [Create a function](/developers/automate/create-function).
</Tip>

The new automation runs the next time someone publishes a version to the trigger model. To run it straight away, select **Trigger automation** on the automation's page.

## Create a test automation

A test automation connects your local development environment to project data, so you can run your function code against a model and submit results without publishing a function release.

In the **Create automation** dialog, select **Create test automation**. Choose the model to connect to and name the automation, then select **Create**. To go back to a regular automation, select **Standard automation**.

<Note>
  Test automations do not run when someone publishes a new version, and they never run published
  functions. In the automations table they show a **Test** badge and **Connected to** instead of
  **Triggered by**. See [Testing functions](/developers/automate/function-testing).
</Note>
