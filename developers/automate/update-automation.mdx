---
title: Update an Automation
description: Change an automation's function release, parameter values, or target model from project Settings → Automations, or turn it off, without recreating the automation.
---

Update an automation when a new function release is out, when its parameters need different values, or when it should run on a different model. You change all three in the **Function settings** dialog; the automation keeps its name and run history.

{/* IMAGE_PLACEHOLDER: Function settings dialog — Function release, parameter form, Target model; View function link; Save. */}

<Steps>
  <Step title="Open project Automations">
    Open the project, then **Settings → Automations**. You should see the automations table.
  </Step>
  <Step title="Open the function settings">
    Open the automation's row menu and select **Edit settings**. The **Function settings** dialog
    opens. On the automation's own page, **Edit details** opens the same dialog.
  </Step>
  <Step title="Choose a function release">
    Select the release to run in **Function release**. Releases are listed by version tag.
  </Step>
  <Step title="Update parameters and target model">
    Amend the parameter values in the form, and change **Target model** if the automation should run
    on a different model.
  </Step>
  <Step title="Save the changes">Select **Save**. The next run uses the new settings.</Step>
</Steps>

<Tip>
  On the automation's page, an **Outdated** badge next to the function release means a newer release
  is available.
</Tip>

## Turn an automation off or delete it

On the automation's page, use the switch next to its name to turn it off or back on. A turned-off automation shows a **Disabled** badge in the automations table and does not run when the model gets a new version.

To remove it, open the menu next to the switch and select **Delete automation**.

<Warning>
  Deleting an automation removes all of its previous runs. Model data is not changed. Turn the
  automation off instead if you might need its run history.
</Warning>

## FAQ

<AccordionGroup>
  <Accordion title="Why can't I edit a test automation's function?">
    Test automations are connected to your local development environment and never run a published
    function release, so they have no function settings to edit. See [Testing Your
    Functions](/developers/automate/function-testing).
  </Accordion>
  <Accordion title="Does changing settings re-run the automation?">
    No. The new settings apply from the next run. To run straight away, select **Trigger
    automation** on the automation's page.
  </Accordion>
</AccordionGroup>
