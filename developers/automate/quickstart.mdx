Go from no code to a function that runs every time a model gets a new version. You create the function from a template, release it from GitHub, attach it to a model with an automation, and check its first run.

<Note>
  Speckle Automate is available only on Speckle Enterprise Server. For deployment setup, see
  [Enterprise license —
  Automate](/developers/server/deployment/enterprise-license#optional-automate).
</Note>

## Prerequisites

Before you begin, make sure you have:

- An **Enterprise plan** workspace on [app.speckle.systems](https://app.speckle.systems)
- A verified account on [app.speckle.systems](https://app.speckle.systems)
- A project in that workspace where you can manage automations (project owners can)
- An account on [github.com](https://github.com)

<Tip>Verify your account by responding to the email sent to you upon sign-up.</Tip>

<Note>
  GitHub is the default platform for creating and releasing functions. To publish a function without
  GitHub, see [Publishing without GitHub](/developers/automate/publishing-without-github).
</Note>

## Where Automate lives

Automate is part of the Speckle web app. Open a project in your Enterprise workspace and go to **Settings → Automations**. From there, **New Automation** creates an automation and **View functions** opens the workspace **Functions** page.

## Build and run your first function

<Steps>
  <Step title="Create a function">
    Go to **Settings → Automations**, select **View functions**, then select **New function** and
    follow [Create a function](/developers/automate/create-function). The function's page opens with
    a link to its new GitHub repository.
  </Step>
  <Step title="Write your function logic">
    Clone the repository and edit the template code to implement your logic. To try it against
    project data before you release, use a [test automation](/developers/automate/function-testing).
  </Step>
  <Step title="Publish a release">
    Create a release in the GitHub repository. When the release workflow finishes, your function
    appears on the workspace **Functions** page.
  </Step>
  <Step title="Create an automation">
    In **Settings → Automations**, select **New Automation**, choose your function and its
    parameters, pick the trigger model, name the automation, and select **Create**. The automation's
    page opens; see [Creating Automations](/developers/automate/create-automation).
  </Step>
  <Step title="Check the run">
    Publish a new version to the trigger model, or select **Trigger automation** on the automation's
    page. The **Runs** table shows the new run and its status.
  </Step>
</Steps>

<Note>
  The 3D viewer does not show Automate results. Open a run for its log output, and use the
  Dashboards **Automate results** widget to see the results your function recorded. See [Viewing
  Automation Results](/developers/automate/viewing-results).
</Note>
