---
title: Viewing Automation Results
description: Where to see Speckle Automate runs and results — run status and logs in project Settings → Automations, and the results each function recorded in the Dashboards Automate results widget.
---

Every automation run records its status, its log output, and the results your function attached to objects. Check the run itself from the project's automation settings, and see the recorded results in a dashboard.

<Warning>
  The 3D viewer and the project model list do not show Automate results. Runs still complete and
  record their results, so a run with no results visible in the viewer has not failed: check its
  status as described below.
</Warning>

<Note>
  If your function attaches results to individual objects, see [Attach results to 2026.9
  models](/developers/automate/function-results#attach-results-to-2026-9-models) for how those
  results line up with the model's objects.
</Note>

## Check a run's status

{/* IMAGE_PLACEHOLDER: Automation page under project Settings → Automations — Function and Model trigger cards, Runs table with Status, Run ID, Model version, Date, Duration. */}

<Steps>
  <Step title="Open project Automations">
    Open the project, then **Settings → Automations**. The **Status** column shows the latest run of
    each automation.
  </Step>
  <Step title="Open the automation">
    Select the automation's name. The **Runs** table lists each run with its status, run ID, model
    version, date, and duration.
  </Step>
  <Step title="Open a run">
    Select the eye icon on a run. The **Run details** dialog shows the run's status, start time,
    duration, any error message, and the log output.
  </Step>
</Steps>

## See results in a dashboard

Dashboards include an **Automate results** widget, in Beta, that shows the latest Automate runs for a model version. For each run it lists the results your function recorded — level, category, and message — with any attachments. Selecting a result isolates the objects it refers to in the dashboard's 3D view.

{/* IMAGE_PLACEHOLDER: Dashboards — Automate results widget listing a run's results as cards, with the affected objects isolated in the 3D view. */}

<Steps>
  <Step title="Add the widget">
    Open a dashboard on the project and add the **Automate results** widget. See [Intelligence
    Dashboards](/analytics/intelligence-dashboards) for adding widgets.
  </Step>
  <Step title="Point it at a model version">
    Choose the model version the automation ran on as the widget's data source. The widget lists
    that version's latest runs and their results.
  </Step>
  <Step title="Isolate a result's objects">
    Select a result card. The objects it refers to are isolated in the dashboard's 3D view.
  </Step>
</Steps>

<Note>
  The widget matches a result to model objects by `applicationId`. Results stored before a model was
  migrated to the 2026.9 data model reference the old content-hashed ids and do not match; re-run
  the automation to get results that line up.
</Note>

## FAQ

<AccordionGroup>
  <Accordion title="Did my automation actually run if I can't see results in the viewer?">
    Yes, if its run shows **SUCCEEDED** in the **Runs** table. The viewer does not show Automate
    results; the run and what it recorded are not affected.
  </Accordion>
  <Accordion title="Is there an API to read results back?">
    There is no documented, supported API for reading Automate results after a run. Use the
    Dashboards **Automate results** widget.
  </Accordion>
  <Accordion title="Why does a run show as failed?">
    Open the run's **Run details**. The error message and the log output show what the function
    reported. See [Troubleshooting Automations](/developers/automate/troubleshooting).
  </Accordion>
</AccordionGroup>
