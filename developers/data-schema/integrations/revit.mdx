All Revit models published to Speckle are structured by collections representing the File, Level, Category, and Type of each Revit element.

```mdx
**Revit Model Structure**

```text
📁 Root Collection
├── 📁 Revit File (could be a linked model)
│   └── 📁 Level
│       └── 📁 Category
│           └── 📁 Type
│               └── 📄 Revit Object
├── Proxies: Render Materials
├── Proxies: Levels
├── Proxies: Groups
├── Info: Reference Point Transform
└── Info: Views

## The Revit Object

<Info>
The Speckle `RevitObject` represents an **element** `Autodesk.Revit.DB Element` in Revit.
</Info>

The Revit object inherits from the [DataObject](../schemas/dataobject) class, with the following schema:

```JSON
{
  "__comment": "these fields are specified on the Base class",
  "id": string,
  "speckle_type": "Objects.Data.DataObject:Objects.Data.RevitObject",
  "applicationId": string,
  
  "__comment": "these fields are specified on the DataObject",
  "name": string,
  "properties": {
    string : value
  },
  "displayValue": [
    Base
  ],

  "__comment": "these fields are specified on the RevitObject",
  "type": string,
  "family": string,
  "category": string,
  "level": string,
  "location": base,
  "elements": [
    RevitObject
  ],
  "units": string
}
```

### Revit Object Properties

Revit object properties include:
- Instance Parameters
- Type Parameters
- Material Quantities

## Proxies

Proxies found on the root collection of a Revit model:
- [Render Materials](../schemas/proxy)
- Levels
- [Groups](../schemas/proxy)

## Additional Info Fields

Revit models can also include:
- **Reference Point Transform**: a transform matrix indicating the transfrom applied to all model objects from the selected reference point setting during publish.
- **Views**: a list of `Camera` class objects from **perspective 3D views** in the file that the Revit model is published from.
