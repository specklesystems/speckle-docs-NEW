**AutoCAD Model Structure**

📁 Root Collection
├── 📁 AutoCAD File

│       ├── 📄 Geometry
│       └── 📄 Instance
├── Proxies: Render Materials
├── Proxies: Colors
├── Proxies: Groups
└── Proxies: Instance Definitions

## Geometry and Instance Properties

Geometries and Instances published from AutoCAD can also have a properties field dynamically attached.
Properties include:
- Extension Dictionaries
- XData
