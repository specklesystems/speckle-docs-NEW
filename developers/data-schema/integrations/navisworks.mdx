All Navisworks models published to Speckle have one of two types of structures, depending on the **preserve hierarchy** publish setting used.
By default, model objects are published in a flattened hierarchy, which ignores the position of the object in the Navisworks selection tree.
Turning the **preserve hierarchy** setting on will result in a model with collections created according to the selection tree structure.

```mdx
**Navisworks Model Structure: default setting**

```text
📁 Root Collection
├── 📁 Navisworks File 
│   └── 📄 Navisworks Object
└── Proxies: Render Materials

```mdx
**Navisworks Model Structure: preserve hierarchy setting**

```text
📁 Root Collection
├── 📁 Navisworks File 
│   └── 📁 Selection Tree Item
│       └── 📁 Nested Selection Tree Item
│           └── 📄 Navisworks Object
└── Proxies: Render Materials

## The Navisworks Object

<Info>
The Speckle `NavisworksObject` represents the **first selectable ancestor** `Navisworks.ModelItem` object in Navisworks
</Info>

The Navisworks object inherits from the [DataObject](../schemas/dataobject) class, with the following schema:

```JSON
{
  "__comment": "these fields are specified on the Base class",
  "id": string,
  "speckle_type": "Objects.Data.DataObject:Objects.Data.NavisworksObject",
  "applicationId": string,
  
  "__comment": "these fields are specified on the DataObject",
  "name": string,
  "properties": {
    string : value
  },
  "displayValue": [
    Base
  ],

  "__comment": "these fields are specified on the NavisworksObject",
  "units": string
}
```
