## The Tekla Object

<Info>
The Speckle `TeklaObject` represents an **element** in Tekla.
</Info>

The Tekla object inherits from the [DataObject](../schemas/dataobject) class, with the following schema:

```JSON
{
  "__comment": "these fields are specified on the Base class",
  "id": string,
  "speckle_type": "Objects.Data.DataObject:Objects.Data.TeklaObject",
  "applicationId": string,
  
  "__comment": "these fields are specified on the DataObject",
  "name": string,
  "properties": {
    string : value
  },
  "displayValue": [
    Base
  ],

  "__comment": "these fields are specified on the TeklaObject",
  "type": string,
  "elements": [
    TeklaObject
  ],
  "units": string
}
```
