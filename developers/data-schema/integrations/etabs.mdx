All Etabs models published to Speckle are structured by collections representing the File, Level, and Design Orientation of each Etabs element.

```mdx
**Etabs Model Structure**

```text
📁 Root Collection
├── 📁 Etabs File
│   └── 📁 Level
│       └── 📁 Design Orientation
│           └── 📄 Etabs Object
├── Proxies: Sections
├── Proxies: Materials
└── Info: Analysis Results

## The Etabs Object

<Info>
The Speckle `EtabsObject` represents an **element** in Etabs.
</Info>

The Etabs object inherits from the [DataObject](../schemas/dataobject) class, with the following schema:

```JSON
{
  "__comment": "these fields are specified on the Base class",
  "id": string,
  "speckle_type": "Objects.Data.DataObject:Objects.Data.EtabsObject",
  "applicationId": string,
  
  "__comment": "these fields are specified on the DataObject",
  "name": string,
  "properties": {
    string : value
  },
  "displayValue": [
    Base
  ],

  "__comment": "these fields are specified on the EtabsObject",
  "type": string
  "elements": [
    EtabsObject
  ],
  "units": string
}
```

### Etabs Object Properties

Etabs object properties include:
- Assignments, such as material, section, and property modifiers
- Geometry properties
- Object ID properties, such as label and level

## Proxies

Proxies found on the root collection of an Etabs model:
- [Render Materials](../schemas/proxy)
- Sections
- Materials. Material proxy object ids point to section proxies.

## Additional Info Fields

Etabs models can also include:
- **Analysis results**: base and joint reactions, frame and story forces, and story drifts.
