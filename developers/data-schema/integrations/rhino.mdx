All Rhino models published to Speckle have this structure:

```mdx
**Rhino Model Structure**

```text
📁 Root Collection
├── 📁 Rhino File 
│   └── 📁 Layer
│       └── 📁 Sublayer
│           ├── 📄 Geometry
│           └── 📄 Instance
├── Proxies: Render Materials
├── Proxies: Colors
├── Proxies: Groups
├── Proxies: Instance Definitions
└── Info: Views

## Geometry and Instance Properties

Geometries and Instances published from Rhino can also have a properties field dynamically attached.
Properties include:
- User Strings
- User Dictionaries

## Proxies

Proxies found on the root collection of a Rhino model:
- [Render Materials](../schemas/proxy)
- [Colors](../schemas/proxy)
- [Groups](../schemas/proxy)
- [Instance Definitions](../schemas/proxy)

## Additional Info Fields

Rhino models can also include:
- **Views**: a list of `Camera` class objects from **named perspective views** in the file that the Rhino model is published from.
