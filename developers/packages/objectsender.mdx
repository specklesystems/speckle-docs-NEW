## Overview

`@speckle/objectsender` is a JavaScript/TypeScript package for sending Speckle objects to Speckle Server. It serializes an object graph, uploads it to a project, and returns the id of its root object. You then create a version that points at that id.

**Package:** [@speckle/objectsender on npm](https://www.npmjs.com/package/@speckle/objectsender)

Creating the version returns a reserved id, not a version you can read yet. Wait for the
conversion to finish before you query or link it; see [Publish through model
ingestions](/developers/migration/publish-through-ingestions). A server without legacy-send support
rejects object-graph publishes with `LEGACY_SEND_UNSUPPORTED`. Consumers read the converted version
as a bundle.

## Installation

```bash
npm install @speckle/objectsender
```

## Quick Start

```typescript
import { send, Base } from '@speckle/objectsender'

const { hash } = await send(new Base({ name: 'My object' }), {
  serverUrl: 'https://app.speckle.systems',
  projectId,
  token
})
```

Then create a version on a model with the returned `hash` as its `objectId`, through the
`versionMutations.create` GraphQL mutation:

```graphql
mutation CreateVersion($input: CreateVersionInput!) {
  versionMutations {
    create(input: $input) {
      id
    }
  }
}
```

```json Variables
{
  "input": {
    "projectId": "<projectId>",
    "modelId": "<modelId>",
    "objectId": "<hash>",
    "message": "Sent from my app"
  }
}
```

## Features

- Send objects to Speckle Server
- Handle object serialization
- Detach and chunk large properties with the `Detach` and `Chunkable` decorators
- Support for large object hierarchies
