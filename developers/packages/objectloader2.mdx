## Overview

`@speckle/objectloader2` is a JavaScript/TypeScript package for loading and traversing Speckle objects. It provides utilities for working with Speckle's object-based data model in web and Node.js applications.

**Package:** [@speckle/objectloader2 on npm](https://www.npmjs.com/package/@speckle/objectloader2)

<Warning>
  This package reads object graphs, so a 2026.9 bundle version is not loadable through it — the
  objects endpoints return 404. Start from [Building applications in
  2026.9](/next/developers/building-applications) for the load path to move to.
</Warning>

<Note>
  Compatibility mode keeps a workspace's versions in the object-graph format until it ends on **1
  November 2026**. See [Compatibility mode](/next/it-admin/compatibility-mode).
</Note>

## Installation

```bash
npm install @speckle/objectloader2
```

## Quick Start

Loaders are built through `ObjectLoader2Factory`, not constructed directly.

```typescript
import { ObjectLoader2Factory } from '@speckle/objectloader2'

const loader = ObjectLoader2Factory.createFromUrl({
  serverUrl: 'https://app.speckle.systems',
  streamId: projectId,
  objectId,
  token
})

const root = await loader.getRootObject()

for await (const object of loader.getObjectIterator()) {
  // every object in the graph, root first
}

await loader.disposeAsync()
```

`createFromObjects(objects)` and `createFromJSON(json)` build a loader over objects you
already hold, with `objects[0]` as the root.

## Features

- Load Speckle objects by ID
- Traverse object hierarchies
- Construct complete object graphs
- Support for references and proxies
