title: "Preview Service"
description: "Generate preview images for Speckle models and versions"
---

The preview service generates image previews for Speckle models and versions. Previews are generated asynchronously and cached.

## Endpoints

All preview endpoints return image files (PNG). If no preview exists, a placeholder image is returned.

<Note>
The API endpoints use legacy parameter names (`streamId`, `branchName`, `commitId`) in the URL path for backward compatibility. These correspond to project ID, model name, and version ID in modern Speckle terminology.
</Note>

### Get Project Preview

Returns preview for the latest version in a project.

```bash
GET /preview/{streamId}/{angle?}
```

**Parameters:**
- `streamId` (required): Project ID (legacy parameter name)
- `angle` (optional): View angle (e.g., `iso`, `top`, `front`)

**Example:**
```bash
curl https://YOUR_SERVER_URL/preview/abc123
```

### Get Model Preview

Returns preview for the latest version in a model.

```bash
GET /preview/{streamId}/branches/{branchName}/{angle?}
```

Conceptually equivalent to: `GET /preview/{projectId}/branches/{modelName}/{angle?}`

**Parameters:**
- `streamId` (required): Project ID (legacy parameter name)
- `branchName` (required): Model name (legacy parameter name)
- `angle` (optional): View angle

**Example:**
```bash
curl https://YOUR_SERVER_URL/preview/abc123/branches/main
```

### Get Version Preview

Returns preview for a specific version.

```bash
GET /preview/{streamId}/commits/{commitId}/{angle?}
```

**Parameters:**
- `streamId` (required): Project ID (legacy parameter name)
- `commitId` (required): Version ID (legacy parameter name)
- `angle` (optional): View angle

**Example:**
```bash
curl https://YOUR_SERVER_URL/preview/abc123/commits/def456
```

### Get Object Preview

Returns preview for a specific object.

```bash
GET /preview/{streamId}/objects/{objectId}/{angle?}
```

**Parameters:**
- `streamId` (required): Project ID (legacy parameter name)
- `objectId` (required): Object ID
- `angle` (optional): View angle

**Example:**
```bash
curl https://YOUR_SERVER_URL/preview/abc123/objects/ghi789
```

## Authentication

Preview endpoints respect project permissions. Include authentication token if accessing private projects:

```bash
Authorization: Bearer YOUR_TOKEN
```

## Self-Hosted Setup

For self-hosted instances, the preview service must be running and connected to your server.

The service reads jobs from a Redis queue and generates previews using Puppeteer. Configure the preview service with:

- Redis connection for job queue
- Database connection to access object data
- Server URL for fetching objects

See server deployment documentation for setup details.

## Speckle Cloud

For models hosted on Speckle Cloud (app.speckle.systems), the preview service is already configured and available. No additional setup required.

<Note>
The API endpoints are identical between the open source core and Speckle Cloud. The internal implementation includes additional features like multi-region blob storage support, but the API interface remains the same.
</Note>
