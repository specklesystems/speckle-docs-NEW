## What this is

Preview service makes image previews for projects, models, versions, and objects. Returns PNG files. If preview not ready, returns placeholder image.

## When to use it

Use when you need preview images in your app. Previews generate in background. Cached after first generation.

## When not to use it

Do not use for real-time rendering. Previews are static images. Do not use if you need interactive 3D views.

## The simplest working example

Get preview for latest version in a project:

```bash
curl https://YOUR_SERVER_URL/preview/abc123
```

Returns PNG image. Replace `abc123` with your project ID.

## Notes for real projects

### Endpoints

All endpoints return PNG images. If preview missing, placeholder image returned.

URLs use old names (`streamId`, `branchName`, `commitId`) for backward compatibility. These mean project ID, model name, and version ID.

### Get project preview

Latest version in project:

```bash
GET /preview/{streamId}/{angle?}
```

- `streamId`: Project ID (required)
- `angle`: View angle like `iso`, `top`, `front` (optional)

```bash
curl https://YOUR_SERVER_URL/preview/abc123
```

### Get model preview

Latest version in specific model:

```bash
GET /preview/{streamId}/branches/{branchName}/{angle?}
```

- `streamId`: Project ID (required)
- `branchName`: Model name (required)
- `angle`: View angle (optional)

```bash
curl https://YOUR_SERVER_URL/preview/abc123/branches/main
```

### Get version preview

Specific version:

```bash
GET /preview/{streamId}/commits/{commitId}/{angle?}
```

- `streamId`: Project ID (required)
- `commitId`: Version ID (required)
- `angle`: View angle (optional)

```bash
curl https://YOUR_SERVER_URL/preview/abc123/commits/def456
```

### Get object preview

Specific object:

```bash
GET /preview/{streamId}/objects/{objectId}/{angle?}
```

- `streamId`: Project ID (required)
- `objectId`: Object ID (required)
- `angle`: View angle (optional)

```bash
curl https://YOUR_SERVER_URL/preview/abc123/objects/ghi789
```

### Authentication

Private projects need auth token:

```bash
curl -H "Authorization: Bearer YOUR_TOKEN" https://YOUR_SERVER_URL/preview/abc123
```

Public projects work without token.

### Self-hosted setup

Preview service must run separately. Needs:

- Redis for job queue
- Database connection
- Server URL for fetching objects

Service reads jobs from Redis. Generates previews with Puppeteer. Caches results.

See server deployment docs for setup.

### Speckle Cloud

Speckle Cloud (app.speckle.systems) has preview service running. No setup needed. API same as self-hosted.
