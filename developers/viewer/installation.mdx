title: Installation
---

<Note>
  The published package renders object graphs, the format of versions published before 2026.9. To
  render bundle versions too, add the [bundle bridge](/developers/viewer/loading-bundles): sample
  code you copy into your app, with no other package to install.
</Note>

The viewer library is available on [npm](https://www.npmjs.com/package/@speckle/viewer) and you can install it in your project with

```bash
npm install --save @speckle/viewer
```
