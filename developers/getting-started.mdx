## New to Speckle Development?

If you're just getting started, we recommend this learning path:

<Steps>
  <Step title="Understand the data model">
    Start with the [Object model](/developers/object-model/overview) to understand how Speckle
    structures data
  </Step>
  <Step title="Set up authentication">
    Learn how to create and use [Personal Access Tokens](/developers/authentication/introduction)
    for API access
  </Step>
  <Step title="Learn the API">
    Explore the [GraphQL API](/developers/api/graphql) to understand how to interact with Speckle
    Server
  </Step>
  <Step title="Choose your tool">Pick the right tool for your use case (see options below)</Step>
  <Step title="Follow the quickstart">
    Each section has a quickstart guide to get you up and running in minutes
  </Step>
</Steps>
