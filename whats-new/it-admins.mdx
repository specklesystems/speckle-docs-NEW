Two deadlines fall on **1 November 2026**: the connector upgrade window closes, and compatibility
mode ends for every workspace. Both come with Speckle 2026.9, which introduced a new data format
for models. Connector installation, SSO, firewall rules, ACC and ProjectWise enablement, and [roles
and permissions](/workspaces/roles-and-seats) are unchanged. Each item links to the page that
documents it.

## New

- **Compatibility mode.** Speckle can keep a workspace's ACC and other cloud syncs, and its file
  uploads, in the previous data format while you update downstream tools. It is not self-serve, and it ends for
  every workspace on **1 November 2026**. See [Compatibility mode](/it-admin/compatibility-mode).
- **AI features switch.** Workspace admins can turn Speckle Intelligence off for a whole workspace
  from **Settings → General → AI features**. See [IT setup guide](/it-admin/setup#turn-ai-features-off-for-the-workspace).
- **AI Rules.** Workspace admins set standing instructions, such as a reporting currency or
  language, that Speckle Intelligence follows in every conversation. See [AI
  Rules](/analytics/intelligence-rules).
- **Usage.** Workspace admins see activity, plan limits, and AI spend under **Settings → Usage**.
  See [Usage](/workspaces/usage).
- **Trimble Connect sync (beta).** A workspace admin connects a dedicated Trimble account as the
  workspace's service account, then members pick files to sync. Available on the **Enterprise**
  plan. See [Sync models from Trimble Connect](/connectors/cloud-integrations/trimble-connect).

## Changed

- **Connector upgrade window.** The window is open until **1 November 2026**. Upgrade before then:
  connectors from 2026.8 or earlier cannot load versions published by 2026.9 connectors, and Speckle
  does not guarantee older connectors after the window closes. Models already published stay
  readable. See [Upgrade window for 2026.9](/it-admin/connector-updates#upgrade-window-for-2026-9).
- **Navisworks.** There is no 2026.9 Navisworks connector, and 2026.8 is the last one, so leave
  Navisworks out of the rollout. The 2026.8 connector is deprecated: move teams to NWC and NWD
  uploads (up to 2 GB). See
  [Navisworks](/connectors/navisworks).
- **Upload formats.** The default upload path no longer accepts STL, 3MF, 3DS, AMF, DXF, X, E57,
  IGS/IGES, FBX, PLY, or SLDPRT files; they upload only in compatibility mode. MicroStation,
  Vectorworks, and Solibri files now upload. See [Direct
  uploads](/connectors/direct-uploads/introduction).
- **Browser requirement.** The 3D viewer needs WebGPU, and models do not open in Firefox on macOS.
  Standardise on Chrome, Edge, or Safari. See [3D viewer](/3d-viewer/introduction).
- **Workspace settings.** **General** holds the **AI features** switch, **Plan & billing** adds
  **Usage**, and a new **AI** section holds **Rules**, **Skills**, and **Conversations**. See [Workspace configuration](/workspaces/configuration).
- **Self-hosted servers.** The open-source Speckle Server does not support 2026.9, and 2026.9
  connectors do not work against it. See [Data model migration for
  developers](/developers/migration/data-model-migration).

## Action required

- **Finish connector updates by 1 November 2026.** Pilot with a small group, then move every host
  application except Navisworks to one connector version. See [Keep connectors
  current](/it-admin/connector-updates).
- **Request compatibility mode now, if you need it.** Request it only when cloud syncs or file
  uploads feed a script, report, or tool that still needs the previous data format. Update that tool
  before **1 November 2026**. See [Compatibility mode](/it-admin/compatibility-mode).
- **Move uploads off the removed formats.** The removed formats upload only in a workspace with
  compatibility mode, and not at all after **1 November 2026**. From that date, ACC sync and uploads
  write the 2026.9 format. See [Direct uploads](/connectors/direct-uploads/introduction).
- **Keep open-source servers on 2026.8 connectors.** If you run the open-source server, pin
  connectors to 2026.8 or earlier. On Speckle Enterprise Server, plan your move to 2026.9 with your
  infrastructure support contact. See [Data model migration for
  developers](/developers/migration/data-model-migration).
