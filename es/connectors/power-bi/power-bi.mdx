## Cargando un modelo

<Steps>

    <Step title="Cargar desde Speckle">1. Copie la URL del modelo desde la aplicación web.
2. Péguela en el campo de texto y seleccione **Aceptar**.
</Step>

    <Step title="Importar Visual 3D">1. En el panel Visualizaciones, seleccione los tres puntos **(...),** y luego **Importar un objeto visual desde un archivo**.

2. Navegue hasta `Documentos/Power BI Desktop/Objetos visuales personalizados`.

3. Seleccione `Speckle 3D Visual.pbiviz` y **Ábralo**.
</Step>

    <Step title="Visualiza un modelo">1. En el panel **Visualizaciones**, seleccione **Visualización 3D Speckle**.
2. Configure la visualización:

- Arrastre la columna *Información del modelo* al campo **Información del modelo** (necesario para la **visualización**).

- Arrastre la columna *IDs de objeto* al campo **IDs de objeto** (necesario para la **interactividad**).

- Arrastre cualquier columna al campo **Información sobre herramientas** (para la **información sobre herramientas**).

- Arrastre cualquier columna al campo **Color por** (para **colorear** el modelo).

3. Espere a que el modelo se cargue en el visor.</Step>

</Steps>

- Versión de escritorio (.exe): Ve a %LocalAppData%\Microsoft\Power BI Desktop (normalmente C:\Usuarios\[tu nombre de usuario]\AppData\Local\Microsoft\Power BI Desktop)

- Carpeta CEF

- Carpeta WebView2

- Carpeta Cache

- Archivo User.zip

4. Reinicia Power BI Desktop.

Este proceso borrará todos los datos en caché de Power BI Desktop, no solo los de la autenticación Speckle. Es posible que también necesites volver a autenticarte con otras fuentes de datos.

<AccordionGroup>
    <Accordion title="¿Por qué recibo el error &quot;No se puede conectar al servicio de escritorio&quot;?">Este error se produce por una de dos razones:

- El servicio de escritorio no se está ejecutando. Consulta [¿Cómo puedo comprobar si el servicio de escritorio se está ejecutando?](#how-do-i-check-if-desktop-service-is-running) para verificarlo y reiniciarlo.

- La caché de tokens ha caducado. Sigue estos pasos para borrar la caché:

1. Ve a **Archivo** > **Opciones y configuración** > **Configuración del origen de datos**.

2. Selecciona **https://app.speckle.systems/** o la URL de tu servidor.

3. Selecciona **Borrar permisos**.

4. Ve a **%APPDATA%/Speckle/Projects**.

5. Elimina los archivos **PowerBITokenCache.db**.

6. Reinicia Power BI e inténtalo de nuevo.</Accordion>

    <Accordion title="¿Cómo puedo comprobar si el servicio de escritorio está en ejecución?">1. Abre el **Administrador de tareas**.

2. Busca **Speckle.Desktop.Services**.

3. Si el proceso aparece en la lista, se está ejecutando.

4. Si el proceso no aparece:

- Selecciona **Ejecutar nueva tarea**.

- Introduce esta ruta: **%APPDATA%\Speckle\Desktop Services\Speckle.Desktop.Services.exe**

- Selecciona **Aceptar**.

El proceso Speckle.Desktop.Services debería estar ejecutándose ahora.</Accordion>

    <Accordion title="¿Por qué recibo el error &quot;No se puede conectar con el servidor remoto&quot;?">El conector de Power BI necesita que Speckle Desktop Service se ejecute en su equipo. Asegúrese de que Desktop Service esté activo y en ejecución.</Accordion>

## Compartir informes

Puedes compartir tus informes de Power BI con modelos de Speckle de dos maneras:

- **Compartir el archivo de Power BI directamente**: Puede compartir el archivo .pbix con sus colegas, quienes podrán abrir y ver el informe, incluida la visualización del modelo 3D. Sin embargo, podrían encontrar limitaciones al intentar editar consultas o actualizar datos, ya que estas operaciones requieren permisos de acceso y el servicio Speckle Desktop.

- **Publicar en Power BI Service**: Puede publicar su informe en Power BI Web, lo que permite que otros usuarios accedan a él a través de la plataforma en línea, donde pueden ver el informe publicado e interactuar con la visualización 3D. Si se ha configurado una puerta de enlace de datos, el conector Speckle y la visualización 3D admiten la actualización programada, lo que garantiza que sus informes reflejen datos actualizados.

## Configuración de la puerta de enlace de datos

Para los informes de producción que requieren una actualización programada, deberá configurar una puerta de enlace de datos. Esto permite que sus informes de Power BI se actualicen automáticamente con los datos más recientes de Speckle sin intervención manual.

[**Configurar la puerta de enlace de datos →**](/connectors/power-bi/gateway)

<Note>
Las puertas de enlace de datos solo son necesarias para la actualización programada en Power BI Service. Para el uso básico del conector y la visualización 3D, no se necesita una puerta de enlace.
</Note>

## Funciones auxiliares

Hemos añadido una serie de funciones auxiliares al espacio de nombres `Speckle` para que trabajar con datos de Speckle en Power BI sea más eficiente y fácil de usar.

### `Speckle.Projects.Issues`

Obtener incidencias de un proyecto, modelo o versión determinados. <br/>

```powerquery
Speckle.Projects.Issues(url as text, getReplies as bool)
```
Returns a table with the following columns:
- `Id`
- `Title`
- `Description`
- `Status`
- `Priority`
- `Assignee`
- `Due Date`
- `Created`
- `Updated`
- `Labels`
- `Replies`
- `URL`

Esta función acepta una URL que contiene las URL del proyecto, el modelo y la versión. <br/>
Opcionalmente, puede proporcionar `getReplies` para extraer las respuestas.

**Uso:**<br/>

- **Obtener incidencias de un proyecto** -> `Speckle.Projects.Issues("https://app.speckle.systems/projects/PROJECT_ID/")`
- **Obtener incidencias de un modelo** -> `Speckle.Projects.Issues("https://app.speckle.systems/projects/PROJECT_ID/models/MODEL_ID/")`
- **Obtener incidencias de una versión** -> `Speckle.Projects.Issues("https://app.speckle.systems/projects/PROJECT_ID/models/MODEL_ID@VERSION_ID/")`
- **Obtener incidencias con respuestas** -> `Speckle.Projects.Issues("https://app.speckle.systems/projects/PROJECT_ID/", true)`

### `Speckle.Objects.Properties`

Acceda rápidamente a las propiedades de un objeto sin navegar por la estructura anidada. <br/>

```powerquery
Speckle.Objects.Properties(inputRecord as record, optional filterKeys as list)
```

Devuelve un registro que contiene las propiedades y sus valores del `inputRecord` proporcionado.

Opcionalmente, puede proporcionar `filterKeys` para extraer solo propiedades específicas.

**Uso:**<br/>

- **Extrayendo todas las propiedades** -> `Speckle.Objects.Properties([data])`
- **Extrayendo propiedades específicas:** -> `Speckle.Objects.Properties([data], {"Name", "Number", "Area"})`

<Expandable title="Example">
This function works with individual records, and can be used when adding custom columns:

1. Ve a **Agregar columna** > **Columna personalizada**
2. Asigna un nombre a tu nueva columna (por ejemplo, "**Propiedades del objeto**")
3. Llama a la función auxiliar: `Speckle.Objects.Properties([data])`
4. Se agregará una nueva columna con las propiedades del objeto de registro

</Expandable>

### `Speckle.Objects.CompositeStructure`

Extrae la estructura compuesta de objetos como paredes, suelos, techos o cualquier elemento con estructura en capas.

<Note>
Actualmente solo es compatible con modelos de **Revit** y **Archicad**.
</Note>

```powerquery
Speckle.Objects.CompositeStructure(inputRecord as record, optional outputAsList as nullable logical)
```

_Por defecto_, devuelve un registro que contiene la estructura compuesta.

_Opcionalmente_, configure `outputAsList` en `true` para devolverlo como una lista; esto resulta útil para expandir cada capa en una fila independiente.

**Uso:**<br/>

- **Extrayendo la estructura compuesta** -> `Speckle.Objects.CompositeStructure([data])`
- **Extrayendo la estructura compuesta como una lista** -> `Speckle.Objects.CompositeStructure([data], true)`

<Expandable title="Example">
This function works with individual records, and can be used when adding custom columns:

1. Ve a **Agregar columna** > **Columna personalizada**.
2. Asigna un nombre a tu nueva columna (por ejemplo, "**Estructura compuesta**").
3. Llama a la función auxiliar: `Speckle.Objects.CompositeStructure([data], true)`.
4. Se agregará una nueva columna con la estructura compuesta del objeto de registro.

</Expandable>

_Opcionalmente_, configure `outputAsList` en `true` para devolver las cantidades como una lista, lo cual resulta útil para la expansión de filas.

**Uso:**<br/>

- **Extrayendo cantidades de material** -> `Speckle.Objects.MaterialQuantities([data])`
- **Extrayendo cantidades de material como una lista** -> `Speckle.Objects.MaterialQuantities([data], true)`

<Expandable title="Example">
This function works with individual records, and can be used when adding custom columns:

1. Ve a **Agregar columna** > **Columna personalizada**
2. Asigna un nombre a tu nueva columna (por ejemplo, "**Cantidades de material**")
3. Llama a la función auxiliar: `Speckle.Objects.MaterialQuantities([data], true)`

### `Speckle.Models.MaterialQuantities`

Toma una tabla y extrae las cantidades de material para todos los objetos, expandiéndolas en columnas separadas.

```powerquery
Speckle.Models.MaterialQuantities(inputTable as table, optional addPrefix as logical)
```

_Devuelve_ una tabla con columnas de cantidades de material añadidas. <br/> _Opcionalmente_, establezca `addPrefix` en `true` para crear columnas con prefijos como "MQ.materialName" o "MQ.area".

**Ejemplos:**<br/>

- **Uso básico:** `Speckle.Models.MaterialQuantities(Source)` - Crea columnas como "materialName" y "area".
- **Con prefijo:** `Speckle.Models.MaterialQuantities(Source, true)` - Crea columnas como "MQ.materialName" y "MQ.area".

<Expandable title="Example">
This function works with tables and can be used in Power Query:

1. Seleccione el icono fx en la barra de fórmulas.
2. En la barra de fórmulas, llame a la función: `= Speckle.Models.MaterialQuantities(Source)` (Reemplace `Source` con el nombre de su tabla).
3. Se agregará un nuevo paso y se creará una nueva tabla con las cantidades de material expandidas en columnas separadas.

</Expandable>

### `Speckle.Models.Federate`

Federa manualmente los modelos cargados en Power BI para su uso en visualizaciones 3D.

```powerquery
Speckle.Models.Federate(tables as list, optional excludeData as logical)
```

Acepta una lista de tablas (cada una representa un modelo cargado desde Speckle) y devuelve una tabla federada para su uso en la visualización 3D.

Opcionalmente, utilice `excludeData = true` para federar solo los metadatos necesarios para la visualización 3D sin incluir todos los datos.

**Uso:**<br/>

- **Federación de múltiples modelos** -> `Speckle.Models.Federate({Model1, Model2, Model3})`
- **Federación solo con metadatos** -> `Speckle.Models.Federate({Model1, Model2, Model3}, true)`

<Expandable title="Example">
This function works with multiple tables and can be used in Power Query:

1. Vaya a **Inicio** > **Obtener datos** > **Consulta en blanco**
2. En la barra de fórmulas, llame a la función: `= Speckle.Models.Federate({Model1, Model2})`
3. Reemplace `Model1` y `Model2` con los nombres reales de sus tablas de modelos.
4. Se creará una nueva tabla federada que combinará todos los modelos especificados.

</Expandable>

### `Speckle.Utils.ExpandRecord`

Esta función expande una columna de registro en columnas separadas para cada campo. Es especialmente útil en combinación con la función auxiliar `Properties`.

```powerquery
Speckle.Utils.ExpandRecord(table as table, columnName as text, optional FieldNames as list, optional UseCombinedNames as logical)
```

Opcionalmente, utilice `FieldNames` para limitar los campos expandidos.

Opcionalmente, utilice `UseCombinedNames = true` para anteponer a los nombres de las columnas el nombre de la columna del registro (por ejemplo, `Properties.Length`).

**Uso:**<br/>

- **Expandir columna de registro de propiedades** <br/>

`Speckle.Utils.ExpandRecord(Source, "properties")` -> Todas las propiedades se expandirán en columnas separadas.
- **Expandir subconjunto de campos** <br/>

`Speckle.Utils.ExpandRecord(Source, "properties", {"Length", "Width"})` -> Solo los campos Longitud y Ancho tendrán columnas separadas.
- **Expandir columnas de registro con nombres combinados** <br/>

`Speckle.Utils.ExpandRecord(Source, "properties", {"Length", "Width"}, true)` -> Los campos Longitud y Ancho tendrán columnas separadas con el nombre de la columna de registro como prefijo (p. ej., `Properties.Length`, `Properties.Width`).

<Expandable title="Example">
This function works with tables and can be used in Power Query:

1. Seleccione el icono fx en la barra de fórmulas.
2. En la barra de fórmulas, llame a la función: `= Speckle.Utils.ExpandRecord(Source, "properties")` (Reemplace `Source` con el nombre real de su tabla).
3. Se agregará un nuevo paso y se creará una nueva tabla con el registro de propiedades expandido en columnas separadas.

<Note>
Esta función funciona con cualquier columna del registro, no solo con las propiedades.
</Note>
</Expandable>
