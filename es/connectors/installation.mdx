---
title: "Instalación de conectores"
description: "Descarga e instala un conector Speckle."
---

<Info>Connectors are currently available for **Windows only**.</Info>

<Steps>
  <Step title="Crea una cuenta de Speckle">Ve a [speckle.systems](https://app.speckle.systems/) y crea una cuenta.</Step>

  <Step title="Descarga el conector">1. Acceda a [app.speckle.systems/connectors](https://app.speckle.systems/connectors).

2. Descargue el conector para su software, como Revit, Rhino o Archicad. [Consulte todo el software compatible](https://www.speckle.systems/connectors).
</Step>

  <Step title="Instale el conector"><Advertencia>

Asegúrese de que el software de destino esté cerrado durante el proceso de instalación.

No utilice la opción **Ejecutar como administrador** para instalar. Esto impedirá la instalación del conector para su usuario.

</Advertencia>

1. Haga doble clic en el archivo `.exe` descargado o haga clic con el botón derecho y seleccione **Abrir** para ejecutar el instalador.

2. Siga las instrucciones en pantalla para completar la instalación.
</Step>
</Steps>
