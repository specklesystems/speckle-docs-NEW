## Trabajar con objetos Speckle para el seguimiento de cambios

Los parámetros de Grasshopper no tienen un GUID persistente (los parámetros de los modelos Grasshopper 8+ que obtienen objetos de un documento de Rhino sí tienen un GUID). Los nodos Speckle crean un nuevo GUID en cada resolución para cualquier parámetro que no tenga uno. Esto dificulta especialmente el seguimiento de cambios en los modelos Grasshopper.

- Para un seguimiento de cambios adecuado, al trabajar con modelos cargados, utilice los nodos de transferencia directa para modificar los objetos existentes si desea que los ID de la aplicación permanezcan iguales.

- Para un seguimiento de cambios adecuado, al publicar nuevos modelos, cree los objetos Speckle una sola vez, publíquelos y cárguelos para usar los nodos de transferencia directa. Repita este proceso cada vez que añada nuevos objetos a su modelo.

## Crea componentes de proyecto reutilizables con objetos de usuario de Grasshopper

Define conjuntos de componentes personalizados que reflejen los estándares y convenciones de entrega de tu proyecto cuando trabajes en equipo o colabores en varios proyectos. Guarda tus nodos de Speckle Grasshopper como objetos de usuario y compártelos con tu equipo para asegurarte de que sigan las convenciones de nomenclatura de capas, trabajen con conjuntos de propiedades predefinidos durante el análisis, etc.

**Cómo crear un objeto de usuario**

1. Personaliza tu nodo Speckle (o grupo de nodos) según las convenciones de tu proyecto.
2. Selecciona **Archivo** > **Crear objeto de usuario** en el menú de Grasshopper.

3. Completa todos los campos del formulario emergente para describir tu nodo de usuario y tu proyecto.

4. Haz clic en **Aceptar** para guardar el nodo.

5. Todos tus objetos de usuario se almacenan en un archivo `.ghuser`. Para compartir tus componentes reutilizables con otros, ve a **Archivo** > **Carpetas especiales** > **Carpeta de objetos de usuario** para localizar el archivo `.ghuser`.
