La residencia de datos implica almacenar sus datos en una ubicación geográfica específica para cumplir con las leyes y regulaciones locales.

## ¿Por qué importa la residencia de los datos?

Las distintas regiones tienen requisitos diferentes en cuanto al lugar donde se pueden almacenar los datos:

- El RGPD exige que los datos personales de los ciudadanos de la UE se protejan según las normas europeas, independientemente de dónde se almacenen o procesen.

- Algunas organizaciones gubernamentales en países como Australia deben mantener ciertos datos dentro de sus fronteras.

Al elegir dónde se almacenan sus datos, puede cumplir con estos requisitos y demostrar el cumplimiento normativo.

## ¿Cómo funciona la residencia de datos en Speckle?

Los espacios de trabajo de Speckle te permiten elegir dónde se almacenan tus datos, para que puedas cumplir con las normativas a la vez que mantienes el control total sobre ellos.

- Todos los espacios de trabajo se inician en la región predeterminada de Speckle.

- Los clientes del plan Enterprise pueden elegir una región diferente para su espacio de trabajo y así cumplir con sus requisitos de cumplimiento normativo.

- El complemento **Región de datos adicional** permite configurar la residencia de datos a nivel de proyecto para un control más preciso.

## Regiones disponibles

La residencia de datos está disponible en el plan Enterprise.

- Elija entre **UE**, **Reino Unido**, **Norteamérica** o **Asia Pacífico** como región predeterminada de su espacio de trabajo. Todos los datos de su proyecto se almacenarán en esta región.

- Para regiones más específicas y regiones para proyectos concretos, <a href="mailto:billing@specke.systems">
contáctenos</a>

- Si no especificas una región, tus datos se enviarán automáticamente a la región predeterminada de Speckle, optimizada para el rendimiento y la velocidad.
