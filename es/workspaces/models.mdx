Los modelos te ayudan a organizar tus datos dentro de un proyecto. Son útiles para dividir
diferentes partes de tu trabajo, como opciones de diseño, disciplinas o responsabilidades del equipo.
Un modelo puede tener una relación directa con un archivo de modelo 3D, o con una parte del mismo, o puede relacionarse
con varios archivos dentro de un mismo modelo. Los modelos funcionan mejor cuando se utilizan para representar
una parte específica de tu trabajo, el tema central de una conversación, un entregable específico
o una disciplina en particular; la elección es tuya.

## Creación de modelos

Un nuevo proyecto comienza sin modelos. Puedes crear un modelo vacío en la interfaz web o mediante un conector. Este modelo simplemente sirve como contenedor para tus datos; contendrá datos una vez que los publiques desde una herramienta de diseño compatible mediante un conector.

Puedes mantener todo en ese modelo o crear otros adicionales para explorar opciones de diseño, separar el trabajo por equipo o disciplina y organizar los componentes del proyecto con mayor claridad.

Los modelos te brindan la flexibilidad de estructurar tus datos para que se adapten a tu forma de trabajar.

## Gestión de modelos

Puedes crear tantos modelos como necesites dentro de un proyecto, respetando los límites de tu espacio de trabajo.

La aplicación web Speckle facilita la adición de nuevos modelos y el cambio entre ellos.

Los modelos pueden nombrarse para imitar una estructura de carpetas utilizando una barra inclinada `/` en el nombre, por ejemplo: `Edificio A/Plantas/Planta 1`.
