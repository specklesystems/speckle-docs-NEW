Los filtros permiten centrarse en partes específicas de los datos. Esta página abarca los niveles de filtro, los operadores y el comportamiento de las propiedades. Los widgets de gráficos y tablas controlan tanto los filtros a nivel de página como los filtros opcionales a nivel de widget.

- [Niveles de filtrado](#filter-levels) — Nivel de página vs. nivel de widget

- [Operadores y tipos de datos](#operators-and-data-types) — Operadores de texto, numéricos, de lista y especiales
- [Propiedades y el modelo de datos](#properties-and-the-data-model) — Propiedades anidadas, coerción de tipos y casos límite

### Filtros a nivel de página

Cuando se aplica un filtro desde un widget (por ejemplo, haciendo clic en un valor de un gráfico), este se convierte en un **filtro a nivel de página** que afecta a todos los widgets del panel de control.

- Se pueden activar varios filtros simultáneamente.
- Los filtros activos aparecen como iconos en la parte superior del panel; haz clic en la X de un icono para eliminarlo.
- Los widgets individuales pueden desactivar los filtros de página en su configuración.

### Filtros a nivel de widget

Muchos widgets tienen **filtros locales** que afectan solo a ese widget. Úselos para enfocar un solo widget en un subconjunto de datos sin modificar el resto del panel.

### Niveles de filtro

Los filtros a nivel de página (o a nivel de fuente de datos) afectan a los datos que se utilizan en todo el panel. Se aplican a todos los widgets, a menos que un widget desactive esta opción. Utilice los filtros a nivel de página cuando desee que todo el panel se centre en el mismo subconjunto (por ejemplo, una categoría, una planta).

Los filtros a nivel de widget solo afectan a los resultados que se muestran en ese widget. No modifican los datos que se envían a otros widgets ni al visor del modelo. Utilice filtros a nivel de widget cuando un gráfico o tabla deba mostrar una parte diferente de los mismos datos.

### Cómo interactúan los filtros a nivel de página

Al hacer clic en un valor de un gráfico o tabla, se agrega un **filtro a nivel de página** (que se muestra como un icono en la parte superior del panel). Cómo se combinan los filtros:

- **Dentro de un filtro (un chip)**: Si selecciona varios valores para la misma propiedad (p. ej., Categoría = Paredes y

Pisos), se combinan como **O**: se incluyen los objetos que coinciden con cualquiera de esos valores.

- **Entre filtros (varios chips)**: Cada chip es un filtro independiente (p. ej., uno para Categoría, otro para Nivel). Varios
chips se combinan como **Y**: solo se incluyen los objetos que coinciden con todos los filtros activos.

Ejemplo: un chip "Categoría: Paredes, Suelos" y un chip "Nivel: 01" juntos muestran solo los elementos que son (Paredes o Suelos) **y** están en el Nivel 01. Los filtros a nivel de widget se aplican además de los filtros a nivel de página solo para ese widget.

### Operadores y tipos de datos

El menú de **predicados** es el mismo en los **filtros del panel de control** y en las **reglas de validación** (Verificador de propiedades y Validación de modelos). Los predicados que aparecen dependen del tipo de propiedad (texto, número o booleano). Utilice la interfaz de usuario del filtro o de la regla para seleccionar primero una propiedad; no se ofrecen predicados no válidos para ese tipo.

#### Propiedades booleanas

Para propiedades booleanas, utilice **Es verdadero** o **Es falso**.

#### Coincide con el patrón

**Coincide con patrones** admite dos modos: coincidencia con **comodines** y coincidencia con **expresiones regulares**. En los archivos de reglas **TSV**, el mismo predicado se escribe como `is like` en la columna Predicado.

##### Modo comodín (predeterminado)

Utilice caracteres comodín al estilo SQL para la coincidencia de patrones simples:

- `%` — coincide con cualquier secuencia de caracteres (incluso sin ninguna)
- `_` — coincide con un solo carácter (cuando sea compatible)

Ejemplos:

- `door%` — coincide con "door_01", "door_a", "doorway"
- `%window%` — coincide con cualquier valor que contenga "window"
- `Wall%` — coincide con valores que comienzan con "Wall"

##### Modo de expresiones regulares

Envuelve tu patrón entre barras diagonales para usar la coincidencia completa de expresiones regulares:

- `/pattern/` — trata el contenido entre barras diagonales como una expresión regular

Ejemplos:

- `/^D\d{3}$/` — coincide con "D001" o "D123" (exactamente D seguida de tres dígitos)
- `/^(Wall|Door)/` — coincide con valores que comienzan con "Wall" o "Door"
- `/\d{4}-\d{2}-\d{2}/` — coincide con el formato de fecha "AAAA-MM-DD"

La coincidencia no distingue entre mayúsculas y minúsculas en ambos modos. Utilice la coincidencia de patrones cuando necesite hacer coincidir una familia de valores (por ejemplo, todas las puertas, todos los elementos de un nivel) sin tener que enumerarlos uno por uno.

<Note>
Para usar el modo de expresiones regulares, el valor del patrón debe comenzar y terminar con `/`. Sin las barras diagonales, el valor se trata como un patrón comodín con marcadores de posición `%` y `_`.
</Note>

### Referencia rápida por tipo de propiedad

- **Texto**: Existencia (**Existe**, **No existe**, **Tiene valor**), comparación (**Es igual a**, **No es igual a**, **Es uno de**, **No es uno de**) y texto (**Coincide con el patrón**, **Contiene**, **No contiene**)
- **Número**: **Existencia** (mismas etiquetas que el texto), **Comparación** (igualdad, opciones de lista, **Es mayor que**, **Es menor que**) y **Rango** (**Está entre**)
- **Booleano**: **Es verdadero**, **Es falso**

La interfaz de usuario solo muestra los predicados que se aplican al tipo de propiedad seleccionado.

### Propiedades y modelo de datos

**Propiedades anidadas**: Puede filtrar por campos anidados o calculados cuando el widget los exponga (por ejemplo, una ruta como `elemento.material.nombre`). Seleccione la propiedad en el menú desplegable de filtro del widget; la ruta exacta depende de cómo el modelo y el widget expongan las propiedades. Si una propiedad no existe en algunos objetos, estos se excluirán al aplicar el filtro.

**Coerción de tipos**: Los valores se comparan utilizando el tipo de propiedad. Si un número se almacena como cadena, el filtro puede tratarlo como texto (por ejemplo, **Contiene** o **Es igual a**). Para comparaciones numéricas (**Es mayor que**, **Es menor que**,
**Está entre**), el valor se interpreta como un número cuando es posible. Las propiedades booleanas utilizan **Es verdadero** y **Es falso**.

**Comparación de múltiples valores**: **Es uno de** y **No es uno de** permiten seleccionar varios valores para la misma propiedad.

Se aplican únicamente a esa propiedad. Añada varias reglas de filtro si necesita combinar condiciones entre diferentes propiedades.

<Note>
**Cuando el filtrado se convierte en reglas**: Si necesita reglas reutilizables, comprobaciones de aprobación/rechazo o conjuntos de reglas (por ejemplo, «todas las puertas deben tener una clasificación de resistencia al fuego»), utilice los widgets **Verificador de propiedades** o **Validación de modelos** y defina las reglas en el widget o en un conjunto de reglas. Para obtener información sobre la sintaxis de las reglas, los conjuntos de reglas y la validación automatizada, consulte la sección [Validación de datos](/analytics/data-validation/overview).
</Note>
