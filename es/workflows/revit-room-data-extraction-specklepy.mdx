En este flujo de trabajo, demostraremos cómo extraer datos de habitaciones de modelos de Revit utilizando el SDK de SpecklePy y convertirlos a un DataFrame de Pandas.

## Requisitos previos
Antes de comenzar, asegúrese de tener lo siguiente:
- Un modelo de Revit con datos de habitaciones.

- Envíe su modelo a Speckle usando el conector Speckle para Revit. (Aprenda cómo [aquí](https://docs.speckle.systems/connectors/revit/revit))
- El SDK de SpecklePy instalado en su entorno Python.

- La biblioteca Pandas para la manipulación de datos.

## Paso 1: Instalar SpecklePy SDK y Pandas
Puedes instalar las bibliotecas necesarias usando pip:

```bash 
pip install specklepy pandas
```

## Paso 2: Conéctate a Speckle
Primero, importa las bibliotecas necesarias y autentícate con Speckle.

```python

cliente.autenticar_con_token(SPECKLE_TOKEN)

path (list[str]): Lista ordenada de claves, por ejemplo:

""
