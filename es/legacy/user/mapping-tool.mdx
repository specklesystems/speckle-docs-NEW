<Note>
La herramienta de mapeo de moteado, disponible en algunos de nuestros conectores, permite un mayor control al enviar datos CAD a software BIM, ya que permite mapear geometría CAD simple a elementos BIM nativos.

Por ejemplo, permite recibir líneas de Rhino como vigas en Revit, entre otras funciones.

Actualmente, la herramienta de mapeo solo está disponible para flujos de trabajo Rhino > Revit; en el futuro se ampliará a otros como AutoCAD > Archicad o Civil 3D > Tekla, etc.
</Note>

## ¿Cómo funciona?

Esta función requiere disponer de ciertos datos, como familias, tipos, niveles, etc. El primer paso es enviarlos a Speckle desde la herramienta BIM.

A continuación, podrá asignarlos a los elementos compatibles desde la herramienta CAD. Finalmente, solo tendrá que enviar el elemento asignado desde la herramienta CAD a la herramienta BIM.

A continuación se detallan los pasos necesarios para un flujo de trabajo Rhino > Revit.

### Configuración de Revit

En Revit, crea o abre un documento con todos los niveles, familias y tipos que planeas usar.

Luego, envía a Speckle solo esos niveles, familias y tipos.

Recomendamos utilizar un modelo para esto y actualizarlo con el tiempo a medida que agregue más niveles y tipos.

### Configuración de Rhino

En Rhino, escriba el comando `SpeckleMappings`, esto abrirá un nuevo panel (Windows) o ventana (Mac) con la herramienta de mapeo.

<Frame>
  <img src="https://user-images.githubusercontent.com/2679513/203253776-f7899083-5e94-4264-8840-f4941f4b32e1.png" alt="Configuración de Rhino" />
</Frame>

Haz clic en `Seleccionar origen de mapeo` y selecciona el proyecto y el modelo con los datos de Revit que acabamos de enviar:

<Frame>
  <img src="https://user-images.githubusercontent.com/2679513/203254063-5cf9e507-ee22-4969-8613-696bb84b3f49.gif" alt="seleccionar-origen-de-mapeo" />
</Frame>

¡Ya estás listo para crear el mapa!

<Info>
  ☝️ <b>NOTE:</b> The available elements depend on the provided families and types. So, if your Revit document did not have any Beam types available, this option will not be available in the Mapping tool.
</Info>

### Mapeo de la geometría de Rhino a elementos de Revit

Tras seleccionar una fuente de mapeo, solo tiene que seleccionar elementos del modelo de tipos similares, configurar los mapeos y propiedades correspondientes y, a continuación, hacer clic en Aplicar.

<Frame>
  <img src="https://user-images.githubusercontent.com/2679513/203260126-d0136aeb-9ec4-4358-8868-fa4e7e02bbc3.gif" alt="cartografía" />
</Frame>

Finalmente, envíe estos objetos:

<Frame>
  <img src="https://user-images.githubusercontent.com/2679513/203260338-76ae8c08-365d-496f-93ee-802645269e9b.gif" alt="selección de mapeo" />

Y recíbalos en un proyecto de Revit que tenga los tipos y niveles necesarios:

### Mapeos compatibles Rhino > Revit

| Geometría de Rhino | Elemento de Revit |

| -------------- | -------------- |

| Extrusión | Muro |

| Malla | DirectShape |

| Malla | Topografía |

| Brep | DirectShape |

| Punto | Instancia de familia |

| Bloque | Instancia de familia |

| Superficie | Suelo |

| Línea | Viga |

| Línea | Arriostramiento |

| Línea | Tubería |

| Línea | Conducto |

| Línea | Columna |
