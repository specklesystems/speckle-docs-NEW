El Administrador de Speckle es la mejor manera de instalar y actualizar (casi) todos nuestros conectores en su ordenador, y si tiene más de una cuenta de Speckle, también podrá gestionarlas allí.

## Descargar

Manager está disponible para Windows y Mac (con algunas limitaciones).
Manager se actualiza automáticamente cuando hay nuevas versiones disponibles.

<Note>
¡El gestor no requiere privilegios de administrador! Simplemente haga doble clic y ejecútelo para instalarlo.
</Note>

Descarga Speckle Manager ahora:

- [🔽 Gestor de Speckle](https://specke.systems/download/)

## Iniciar sesión y agregar cuentas

<Note>
Ahora puedes iniciar sesión en tu(s) cuenta(s) de Speckle directamente desde nuestra aplicación principal, sin necesidad de tener instalado Manager.
</Note>

### Desde Speckle Manager

Una vez descargado el Administrador, podrás añadir una cuenta fácilmente. Solo tienes que ir al menú «Cuentas», hacer clic en el botón «Añadir cuenta» e introducir la URL de tu servidor. Se abrirá una ventana del navegador donde podrás iniciar sesión o registrar una cuenta en ese servidor y autorizar el Administrador de Speckle.

<Frame>
  ![Adding Account](https://user-images.githubusercontent.com/51519350/186378731-2e996b5f-6ef1-4560-b2dd-7e1c3ec5d3ea.png)
</Frame>

### Durante la incorporación

También puedes añadir una cuenta directamente desde Speckle Web como parte del proceso de incorporación que verás después de registrarte en un nuevo servidor.

### Agregar cuentas manualmente

Utilizar Manager para gestionar tus cuentas y [conectores](/#connectors) es la forma recomendada, pero si prefieres prescindir de él, también está disponible un flujo manual.

Para agregar una cuenta manualmente, primero debe generar un token para su cuenta.

A continuación, puede proceder a crear un archivo `.json` con la siguiente estructura de datos:

```json
{
  "token": "YOUR-TOKEN-HERE",
  "serverInfo": {
    "name": "Server Name",
    "company": "Company Name",
    "url": "https://YOUR-SERVE-URL-HERE"
  },
  "userInfo": {
    "id": "YOUR-USER-ID",
    "name": "First Last",
    "email": "firstlast@email.com"
  }
}
```

Coloca el archivo:
- En Windows, en: `%appdata%\Speckle\Accounts\`
- En Mac, en: `~/.config/Speckle/Accounts`
- En Linux, en `~/.local/share/Speckle/Accounts`

## Instalación de conectores

El administrador también muestra los conectores disponibles y permite instalarlos o desinstalarlos. Acceda al menú «Conectores» para ver los conectores instalados y los disponibles para descargar. Además, podrá consultar la versión de cada conector y actualizarla cuando se publiquen nuevas versiones.

## Configuración avanzada

Puedes acceder a la página de Configuración haciendo clic en el icono ⚙ situado en la parte superior derecha de la ventana de Speckle Manager.

<Frame>
  ![Advanced Settings](https://user-images.githubusercontent.com/51519350/186392111-fda4cbc4-1ed9-4153-a1e2-82e0198d9c40.png)

Desde aquí podrás realizar diversas acciones, como cambiar la posición predeterminada, borrar la caché local, permitir versiones beta, etc.

<Frame>
  ![Advanced Settings Page](https://user-images.githubusercontent.com/51519350/186392354-f04e2b63-0b8a-44af-9b0d-2ec7add92245.png)

### Reiniciando la caché local

La caché local se utiliza al enviar y recibir datos a Speckle para agilizar operaciones similares en el futuro. Si observa que su caché es demasiado grande, puede eliminarla desde aquí.

### Uso de versiones beta de Manager

Al activar esta opción, se habilitarán las versiones beta de Manager. Esto significa que cada vez que publiquemos una versión beta, también podrás instalarla.

Si experimentas problemas con Manager, es posible que te pidamos que la instales para probar una nueva versión.

### Instalación de versiones preliminares de nuestros conectores

Para instalar versiones preliminares de nuestros conectores, simplemente diríjase a la pestaña _versions_ dentro de un conector.

<Frame>
  ![Installing Beta](https://user-images.githubusercontent.com/51519350/186392925-1263b0d4-48e7-4724-be89-c5d0a01e3506.gif)
</Frame>

### Cambiar la dirección predeterminada del servidor Speckle

Puedes cambiar la dirección predeterminada del servidor Speckle de dos maneras:

- Añadiendo un archivo llamado `server` que contenga la URL del servidor en `%appdata%/Speckle/` (o la carpeta equivalente de Speckle en tu sistema).
- Añadiendo una variable de entorno `SPECKLE_SERVER` que contenga la URL del servidor.

## Desinstalación del administrador

En Windows, simplemente diríjase a **Aplicaciones y características**, busque **Manager for Speckle** y luego haga clic en **Desinstalar**.

  ![Uninstalling Manager](https://user-images.githubusercontent.com/2679513/182909714-1a7f4815-949c-4557-870e-05ede9550f0c.png)

## Impedir que el Administrador se ejecute al iniciar

En Windows, el Administrador se iniciará automáticamente al arrancar el sistema para comprobar si hay nuevas actualizaciones.

Si desea desactivar esta funcionalidad, simplemente puede hacerlo:

- Abre el Administrador de tareas, por ejemplo, con `Ctrl + Mayús + Esc`.
- Ve a la pestaña **Inicio**.
- Busca la fila que contiene **Manager.exe** y cambia su **Estado** a **Deshabilitado**.

<Frame>
  ![Disabling Startup](https://user-images.githubusercontent.com/2679513/182909877-e6e86778-7cb6-4c79-9a2e-687f49c9694f.png)
</Frame>

## Solución de problemas

¿Tienes problemas con Speckle Manager? Prueba las siguientes soluciones:

- ¿No puedes iniciar sesión en tu cuenta? Comprueba si el servidor de Speckle está bloqueado (https://speckle.guide/user/FAQs.html#the-speckle-server-is-unreachable). - ¿No ves ningún conector? Comprueba si la URL de los conectores está bloqueada (https://speckle.guide/user/FAQs.html#the-speckle-server-is-unreachable).

¿Sigues teniendo problemas? Ayúdanos a solucionarlos haciendo lo siguiente:

- Abre la página de Configuración ⚙
- Activa el registro
- Intenta reproducir el problema y copia y pega el texto del registro del conector
- ¡Envíanos un mensaje en el [foro](https://speckle.community)!
