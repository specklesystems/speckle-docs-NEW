Estas configuraciones generales para el elemento visual le brindan varias opciones para personalizar su apariencia, diseño, efectos y accesibilidad, lo que le permite adaptar la presentación del elemento visual y la experiencia del usuario en su informe de Power BI.

Estas configuraciones son comunes a todos los elementos visuales de Power BI. Por lo tanto, no explicaremos cada una de ellas. En su lugar, destacaremos únicamente aquellas que consideramos relacionadas con el Visor.

## Propiedades

- **Tamaño**: Ajusta las dimensiones del visor 3D.

- **Relleno**: Define el espacio entre el contenido del visor y sus límites exteriores.

## Título

- **Título**: Permite establecer un título para la visualización en el visor 3D. Por defecto, está desactivado.

- **Subtítulo**: Permite añadir una línea de texto adicional debajo del título. Puede utilizar el subtítulo para proporcionar más contexto o información complementaria relacionada con la visualización.

## Efectos

- **Fondo**: Permite establecer un color específico como fondo del visor 3D.

- **Borde visual**: Agrega un borde alrededor del visor 3D.
