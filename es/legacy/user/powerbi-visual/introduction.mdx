**Visualizador 3D** lleva el conector de Power BI a un nivel completamente nuevo. Con él, puedes dar vida a tus datos de Speckle visualizándolos en 3D directamente en tus informes de Power BI.

Es compatible con Power BI Desktop y también se puede usar en [PowerBI.com](http://powerbi.com/) para visualizaciones en línea.

## Características

Esta versión habilita funciones de visualización, filtrado y coloración, así como algunos controles básicos de cámara y color:

- Cargar objetos individuales obtenidos con el Conector de datos de Power BI.

- Resaltar objetos en el visor 3D seleccionados en una tabla diferente del informe.

- Colorear objetos según una categoría o valor.
- Mostrar información sobre herramientas definida por el usuario.
