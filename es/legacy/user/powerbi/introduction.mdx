La conexión de Speckle con Power BI consta de dos partes.

- Conector de datos de Power BI
- Visualizador 3D

Estas dos partes se complementan entre sí. Juntas, crean una sinergia que te permite aprovechar al máximo tus datos, haciendo que tus informes sean realmente inmersivos y atractivos.

# Conector de datos de Power BI

## Introducción

Speckle Connector para Power BI te permite incorporar fácilmente datos de Speckle a tus informes y visualizaciones de Power BI. Puedes acceder y analizar datos de estas aplicaciones sin complicaciones conectando Power BI con la amplia gama de integraciones de Speckle con aplicaciones AEC (como Revit, Archicad, Navisworks, Grasshopper, etc.).

<Warning>
Actualmente, Speckle Connector para Power BI solo es compatible con **Power BI Desktop**.
</Warning>

## Características

El conector de Power BI le permite importar los datos de su modelo, versión u objeto de Speckle mediante la URL correspondiente. Según el tipo de URL que utilice, se recuperarán los siguientes datos:

- **URL del modelo** -> la versión más reciente de este modelo
- **URL de la versión** -> esta versión
- **URL del objeto** -> este objeto
