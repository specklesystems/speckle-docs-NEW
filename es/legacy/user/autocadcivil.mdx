## Empezando

Para empezar, deberá instalar este conector y agregar su cuenta de Speckle. Siga nuestras instrucciones en [Speckle Manager](/legacy/user/manager) si aún no lo ha hecho.

Una vez instalado, encontrará este conector en la pestaña «Complementos», dentro de «Speckle 2». Al hacer clic en este botón, se abrirá la interfaz del conector Speckle, que muestra una lista de todos los proyectos que tiene actualmente en el modelo.

### Envío de datos

El conector de AutoCAD Civil3D admite el filtrado de selección por capa.

### Recepción de datos

La geometría de los proyectos se agregará a las capas de AutoCAD / Civil3D comenzando con un prefijo con el siguiente formato:

```
project[ model @ version id ]
```

Cualquier información de capa del proyecto entrante se agregará al prefijo con el delimitador estándar de AutoCAD `$`. Al recibir datos de aplicaciones (como Rhino) con capas anidadas, la ruta completa de la capa entrante reemplazará cualquier delimitador predeterminado con `$`.
