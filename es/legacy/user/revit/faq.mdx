<Accordion title="¿Puedo subir mis archivos de Revit a Speckle?">Speckle permite subir archivos en ciertos formatos, pero lamentablemente, debido a su naturaleza propietaria, no podemos admitir el formato de archivo de Revit (.rvt). Speckle es un proyecto de código abierto, por lo que deberá utilizar nuestros conectores para subir sus datos a nuestra plataforma.</Accordion>

<Accordion title="¿El conector de Revit admite materiales/texturas?">El conector de Revit admite materiales y estamos trabajando para que admita texturas próximamente. Por lo tanto, cuando publiques tus datos en Speckle, los materiales de Revit también se incluirán.</Accordion>

<Accordion title="¿Puedo enviar modelos vinculados desde Revit?">Sí, puedes. En **Configuración avanzada**, habilita la opción «**Enviar modelos vinculados**». Los modelos vinculados se incluirán al enviar tu modelo a Speckle. Consulta la sección [Modelos vinculados](https://speckle.community).</Accordion>

<Accordion title="¿El conector de Revit es compatible con el Editor de familias?">Sí. La geometría se puede enviar y recibir desde el entorno de Familia en Revit, con ciertas limitaciones.</Accordion>

<Accordion title="¿El conector de Revit admite opciones de diseño?">Sí. Para más detalles, consulta la página [Opciones de diseño](https://speckle.community).</Accordion>

<Accordion title="¿Cómo instalo el conector de Revit para todos los usuarios?">El administrador de Speckle instala los conectores solo para el usuario actual.</Accordion>

<Accordion title="¿Cómo desinstalar el conector de Revit?">Puedes desinstalar el conector de Revit usando el Administrador o desde el cuadro de diálogo Aplicaciones instaladas.

**Desinstalación mediante el Administrador**

1. Abre el **Administrador**.

2. Selecciona **Conector de Revit**.

3. Haz clic en **Desinstalar**.

**Desinstalación desde las aplicaciones instaladas**

1. En la barra de búsqueda de Windows, busca y selecciona «Agregar o quitar programas».

2. Busca **Speckle para Revit**.

3. Haz clic en los tres puntos (…) que aparecen junto a él.

4. Selecciona **Desinstalar**.</Accordion>
