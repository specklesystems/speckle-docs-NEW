Tras instalar correctamente el conector de Revit para Speckle, vamos a enviar tus primeros datos desde Revit a Speckleverse.

<Note>
Hemos renombrado algunos conceptos clave en Speckle para que sean más fáciles de entender.

- Los flujos se han renombrado a proyectos.
- Las ramas se han renombrado a modelos.
- Las confirmaciones se han renombrado a versiones.
</Note>

## Iniciando el conector

El conector de Revit se añadirá a todas las versiones compatibles que tenga instaladas.

Para iniciar el conector:

<img src="images/legacy/revit/launching-the-connector.png" alt="Lanzamiento del conector" />

1. Dirígete a la pestaña "**Speckle**" en la cinta de opciones.

2. Haz clic en el botón "**Revit Connector**", el que tiene el pequeño ladrillo azul 🧊.

## Envío de modelos

<img src="/images/legacy/revit/sending-from-revit.gif" alt="Enviando desde Revit" />

Enviar tu modelo de Revit solo requiere **4** pasos:

1. **Selecciona (o crea) un proyecto de Speckle**.

2. **Selecciona (o crea) un modelo de Speckle** para enviar.

3. **Selecciona lo que deseas enviar**.

4. Haz clic en **Enviar**.

Ampliemos estos puntos.

## Selección de un proyecto y modelo de Speckle

Antes de enviar datos desde Revit, es importante determinar a dónde desea enviarlos. Puede crear un proyecto y un modelo de Speckle mediante la interfaz web o la interfaz de usuario de Revit Connector. Explicaremos cómo crearlos utilizando la interfaz de usuario de Connector.

### Crear un proyecto Speckle

<img src="/images/legacy/revit/create-speckle-project.png" alt="Crear proyecto Speckle" width={350} />

Para crear un proyecto Speckle:

1. Haz clic en el botón **Crear nuevo proyecto**.

2. Asigna un **Nombre** a tu proyecto y una **Descripción** opcional.

3. Usa el interruptor para configurar tu proyecto como **Privado** o **Compartible mediante enlace**.

4. Haz clic en **Crear**.

<Tip>
No es necesario crear un proyecto Speckle cada vez. También puedes seleccionar un proyecto existente y enviarle datos.
</Tip>

También puedes crear un proyecto de Speckle utilizando la interfaz web de Speckle.

### Crear un modelo Speckle

<img src="/images/legacy/revit/create-speckle-model.png" alt="Crear modelo de moteado" width={700} style={{display: 'block'}} />

Para crear un modelo Speckle:

1. Despliega el menú desplegable **Modelo**.

2. Selecciona **Añadir nuevo modelo**.

3. Introduce un **Nombre** y una **Descripción** opcional.

4. Haz clic en **Crear**.

<Tip>
También puede seleccionar un modelo existente y enviarle datos.
</Tip>

También puedes crear un modelo Speckle utilizando la interfaz web de Speckle.

## Seleccionar qué enviar

A continuación, debes decidir qué elementos quieres enviar desde Revit. Para ayudarte a seleccionar qué elementos se enviarán a Speckle, hemos integrado varios filtros en nuestro conector de Revit. Una vez configurado un filtro, solo tienes que hacer clic en **Enviar** y todos los objetos que cumplan con el filtro se enviarán a tu proyecto.

Vamos a revisar cada uno de los filtros.

### 1. Todo

Envía todos los elementos del modelo compatibles, tipos de familia, niveles, información del proyecto, etc. El filtro "todo" abarca elementos gráficos y no gráficos del modelo.

<img src="/images/legacy/revit/filter-everything.png" alt="Filtro de todo" width={350} />

### 2. Selección

Seleccione manualmente los elementos de Revit, haga clic en "**Establecer selección actual**" y envíelos a Speckle.

<img src="/images/legacy/revit/filter-selection.png" alt="Filtro de selección" width={350} />

### 3. Categoría

El filtro de categorías le permite seleccionar una o varias categorías compatibles de Revit.

<img src="/images/legacy/revit/filter-category.png" alt="Filtro de categoría" width={350} />

### 4. Vista

El filtro de vista funciona de forma similar al filtro de categoría y permite incluir todos los elementos visibles en una o varias vistas.

<img src="/images/legacy/revit/filter-view.png" alt="Ver filtro" width={350} />

### 5. Horario

Envía la tabla de planificación de Revit seleccionada como una **Tabla de datos** a Speckle.

<img src="/images/legacy/revit/filter-schedule.png" alt="Filtro de programación" width={350} />

### 6. Filtros

Los filtros se utilizan para extraer selectivamente elementos específicos del modelo según condiciones lógicas predefinidas. En la imagen proporcionada, por ejemplo, Speckle identificará y enviará todos los elementos que cumplan con el filtro seleccionado.

<img src="/images/legacy/revit/filter-revit-filter.png" alt="Filtro de Revit" width={350} />

### 7. Conjunto de trabajo

Selecciona todos los elementos que pertenecen al conjunto de trabajo seleccionado.

<img src="/images/legacy/revit/filter-worksets.png" alt="Filtro de conjunto de trabajo" width={350} />

### 8. Información del proyecto

El filtro de información del proyecto permite añadir elementos no gráficos, como niveles, vistas (2D y 3D), tipos de familia (sus propiedades, no la geometría) e información del proyecto.

<img src="/images/legacy/revit/filter-project-info.png" alt="Filtro de información del proyecto" width={350} />
