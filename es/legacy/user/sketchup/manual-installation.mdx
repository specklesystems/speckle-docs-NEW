Si desea probar la instalación en una plataforma o versión diferente, puede realizar una instalación manual. Tenga en cuenta que el conector no se ha probado en versiones anteriores ni en otras plataformas. Es posible que surjan problemas, así que no dude en informarlos en el foro.

## 1. Clonar el repositorio

Primero, asegúrese de tener instalado [git](https://git-scm.com).

Ejecuta el siguiente comando en tu terminal para clonar el repositorio:

```bash
git clone https://github.com/specklesystems/speckle-sketchup
```

Esto creará una carpeta llamada `speckle-sketchup` con los archivos del conector en la ubicación donde ejecute este comando.

## 2. Construir la interfaz de usuario

Navegue hasta la carpeta `ui/`.

```bash
cd speckle-sketchup/ui
```

A continuación, ejecute los siguientes comandos:

```bash
npm install
npm run build
```

Esto creará una carpeta `html` dentro de la carpeta `speckle-sketchup/speckle_connector`.

## 3. Añade el conector a SketchUp

Busca la carpeta `Plugins` de tu instalación de SketchUp. En Windows, la carpeta se encuentra en:

```
C:\Users\{YOU}\AppData\Roaming\SketchUp\`{SketchUp_VERSION}\SketchUp\Plugins
```

Una vez que hayas encontrado el equivalente para tu sistema operativo/versión de SketchUp, copia la carpeta `speckle_connector` y el archivo `speckle_connector.rb` en la carpeta `Plugins`.
