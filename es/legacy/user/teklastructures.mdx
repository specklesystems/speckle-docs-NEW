### Filtros

Para ayudarte a seleccionar qué elementos se enviarán a Speckle, hemos integrado varios filtros en nuestro conector de Tekla Structures. Una vez configurado un filtro, solo tienes que hacer clic en **Enviar** y todos los objetos que cumplan con el filtro se enviarán a tu proyecto. Las propiedades de sección y los materiales definidos en el modelo siempre se enviarán.

<Tip>
Los elementos se envían independientemente de si son visibles o si se crearon después de configurar el filtro.
</Tip>

#### Filtros de selección

Los filtros de selección enviarán todo lo que esté seleccionado dentro de la pantalla de Tekla Structures.

#### Filtros de fase

El filtro de fase seleccionará las fases predefinidas dentro de Tekla Structures que están adjuntas a los objetos y enviará todos los objetos asociados con esa fase.

#### Filtro de categoría

El filtro de categoría le permite seleccionar una o más de las categorías de Tekla Structures compatibles actualmente. Este es el filtro más específico y también le permitirá enviar resultados. Nota: Otros filtros no le permitirán enviar resultados ni elementos y propiedades no geométricos.

#### Todos los filtros

Este sencillo filtro permite seleccionar todos los elementos compatibles con el conector de Tekla Structures. Esto enviará todos los elementos geométricos y sus propiedades asociadas.

## Actualizando elementos

El conector no se encarga de actualizar los elementos existentes dentro del proyecto.

## Datos de Revit y BIM a Tekla Structures

Al enviar elementos desde Revit, Speckle se encarga de convertir los datos a un formato compatible con Speckle. Si le interesa saber cómo se estructuran estos datos, consulte las definiciones de las clases del kit de objetos (https://github.com/specklesystems/speckle-sharp/tree/master/Objects/Objects/BuiltElements).

Actualmente, puedes enviar modelos a Revit y recibirlos con propiedades geométricas. Seguimos trabajando en este flujo de trabajo, que se irá perfeccionando con el tiempo. ¡Mantente al tanto para más novedades!

## Estructuras de Grasshopper a Tekla

Tekla Structures cuenta con sus propios plugins para Grasshopper, pero también puede enviarlos a través de los sistemas Speckle con nuestros constructores de esquemas. Vaya a la pestaña específica de Tekla Structures y envíe elementos de viga que abarquen todos los elementos geométricos 1D y placas de contorno que abarquen todos los elementos geométricos 2D. Las secciones se definirán por nombre, por lo que, siempre que las secciones del catálogo estén definidas por nombre en el catálogo de Tekla, se importarán y construirán correctamente. Consulte un ejemplo similar en la documentación de ETABS.

## Explorando los datos de Tekla Structures

Para explorar fácilmente los datos y parámetros de un objeto, nuestra interfaz web Speckle puede ser de gran ayuda. También lo son otras aplicaciones que permiten explorar los metadatos del objeto (por ejemplo, Grasshopper, Dynamo, Unity, etc.).
