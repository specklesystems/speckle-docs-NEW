This guide is for IT administrators who need to enable the Bentley ProjectWise cloud integration before users can sign in and create syncs in Speckle.

## Add the Speckle service account to ProjectWise projects

To give Speckle access to your ProjectWise files, add the following service account email as a member to each ProjectWise project you want to sync:

<CodeGroup>
service-VTc0NKefa1k4kXA4p16zC17R7@apps.imsoidc.bentley.com
</CodeGroup>

Once this email has been added to a project, users in your Speckle workspace can connect and sync files from that project.

<Note>
  The Speckle service account only has access to projects you explicitly add it to. It does not inherit personal permissions or see any data outside what you grant.
</Note>

After this is enabled, users can continue with [Bentley ProjectWise user setup](/connectors/cloud-integrations/projectwise).
