## What is a workspace?

A workspace is your team's operating area in Speckle.
Use it to manage projects, assign access, and keep delivery work under one shared security model.
Use this page as a quick map of where to go next.

<Note>
  Workspaces are available on Speckle Cloud and on Speckle Enterprise Server. For self-hosted setup,
  see [Enterprise license](/developers/server/deployment/enterprise-license#enable-workspaces).
</Note>

## Open user settings

<Frame caption="1 Your name opens User settings">
  <img
    src="/images/workspaces/introduction/workspace-switcher-menu.png"
    alt="Workspace switcher menu open below the workspace name, listing Workspace home, Switch workspace, the signed-in user's name, Theme, Copy support reference and Log out"
  />
</Frame>

Your account settings open from the **workspace switcher**: the workspace name at the top of the
left sidebar. In that menu, select **your name** (the row with your avatar). That row opens **User
settings** on **Profile**. There is no separate Profile or Settings item in this menu.

User settings lists **Profile**, **Notifications**, **Developer** (access tokens and apps), and
**Emails**. The same workspace-switcher menu also has **Theme**, **Copy support reference**, and
**Log out**. Server administrators also see **Server settings**.

## FAQ

<AccordionGroup>
  <Accordion title="Why does Intelligence open dashboards instead of Chat?">
    Workspace **Intelligence** opens dashboards. Chat is in the project sidebar, next to **Browse**.
    The sparkle in the 3D viewer is a third entry point for questions about loaded models. See [Ask
    questions about your models with Speckle Intelligence](/analytics/intelligence).
  </Accordion>
  <Accordion title="What happens if Documents is missing from the sidebar?">
    **Documents** appears only when the workspace includes Speckle Intelligence Chat and the
    documents library is enabled. Other sidebar items stay. Ask a workspace admin if you expected to
    see it.
  </Accordion>
  <Accordion title="Where did user settings and the avatar menu go?">
    The avatar menu is gone. User settings open from the workspace switcher: open the workspace name
    at the top of the left sidebar, then select your name. That opens User settings. See [Open user
    settings](#open-user-settings).
  </Accordion>
</AccordionGroup>
