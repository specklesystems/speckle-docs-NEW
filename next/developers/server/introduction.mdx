2026.9 developer notes for Speckle Server deployment and self-hosting are not on this preview yet.
Use the [current Server documentation](/developers/server/introduction) until those notes land.

<Warning>
  The open-source Speckle Server (core release) does not support 2026.9. If you run the open-source
  server, pin your connectors to 2026.8 or earlier. 2026.9 connectors will not work against it.
</Warning>

<Note>
  This does not apply to Speckle Enterprise Server, including deployments on third-party
  infrastructure. If you maintain or operate an Enterprise-licensed server, work with your
  infrastructure support agent to plan your move to 2026.9.
</Note>
