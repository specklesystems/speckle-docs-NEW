2026.9 developer notes for the TypeScript and JavaScript SDK are not on this preview yet. Use the
[current JS/TS SDK documentation](/developers/sdks/typescript/introduction) until those notes land.

<Warning>
  **Building directly on the Viewer package, or on `@speckle/objectloader` /
  `@speckle/objectloader2`?** This is the case most likely to break silently, and it's easy to miss
  in the general migration comms because it isn't "just" an SDK or API consumer. Your app stops
  getting data as soon as any version you load is a 2026.9 bundle: the objects endpoints return
  404.

Start from [Building applications](/next/developers/building-applications), which routes rendering
apps and data-only apps to the right load path and explains why there is no drop-in
object-graph loader.

</Warning>
