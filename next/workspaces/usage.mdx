Workspace **Settings → Usage** shows activity, plan limits, and AI spend for this workspace. Use
this page as a workspace admin. Current User Guides have no equivalent page. The closest Current
guides are [Configuration](/workspaces/configuration) and [Billing](/workspaces/billing).

If **Usage** is missing from Settings, you do not have that permission or the plan does not include
it. The Settings map is on [Workspace settings in 2026.9](/next/workspaces/settings).

## Open Usage

{/* IMAGE_PLACEHOLDER: Settings → Usage landing — title Usage, subtitle, filter bar, section tabs Projects through Limits. */}

<Steps>
  <Step title="Open workspace Settings">
    Sign in, open the workspace, then select **Settings**. You should see **General** at the top of
    the Settings list.
  </Step>
  <Step title="Open Usage">
    Select **Usage**. The heading is **Usage**. The subtitle is "Activity, plan limits and AI spend
    for this workspace." You should see a filter bar and section tabs.
  </Step>
</Steps>

## Filter and export

The filter bar applies to the activity sections, not to **Limits**.

- Range: **Last 7 days**, **Last 30 days**, **Last 90 days**, or **Last 12 months**.
- **Projects**, project labels, and **Member** narrow the scope. **Clear** removes that scope.
- Charts and tables include **Download CSV** when there are rows to export.

**Limits** is workspace-wide. Changing the filters does not change that tab.

## Sections

{/* IMAGE_PLACEHOLDER: Usage Projects tab — project leaderboard, Last 12 months chart, feature adoption. */}

- **Projects** — which projects see the most activity, and how many are active month to month.
- **Users** — the most active people, and how many are active month to month.
- **Integrations** — where versions come from, and which ACC and ProjectWise files are wired to
  auto-refresh.
- **Dashboards & Reports** — which projects every dashboard and report is attached to, and who
  owns it.
- **AI** — token spend by user, project, purpose, and tool. This tab appears when the workspace
  includes Speckle Intelligence Chat. Under a project scope, workspace-level chats drop out.
- **Limits** — what the plan includes and how much of it is used. **Manage plan** opens **Billing
  and plans**. See [Billing](/workspaces/billing).

Empty activity sections show "No usage data available" until people start working in the
workspace. If a load fails, the page shows "Couldn't load usage data" and **Try again**.

<Note>
  Speckle Intelligence Chat is available when your workspace plan includes it. On a self-hosted
  server, it is available only on Speckle Enterprise Server. For deployment setup, see [Enterprise
  license — Intelligence](/developers/server/deployment/enterprise-license#optional-intelligence).
</Note>

## FAQ

<AccordionGroup>
  <Accordion title="Why don't the filters change Limits?">
    **Limits** is workspace-wide. The filters apply to Projects, Users, Integrations, Dashboards &
    Reports, and AI. Use **Manage plan** on the Limits tab to open **Billing and plans**.
  </Accordion>
  <Accordion title="What happens if the AI tab is missing?">
    **AI** appears when the workspace includes Speckle Intelligence Chat. The other tabs stay. Chat
    itself is documented on [Ask questions about your models with Speckle
    Intelligence](/next/analytics/intelligence).
  </Accordion>
  <Accordion title="Is there a Current Usage page?">
    No. Current documents billing and configuration, not this analytics surface. Use
    [Configuration](/workspaces/configuration) and [Billing](/workspaces/billing) for those topics,
    and this page for Usage.
  </Accordion>
</AccordionGroup>
