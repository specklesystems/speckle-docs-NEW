The workspace sidebar in 2026.9 lists the live areas of the web app. Current workspace cards still
show Home, Projects, Intelligence, Team, and Settings only. This page is the map for what you
actually see. For how workspaces work today, see [Workspaces](/workspaces/introduction).

<Note>
  Workspaces are available on Speckle Cloud and on Speckle Enterprise Server. For self-hosted setup,
  see [Enterprise license](/developers/server/deployment/enterprise-license#enable-workspaces).
</Note>

## Find your way around

{/* IMAGE_PLACEHOLDER: Workspace sidebar — Home, Projects, Intelligence, Documents when gated on, Team, Settings. */}

The left sidebar is the same on Home and on other workspace pages:

- **Home** — recent activity and a summary of the workspace.
- **Projects** — the projects in this workspace. See [Projects](/workspaces/projects).
- **Intelligence** — workspace dashboards. This is not Chat. Chat lives in the project sidebar,
  next to **Browse**. See [Ask questions about your models with Speckle
  Intelligence](/next/analytics/intelligence) and [Intelligence
  Dashboards](/analytics/intelligence-dashboards).
- **Documents** — the workspace file library. This item appears only when the workspace includes
  Speckle Intelligence Chat and the documents library is enabled.
- **Team** — members, invites, and seats. See [Inviting](/workspaces/inviting) and [Roles and
  permissions](/workspaces/roles-and-seats).
- **Settings** — workspace-wide controls. Open **Settings** to expand the children listed on
  [Workspace settings in 2026.9](/next/workspaces/settings).

<Note>
  **Documents** is gated. If you do not see it, the workspace does not have that library yet. It is
  not missing from the product.
</Note>

## What stays on Current

Projects, models, versions, roles, and inviting still use the Current guides. This page does not
clone them.

## FAQ

<AccordionGroup>
  <Accordion title="Why does Intelligence open dashboards instead of Chat?">
    Workspace **Intelligence** opens dashboards. Chat is in the project sidebar, next to **Browse**.
    The sparkle in the 3D viewer is a third entry point for questions about loaded models. See [Ask
    questions about your models with Speckle Intelligence](/next/analytics/intelligence).
  </Accordion>
  <Accordion title="What happens if Documents is missing from the sidebar?">
    **Documents** appears only when the workspace includes Speckle Intelligence Chat and the
    documents library is enabled. Other sidebar items stay. Ask a workspace admin if you expected to
    see it.
  </Accordion>
  <Accordion title="Where do I change SSO, billing, or labels?">
    Open workspace **Settings**. The children are listed on [Workspace settings in
    2026.9](/next/workspaces/settings). Depth that is still accurate lives on Current
    [Configuration](/workspaces/configuration).
  </Accordion>
</AccordionGroup>
