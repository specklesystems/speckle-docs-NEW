Speckle Intelligence is the assistant in the Speckle web app. You ask about a project in plain
language. It reads the models you have published and replies with answers, charts, and — in the 3D
viewer — changes to what you are looking at.

There is no Current equivalent for this Chat surface. For how Speckle works today, see
[Compare Current and v2026.9](/next/whats-new) and
[Speckle's data model is changing](/workspaces/data-model-migration). Dashboards stay on
[Intelligence Dashboards](/analytics/intelligence-dashboards); this page does not cover them.

<Note>
  Speckle Intelligence Chat is available when your workspace plan includes it. On a self-hosted
  server, it is available only on Speckle Enterprise Server. For deployment setup, see [Enterprise
  license — Intelligence](/developers/server/deployment/enterprise-license#optional-intelligence).
</Note>

## Open Chat

The live product entry point is **Chat**, not the **Intelligence** item in the project or workspace
sidebar. That **Intelligence** label currently opens dashboards.

<Steps>
  <Step title="Open a project">
    Open the project whose models you want to ask about. You should see the project sidebar with
    **Browse** and **Chat** at the top when Chat is available for the workspace.
  </Step>
  <Step title="Choose Chat">
    Select **Chat**. The page title is **Chat**. The empty state reads **Ask about** your project
    name, with the prompt to ask in plain language.
  </Step>
  <Step title="Ask a question">
    Type a question, or pick a suggested starter if one is shown. You can attach a published model
    from the composer when the question needs a specific version.
  </Step>
  <Step title="Read the reply">
    Wait for the reply. You should see a conversation in the Chat history, titled from your
    question, and an answer that uses that project's data.
  </Step>
</Steps>

<Tip>
  In the 3D viewer, open Chat from the sparkles control at the right of the navbar. That control is
  labelled **Open AI chat**. The empty state reads **Chat with your model**, and the composer
  placeholder is **Ask about this model…**
</Tip>

<Note>
  If **Chat** is missing, your workspace may not include Speckle Intelligence, a workspace admin may
  have turned **AI features** off in workspace settings, or you may need to choose **Enable AI for
  this workspace** when the **Enable AI** dialog appears.
</Note>

## What changes in v2026.9

Today, Speckle Intelligence looks at properties on each object. After a project moves to the new
data format, it can also see how parts of a model relate to each other: what connects to what, and
what contains what.

That is the same change summarised on [Compare Current and v2026.9](/next/whats-new). Follow
[Speckle's data model is changing](/workspaces/data-model-migration) for dates and what to do next.
Do not expect answers about what connects or contains what from models that still use today's format.

## What you can ask

Ask in the same language you would use with a colleague who has the model open.

In the 3D viewer, starters can include **What's in this model?**, **Give me a tour**, **What
changed recently?**, and **Color it by category**. If you have an object selected, you may also see
**What is this?**

After the project is on the new data format, you can also ask what contains an object, what it
connects to, or what sits on a level. Those questions need the relational layer in the new format.

Chat can also build a **Report** from a conversation. Saved reports appear under **Reports** in the
project sidebar when Chat is enabled. Data Validation has its own assistant in the check editor;
that flow stays on the Data Validation guides.

## FAQ

<AccordionGroup>
  <Accordion title="Why does Intelligence in the sidebar open dashboards?">
    In the product today, **Intelligence** in the workspace and project sidebars opens dashboards.
    Speckle Intelligence Chat is a separate surface: **Chat** on the project, or **Open AI chat** in
    the 3D viewer. Dashboards are documented on [Intelligence
    Dashboards](/analytics/intelligence-dashboards).
  </Accordion>
  <Accordion title="What happens if my project has not moved to the new data format?">
    Chat still answers questions about object properties. Questions about what connects to what, or
    what contains what, need the new format. See [Speckle's data model is
    changing](/workspaces/data-model-migration).
  </Accordion>
  <Accordion title="How do I start a new conversation?">
    Use **New chat** in the Chat history. That starts an empty conversation so the next question is
    not mixed with an earlier thread.
  </Accordion>
  <Accordion title="What happens if the workspace AI credit is used up?">
    New Chat turns are blocked until a workspace admin adds more **AI credit**. Stored conversations
    remain. The composer shows that the workspace credit has been used up.
  </Accordion>
</AccordionGroup>
