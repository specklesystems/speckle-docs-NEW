Some dashboard widgets do not yet run against models in the 2026.9 data format. A saved instance stays on the grid as a placeholder. It keeps its configuration. It does not load 2026.9-format data until that widget is ported.

Widgets that are **not** on this list either already run against 2026.9-format models, or they are presentation chrome that does not read model properties.

For the launch limitation and compatibility mode, see [Dashboards in 2026.9](/next/analytics/dashboards). For building dashboards on pre-2026.9 data, use the [current Dashboards documentation](/analytics/intelligence-dashboards).

## How to read this list

- A widget leaves the sections below when it can run against 2026.9-format models.
- Pre-2026.9 data, and workspaces in [compatibility mode](/next/it-admin/compatibility-mode), still use the widget set from before 2026.9.
- Widgets in Deprecated in 2026.9 are retired. They will not gain 2026.9-format support.

## Deprecated in 2026.9

<Warning>
  These widgets are retired in 2026.9. A saved instance may still appear on a dashboard. That does
  not restore the widget. Use the replacement named for each widget. If no replacement is named, the
  widget has no successor.
</Warning>

- **Element table** — replaced by the unified Data table.
- **Pivot table** (matrix table) — replaced by the unified Data table.
- **Context** (experimental, model on a map) — deprecated. This is not the same as marking a model as a [context model](/analytics/intelligence-dashboards#context-models) in the Model Viewer.
- **Parameter Updater** — not a dashboard widget in 2026.9. Use the [Elements panel in the model viewer](/next/analytics/data-conditioning).
- **Revit-category Material quantities over time** — replaced by Time series Beta Material quantities over time.
- **Cost Estimation** — deprecated. No replacement.
- **Render Genie** — no longer supported. No replacement.
