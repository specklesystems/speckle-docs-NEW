Dashboards work in 2026.9, with one important limitation at launch.

**Data sent before 2026.9** — anything already in your projects from previous connector versions — will load and display in Dashboards as expected.

**Data in the new 2026.9 format** — models sent with 2026.9 connectors, or brought in via Rhino or IFC file upload — won't display correctly in Dashboards yet. If you need to view that data in Dashboards right now, ask us to enable **compatibility mode**, which keeps new data in a format Dashboards can read while we finish the update. Reach out via [speckle.community/help](https://speckle.community/help) or contact your Customer Success Advisor. We're actively working to remove this limitation.

<Note>
  Compatibility mode is not self-serve. See [Compatibility mode](/next/it-admin/compatibility-mode)
  for how to request it and what it covers.
</Note>

For everything else — building dashboards, working with existing data, sharing views — use the
[current Dashboards documentation](/analytics/intelligence-dashboards).

## Dashboards aren't going away

Dashboards remain the analytics product for workspaces that don't include Speckle Intelligence, and they will continue to be supported. If your team adopted Speckle partly because Dashboards offered a faster, simpler path to shared data views than Power BI or similar tools, that proposition hasn't changed.

We're investing in making Dashboards work correctly with 2026.9-format data — compatibility mode is the bridge while that work lands.

If you've built something with Dashboards that solves a problem in a way we haven't seen before, we genuinely want to hear about it. The bespoke things people make are what shape how Dashboards and Reports develop alongside each other. Share what you've built in the [forum](https://speckle.community) or email [feedback@speckle.systems](mailto:feedback@speckle.systems).

## Intelligence Reports

For workspaces with Speckle Intelligence, there is a new direction for sharing data insights: **Intelligence Reports**.

The difference is where you start. A dashboard is something you build from scratch to answer a question. A Report begins with an analysis you were already running in [Speckle Intelligence Chat](/next/analytics/intelligence) — you ask the AI a question about your model, it builds the analysis, and you save that conversation as a Report. What you discovered becomes the starting point for sharing it, not a separate construction task.

{/* IMAGE_PLACEHOLDER: Intelligence Chat with a completed analysis — Save as Report button visible; the saved Report open in the project sidebar. */}

Beyond BIM model data, Reports can draw on external data sources — Snowflake, Databricks, and others — letting you bring cost rates, programme data, or benchmark figures into the same analysis. This is the capability shift that makes Reports a different kind of tool, not just a rename.

### Edit the generated report

Opening a saved Report gives you a live editor. You can add, remove, and reorder sections — **Charts**, **KPIs**, **Tables**, **3D Viewer**, or **Text** — without going back to Chat. Select any section to set its title, subtitle, and tab structure. Drag sections to reorganise them.

Edits stay local until you save; there is no auto-save. If you want the AI to rework a section rather than editing it by hand, Chat is available on the report page — those turns spend AI credit, direct edits don't.

{/* IMAGE_PLACEHOLDER: Report editor — Add menu open showing Chart KPI Table Viewer Text; Properties panel open on a selected section with title and subtitle fields. */}

### Change sources and adjust inputs

Reports carry an **Inputs** strip along the top. Each chip shows a model, version, and alias. You can swap in a different version or point a chip at a different model without re-running the AI. Individual sections can expose **knobs** — adjustable values like a rate or occupancy figure — that a viewer can change without spending AI credit.

{/* IMAGE_PLACEHOLDER: Report Inputs strip showing source chips — Change version dialog open on one chip; a section below showing Inputs knobs with Reset. */}

### Share

Reports can be kept **private**, shared with **anyone in the project**, or published as a **public link** anyone can open without signing in.

For full details, see [Create and share Intelligence Reports](/next/analytics/reports).
