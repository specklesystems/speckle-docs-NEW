Check your workspace’s upload mode before uploading a file in 2026.9. Some formats require
legacy/compatibility mode, which ends on **1 November 2026**. Tekla Structures and Vectorworks
uploads are available where enabled.

## Breaking change: supported file formats

<Warning>
  In 2026.9, the default file upload path no longer accepts **STL**, **3MF**, **3DS**, **AMF**,
  **DXF**, **X**, **E57**, **IGS/IGES**, **FBX**, **PLY**, or **SLDPRT**. Earlier upload-format
  lists do not apply to this path. **These formats remain supported for direct uploads in
  legacy/compatibility mode only until it ends on 1 November 2026.** Move affected workflows to a
  supported format before then.
</Warning>

This affects both drag-and-drop uploads in the web app and uploads through the API. Existing
models stay readable; the change affects importing new files and uploading new versions.

## Additional format: Tekla Structures

2026.9 adds support for Tekla Structures model packages (`.tekla`) and model databases (`.db1`)
on deployments where Tekla uploads are enabled. This is not enabled by default; confirm
availability with Speckle before relying on it for your workflow.

Use the complete model folder when uploading a Tekla model to preserve profiles, shapes, and materials.

<Tip>
  A `.tekla` package contains the model folder and its supporting catalogs. A `.db1` file alone can
  be converted, but missing catalogs can reduce profile, shape, and material fidelity.
</Tip>

## Additional format: Vectorworks

2026.9 adds support for Vectorworks files (`.vwx`) on deployments where Vectorworks uploads are
enabled. Confirm availability with Speckle before relying on it for your workflow.

Upload a Vectorworks file to publish it without Vectorworks or its connector. The [Vectorworks
connector](/connectors/third-party/vectorworks) publishes the objects you select; an upload
publishes the 3D content of every design layer.

<Note>
  On a self-hosted server, Vectorworks uploads need a converter image with Vectorworks support. Your
  server admin can check the [file imports
  setup](/developers/server/deployment/enterprise-license#file-imports-conversion-runner).
</Note>

### Files that convert

Speckle reads files last saved in Vectorworks 2021 through 2026. Files from other releases are not
supported yet.

### What is published

- 3D objects on every design layer, including design layers hidden in the document, grouped by
  story, layer, and type.
- Each object's name, type, object properties, and IFC properties. An object whose 3D geometry
  Speckle cannot read yet still arrives with its properties.

These parts of the document are not published:

- Objects in a class that is hidden in the document.
- Sheet layers.
- 2D-only objects, such as callouts, data tags, and section lines.

<Note>
  Speckle follows the class visibility saved in the file. To include a hidden class, make it visible
  and save the file before you upload it.
</Note>

### If a Vectorworks upload fails

| Message                                                  | What to do                                                                         |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Vectorworks file version … is not supported              | Open the file in Vectorworks 2026, save it, and upload it again.                   |
| This is not a supported Vectorworks document             | Check that the file is a Vectorworks document, not another file renamed to `.vwx`. |
| This Vectorworks document uses an unsupported byte order | Open the file in Vectorworks 2026, save it, and upload it again.                   |

## Update an affected workflow

If your workspace uses legacy/compatibility mode, you can continue uploading the affected
formats until compatibility mode ends on **1 November 2026**. Before moving to the default 2026.9 mode,
export to a supported format or publish through a supported desktop connector. Check the
resulting model before switching your workflow: uploads and connector publishing can produce
different geometry and properties. See [Uploads and connectors produce different
datasets](/connectors/direct-uploads/introduction#uploads-and-connectors-produce-different-datasets).

For the upload steps, see [Upload a file](/connectors/direct-uploads/introduction#upload-a-file).
For programmatic uploads, see [Uploading IFC and other files](/developers/api/guides/file-uploads).
Use the supported formats on this page for 2026.9.

## Temporary compatibility option

Legacy mode, also called compatibility mode, retains direct upload support for the affected
formats when the older conversion service is enabled. Ask Speckle to confirm availability for your workspace. It ends for every workspace on **1 November 2026**. This exception applies
to direct uploads, not cloud sync.

Compatibility mode affects the entire workspace's upload and sync routing; it is not a per-file
fallback. **DGN uploads are not supported in compatibility mode.**

For availability, the **1 November 2026** end date, and how to request it, see
[Compatibility mode for ACC sync and uploads](/next/it-admin/compatibility-mode).
