There is no 2026.9 Navisworks desktop connector. **2026.8** is the last installer.

The 2026.8 connector remains the advised path for a publish around **200 MB**. For larger files,
upload an **NWC** or **NWD**. Speckle parses the file on the server, so you do not sit in Navisworks
watching a publish progress bar.

This page covers only that change. For install, sign-in, and publish in the 2026.8 connector, see
[How to use Speckle for Navisworks](/connectors/navisworks).

## What to do

- **About 200 MB.** Publish from the **2026.8** desktop connector. That is still the advised path
  for a publish of that size. Do not wait for a 2026.9 installer.
- **Larger files.** Upload an NWC or NWD. Direct upload follows the general file-size limit of
  **2 GB**. ACC sync of Navisworks files has been tested to **6 GB**. See [Direct
  uploads](/connectors/direct-uploads/introduction) and [Autodesk Forma Data Management
  (ACC)](/connectors/cloud-integrations/acc).

<Warning>
  A file uploaded directly and the same model published from the desktop connector do not produce
  identical Speckle data. See [Uploads and connectors produce different
  datasets](/connectors/direct-uploads/introduction#uploads-and-connectors-produce-different-datasets).
</Warning>

## Data format if you stay on 2026.8

The 2026.8 connector publishes Speckle's current data model — the model in use before 2026.9.
Speckle may convert that published version to the 2026.9 format on the server. Treat that conversion
as best effort, not a guarantee.

- In the web app, versions stay readable either way.
- Speckle Intelligence can query only versions that are already in the 2026.9 format. See [Ask
  questions about your models with Speckle Intelligence](/next/analytics/intelligence).
- If you read this data in a script, notebook, Automate function, or other API consumer, follow
  [Data model migration for developers](/developers/migration/data-model-migration). Do not assume
  the version was converted, and do not assume it stayed on the old model.

NWC and NWD uploads follow the upload path: new format by default, or the old format if the
workspace is in [compatibility mode](/next/it-admin/compatibility-mode) until **1 November 2026**.
Compatibility mode does not apply to desktop-connector publishes.

## Desktop-only workflows

If a file is larger than the upload or ACC sizes above, or you have a workflow that only the
desktop connector can do, tell Speckle in [speckle.community/help](https://speckle.community/help).
Those cases will be noted for consideration. As of now there is no 2026.9 connector.

## FAQ

<AccordionGroup>
  <Accordion title="When should I use the connector instead of an upload?">
    Use the **2026.8** connector for a publish around **200 MB**, and when you need session filters
    such as a selection, saved search, or saved view. Upload an NWC or NWD when the file is larger,
    or when you do not want to leave Navisworks open on a publish progress bar.
  </Accordion>
  <Accordion title="Can I keep using the Navisworks desktop connector?">
    Yes, on **2026.8**. That is the last installer. There is no 2026.9 package. New publishes from
    that connector use the current data model. Server-side conversion to the 2026.9 format is not
    guaranteed. If you consume the data in code, see [Data model migration for
    developers](/developers/migration/data-model-migration).
  </Accordion>
  <Accordion title="Will there be a 2026.9 Navisworks connector later?">
    Not as of now. If a file above the upload or ACC sizes, or a desktop-only workflow, blocks you,
    post in [speckle.community/help](https://speckle.community/help) so it can be considered.
  </Accordion>
  <Accordion title="Why is there no 2026.9 desktop connector?">
    The desktop connector cannot match the throughput of server-side NWC and NWD ingest on large
    files. Speckle takes that processing so you do not watch a progress bar in Navisworks. A 200 MB
    publish from the 2026.8 connector is still the advised desktop path.
  </Accordion>
  <Accordion title="Does this change loading into Navisworks?">
    No. The Navisworks connector has always been publish-only. You still cannot load Speckle models
    back into Navisworks.
  </Accordion>
</AccordionGroup>
