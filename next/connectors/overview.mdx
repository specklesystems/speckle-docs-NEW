If you publish and load through Speckle connectors, your day-to-day work stays the same in 2026.9.
After you update a connector, new publishes use the new format going forward. Most people do not
need to do anything beyond updating their connector. Navisworks has no 2026.9 installer — see
[Navisworks in 2026.9](/next/connectors/navisworks/introduction).

For how to publish and load in each design tool today, see [Connectors](/connectors/overview). For
dates and the full workspace steps, see
[Speckle's data model is changing](/workspaces/data-model-migration). For a compact Current versus
2026.9 table, see [Compare Current and 2026.9](/next/whats-new).

This page covers the shared data-format change for connectors. 2026.9 pages exist for Revit,
Grasshopper, Power BI, and Navisworks. Every other design tool stays on the Current connector
guides — see [Design tools still on Current guides](#design-tools-still-on-current-guides).

## What stays the same

You still publish and load through your connectors, and you still view and share in the web app.
Your existing connectors keep working. Models you already published stay readable.

## What changes

After your project moves to the new data format, publish, load, and view are faster. New publishes
from an updated connector use the new format going forward. A 2026.8 Navisworks publish still uses
the current data model; the server may convert it, but that is not guaranteed.

## What you should do

<Steps>
  <Step title="Update your connector">
    Update from **1 September 2026**, and no later than **1 November 2026**. Your existing connector
    keeps working either way. Updating gets you the performance improvements sooner. Skip this step
    for Navisworks: there is no 2026.9 installer. A 200 MB publish still uses **2026.8**. Larger NWC
    and NWD files should be uploaded. See [Navisworks in
    2026.9](/next/connectors/navisworks/introduction).
  </Step>
  <Step title="Keep publishing as usual">
    Publish and load the same way you do today. New publishes from an updated connector use the new
    format. Models you already published stay readable.
  </Step>
</Steps>

<Note>
  Compatibility mode is only for ACC sync and drag-and-drop uploads when another tool still expects
  the old format. You do not need it if you only publish from desktop connectors. That option ends
  **1 November 2026**. See [Who should pay closer
  attention](/workspaces/data-model-migration#who-should-pay-closer-attention).
</Note>

## FAQ

<AccordionGroup>
  <Accordion title="Do I need to change how I publish and load?">
    No. You still publish and load through your connectors, and you still view and share in the web
    app. After your project moves to the new data format, those flows are faster.
  </Accordion>
  <Accordion title="What happens to models I already published?">
    They stay readable. New publishes from an updated connector use the new format going forward. A
    2026.8 Navisworks publish still uses the current data model unless the server converts it. That
    conversion is not guaranteed. See [Navisworks in
    2026.9](/next/connectors/navisworks/introduction).
  </Accordion>
  <Accordion title="Do I need compatibility mode if I only publish from desktop connectors?">
    No. Compatibility mode is only for ACC sync and drag-and-drop uploads when another tool still
    expects the old format. It ends on **1 November 2026**. See [Who should pay closer
    attention](/workspaces/data-model-migration#who-should-pay-closer-attention).
  </Accordion>
  <Accordion title="What if there is no 2026.9 page for my design tool?">
    Use the Current connector guides. See [Design tools still on Current
    guides](#design-tools-still-on-current-guides) for the named list. The feature did not go away.
    Navisworks is the exception: there is a 2026.9 page because there is no 2026.9 desktop
    connector. See [Navisworks in 2026.9](/next/connectors/navisworks/introduction).
  </Accordion>
</AccordionGroup>
