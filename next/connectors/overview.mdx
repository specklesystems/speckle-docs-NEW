If you publish and load through Speckle connectors, your day-to-day work stays the same in 2026.9.
New publishes use the new format going forward. Most people do not need to do anything beyond
updating their connector.

For how to publish and load in each design tool today, see [Connectors](/connectors/overview). For
dates and the full workspace steps, see
[Speckle's data model is changing](/workspaces/data-model-migration). For a compact Current versus
2026.9 table, see [Compare Current and 2026.9](/next/whats-new).

This page covers the shared data-format change for connectors. 2026.9 pages exist for Revit,
Grasshopper, and Power BI. For any other design tool, use the Current connector guides.

## Design tools in 2026.9

- [Revit in 2026.9](/next/connectors/revit/introduction) — reference points and model placement
- [Grasshopper in 2026.9](/next/connectors/grasshopper/introduction) — node names, Explore, and
  script upgrades
- [Power BI in 2026.9](/next/connectors/power-bi/introduction) — Get Tables and the 2026.9 3D visual

## What stays the same

You still publish and load through your connectors, and you still view and share in the web app.
Your existing connectors keep working. Models you already published stay readable.

## What changes

After your project moves to the new data format, publish, load, and view are faster. New publishes
use the new format going forward.

## What you should do

<Steps>
  <Step title="Update your connector">
    Update from **1 September 2026**, and no later than **1 November 2026**. Your existing connector
    keeps working either way. Updating gets you the performance improvements sooner.
  </Step>
  <Step title="Keep publishing as usual">
    Publish and load the same way you do today. New publishes use the new format. Models you already
    published stay readable.
  </Step>
</Steps>

<Note>
  Compatibility mode is only for ACC sync and drag-and-drop uploads when another tool still expects
  the old format. You do not need it if you only publish from desktop connectors. That option ends
  **1 November 2026**. See [Who should pay closer
  attention](/workspaces/data-model-migration#who-should-pay-closer-attention).
</Note>
