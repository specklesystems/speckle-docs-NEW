If you publish and load through Speckle connectors, your day-to-day work stays the same in 2026.9.
After you update a connector, new publishes use the new format going forward. Most people do not
need to do anything beyond updating their connector. Navisworks has no 2026.9 installer — see
[Navisworks in 2026.9](/next/connectors/navisworks/introduction).

For how to publish and load in each design tool today, see [Connectors](/connectors/overview). For
dates and the full workspace steps, see
[Speckle's data model is changing](/workspaces/data-model-migration). For a compact before-and-after table, see [Compare 2026.8 and 2026.9](/next/whats-new).

This page covers the shared data-format change for connectors. 2026.9 pages exist for Revit,
Grasshopper, Power BI, Navisworks, and Trimble Connect. For any other design tool, use the connector guides under **Current** in the version selector — see [Design tools without a dedicated page](#design-tools-without-a-dedicated-page).

## File uploads in 2026.9

The default upload path accepts fewer file formats in 2026.9. STL and the other affected formats
remain supported for direct uploads in legacy/compatibility mode. See
[File uploads in 2026.9](/next/connectors/file-uploads) for supported formats and alternatives.

## Design tools without a dedicated page

These tools have no dedicated 2026.9 page. Update the connector when a 2026.9 build exists.
Publish and load stay the same. How-to remains under **Current** in the version selector — see [Connectors](/connectors/overview).

- ProjectWise on-prem, ProjectWise Cloud, and other cloud integrations without a 2026.9
  page (ACC, Databricks, Snowflake)
- DGN / MicroStation / OpenRoads
- Tekla Structural Designer
- Rhino, SketchUp, Archicad, Blender, Civil 3D, Plant 3D, AutoCAD, ETABS, and Tekla Structures
- Third-party connectors (Vectorworks, Karamba3D, ShapeDiver)

<Warning>
  A 2026.8-or-earlier connector cannot load data published by a 2026.9-or-newer connector. Check the
  receiving connector's supported data format before updating a shared workflow.
</Warning>

Vectorworks does not yet support loading the 2026.9 data format. See [Why can't I load a model
into Vectorworks anymore?](#why-cant-i-load-a-model-into-vectorworks-anymore).

<Note>
  Compatibility mode applies to ACC sync and drag-and-drop uploads. It does not change the data
  format published or loaded by desktop connectors.
</Note>

## What stays the same

You still publish and load through your connectors, and you still view and share in the web app.
Your existing connectors keep working. Models you already published stay readable.

## What changes

After your project moves to the new data format, publish, load, and view are faster. New publishes
from an updated connector use the new format going forward. A 2026.8 Navisworks publish still uses
the pre-2026.9 data format; the server may convert it, but that is not guaranteed.

## What you should do

Update your connector from **1 September 2026**, and no later than **1 November 2026**.
Publish and load as usual after updating. New publishes use the 2026.9 format; existing models
stay readable.

<Note>
  Navisworks has no 2026.9 installer. Keep using the 2026.8 connector for publishes around 200 MB;
  upload larger NWC and NWD files. See [Navisworks in
  2026.9](/next/connectors/navisworks/introduction).
</Note>

  <Accordion title="Why can't I load a model into Vectorworks anymore?">
    The model was published from a connector that has already updated to 2026.9 — Revit, Archicad,
    or any other design tool once it updates. Vectorworks' current read path doesn't support that
    format yet. No 2026.8-or-earlier connector can load data published by a 2026.9-or-newer
    connector, so this isn't specific to Vectorworks. Ask the publisher to use a **2026.8**
    connector build until Vectorworks ships its own 2026.9 read-side update — download it from
    [releases.speckle.systems](https://releases.speckle.systems/).
  </Accordion>
</AccordionGroup>
