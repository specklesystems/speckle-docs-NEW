Use this page to see what v2026.9 changes for you, next to how Speckle works today. For the
current product, switch to **Current** in the version selector.

If you only publish and load through Speckle connectors, your day-to-day work stays the same. The
rows below are the exceptions and dates that matter. For the full steps, see
[Speckle's data model is changing](/workspaces/data-model-migration).

## What's different

| What you do                  | Today                                                   | In v2026.9                                                                                                                                                  | Learn more                                                                                          |
| ---------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Publish, load, and view      | You publish and load through connectors and the web app | You still do. After your project moves to the new data format, those flows are faster                                                                       | [What to do next](/workspaces/data-model-migration)                                                 |
| Models you already published | Your existing models stay readable                      | They stay readable. New publishes use the new format going forward                                                                                          | [What to do next](/workspaces/data-model-migration)                                                 |
| ACC sync or drag-and-drop    | Uploads use today's data format                         | Uploads move to the new format. If another tool still needs the old format, ask Speckle to turn on compatibility mode. That option ends **1 November 2026** | [Who should pay closer attention](/workspaces/data-model-migration#who-should-pay-closer-attention) |
| Connector updates            | Your current connectors keep working                    | Update them from **1 September 2026**, and no later than **1 November 2026**                                                                                | [What you should do now](/workspaces/data-model-migration#what-you-should-do-now)                   |
| Speckle Intelligence         | It looks at properties on each object                   | It can also see how parts of a model relate to each other — what connects to what, and what contains what                                                   | [What to do next](/workspaces/data-model-migration)                                                 |

This table is a summary. Follow the linked page for steps and dates.

<Note>
  Connector-specific changes for Grasshopper, Revit, or Power BI, and new workspace screens, are not
  listed here yet. Until a v2026.9 page exists for a topic, use the Current docs.
</Note>

## If you build on Speckle

If you use SDKs, APIs, Automate, or a self-hosted server, see
[Data model migration for developers](/developers/migration/data-model-migration). That page covers
SDK updates, compatibility mode for uploads, and when to stay on v2026.8.

## FAQ

<AccordionGroup>
  <Accordion title="Why isn't my connector in the table?">
    Most people who publish and load through Speckle connectors keep the same workflow. Details for
    Grasshopper, Revit, or Power BI will appear in those connector guides when they are ready.
  </Accordion>
  <Accordion title="What if I cannot find a v2026.9 page for something I use?">
    Use the Current documentation. If this preview has no page for that topic yet, the feature is
    still in the Current docs. It did not go away.
  </Accordion>
  <Accordion title="Do I need compatibility mode if I only publish from desktop connectors?">
    No. Compatibility mode is only for ACC sync and drag-and-drop uploads when another tool still
    expects the old format. It ends on **1 November 2026**. See [Who should pay closer
    attention](/workspaces/data-model-migration#who-should-pay-closer-attention).
  </Accordion>
</AccordionGroup>
