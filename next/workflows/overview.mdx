## What still applies

These Current guides still describe the outcome. Use them for the repeatable pattern. Switch to
the 2026.9 pages below when a step hits the new viewer, Intelligence, or a dump-host connector.

- [Design review](/workflows/design-review-workflow) — saved views, federation, markups, and
  issues. In 2026.9 the viewer chrome is different: see [3D viewer in
  2026.9](/next/3d-viewer/introduction).
- [Model validation](/workflows/model-validation-workflow) — rules and dashboards. Workspace
  **Intelligence** still opens dashboards. Chat is a separate surface: see [Ask questions about
  your models with Speckle Intelligence](/next/analytics/intelligence).
- [Grasshopper componentised pipeline](/workflows/grasshopper-componentised-workflow) — modules
  that hand off data through Speckle models. Node names, Explore, and script upgrades are on
  [Grasshopper in 2026.9](/next/connectors/grasshopper/introduction) and [Upgrade Grasshopper to
  2026.9](/next/connectors/grasshopper/upgrading).
- [Revit room data extraction](/workflows/revit-room-data-extraction-specklepy) — pull room data
  with SpecklePy. Revit placement and Apply Transform are on [Revit in
  2026.9](/next/connectors/revit/introduction).
- [SpecklePy model analytics](/workflows/specklepy-model-data-analytics) — load published data
  into DuckDB. Publish and load still follow the Current connector guides unless your host has a
  2026.9 page. See [Connectors in 2026.9](/next/connectors/overview).
- [Grasshopper design explorer](/workflows/grasshopper-design-explorer) — compare alternatives from
  Grasshopper. Do not treat that page as a 2026.9 rewrite. Explore and related connector changes
  live under [Grasshopper in 2026.9](/next/connectors/grasshopper/introduction).

Mapping Speckle data to native families and types is still coming soon on Current. This preview
does not add that tutorial.

## What 2026.9 changes in those outcomes

- **Viewing** — hybrid load, docked **Selection** / **Filters** / **Views**, and section planes.
  See [3D viewer in 2026.9](/next/3d-viewer/introduction).
- **Intelligence** — Chat in the project sidebar and the viewer sparkle. Workspace **Intelligence**
  is still dashboards. See [Ask questions about your models with Speckle
  Intelligence](/next/analytics/intelligence).
- **Connectors** — Revit Apply Transform, Grasshopper Explore, and Power BI Get Tables. See
  [Connectors in 2026.9](/next/connectors/overview), [Revit in
  2026.9](/next/connectors/revit/introduction), [Grasshopper in
  2026.9](/next/connectors/grasshopper/introduction), and [Power BI in
  2026.9](/next/connectors/power-bi/introduction).

Until a 2026.9 page exists for another step, use the Current workflow guide.
