Use this section when you manage Speckle for an organisation. It covers the 2026.9 dates that
differ from the current IT guides, the workspace-wide **AI features** switch, and workspace
Settings and Usage for workspace admins. For
firewall rules, SSO, connector installation, and cloud integrations, see the [IT Setup
Guide](/it-admin/setup).

2026.9 does not change how you install connectors, configure SSO, or enable ACC and ProjectWise.
Trimble Connect is new in 2026.9: a workspace admin connects a Trimble **service account** in the
project sidebar — there is no separate ACC Hub-style enablement step. See [Sync models from Trimble
Connect](/next/connectors/cloud-integrations/trimble-connect).

Two dated actions do change:

- Request **compatibility mode** before **1 November 2026** if ACC sync or drag-and-drop uploads
  feed a downstream tool that still needs the old data format.
- Plan a **connector upgrade window** from **1 September 2026**, and complete it no later than
  **1 November 2026**.

Those actions are not a freeze of desktop connectors. Publish and load continue. Compatibility
mode applies only to ACC sync and drag-and-drop uploads.

## Turn AI features off for the workspace

Speckle Intelligence is available when the workspace plan includes it. A workspace admin can turn
**AI features** off for the whole workspace from workspace **Settings**, then **General**. Only
workspace admins can change this switch; members and guests can open the General page but cannot
change it.

{/* IMAGE_PLACEHOLDER: Workspace Settings → General with the AI features switch turned off. */}

When AI features are off, **Chat** and the sparkle control in the 3D viewer are unavailable to
everyone in the workspace, so nobody can start a conversation or spend AI credit. Turn the switch
back on the same way to restore access.

The switch is a workspace setting, not a plan change. It applies to one workspace, so if your
organisation runs several workspaces, turn AI features off in each one. To remove Speckle
Intelligence from the plan itself, use **Settings**, then **Billing and plans**, or contact us.

<Note>
  On Speckle Enterprise Server, Intelligence is also controlled by the licence. See [Enterprise
  license — Intelligence](/developers/server/deployment/enterprise-license#optional-intelligence).
</Note>
