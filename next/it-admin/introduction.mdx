Use this section when you manage Speckle for an organisation. It covers the 2026.9 dates that
differ from the current IT guides, plus workspace Settings and Usage for workspace admins. For
firewall rules, SSO, connector installation, and cloud integrations, see the [IT Setup
Guide](/it-admin/setup).

2026.9 does not change how you install connectors, configure SSO, or enable ACC and ProjectWise.
Two dated actions do change:

- Request **compatibility mode** before **1 November 2026** if ACC sync or drag-and-drop uploads
  feed a downstream tool that still needs the old data format.
- Plan a **connector upgrade window** from **1 September 2026**, and complete it no later than
  **1 November 2026**.

Those actions are not a freeze of desktop connectors. Publish and load continue. Compatibility
mode applies only to ACC sync and drag-and-drop uploads.

## What to do

| Date                   | What you do                                                                                        | Learn more                                                            |
| ---------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 1 September 2026       | Start rolling connector updates across the estate.                                                 | [Plan the connector upgrade window](/next/it-admin/connector-updates) |
| Before 1 November 2026 | If ACC sync or drag-and-drop still needs the old format, ask Speckle to enable compatibility mode. | [Compatibility mode](/next/it-admin/compatibility-mode)               |
| 1 November 2026        | Finish connector updates. Compatibility mode ends.                                                 | [Compare Current and 2026.9](/next/whats-new)                         |

For the user-facing migration steps, see [Speckle's data model is changing](/workspaces/data-model-migration).

<Note>
  Setup, security, support mode, and cloud-integration pages are unchanged. Switch to **Current** in
  the version selector for those guides.
</Note>
