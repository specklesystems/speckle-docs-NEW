When a workspace moves to the 2026.9 data model, ACC sync and drag-and-drop uploads write the new
format by default. If a script, report, or other tool still expects the old format, that connection
can break. Compatibility mode keeps those uploads in the old format while you update the
downstream tool.

For ACC hub setup that does not change, see [Enable Autodesk Forma Data Management
integration](/it-admin/integrations/acc). For the user-facing migration steps, see [Speckle's data
model is changing](/workspaces/data-model-migration).

<Warning>
  Compatibility mode is a temporary bridge. It is available until **1 November 2026**. It is not a
  freeze of desktop connectors, and it does not pause ordinary publish and load.
</Warning>

## When to request it

Request compatibility mode when all of the following are true:

- The workspace uses **ACC sync** or **drag-and-drop uploads**.
- Something downstream of Speckle depends on the old data format.
- You cannot update that downstream tool before the workspace starts writing the new format.

Do not request it only because connectors are still on an older release. Connector upgrades have
their own window. See [Plan the connector upgrade window](/next/it-admin/connector-updates).

## As a workspace admin

Identify whether any project uses ACC sync or drag-and-drop, and whether any script, custom report,
or other tool reads that data in the old format. If it does, ask Speckle to switch the workspace
into compatibility mode before **1 November 2026**.

After Speckle confirms the workspace is in compatibility mode, ACC sync and drag-and-drop continue
to write the old format until you migrate off, or until **1 November 2026**, whichever comes first.

Contact Speckle in-app, through [speckle.community/help](https://speckle.community/help), or via
your Customer Success Advisor.

## As an IT administrator

Compatibility mode does not change ACC hub enablement, firewall allowlists, or connector
installers. Keep using the [IT Setup Guide](/it-admin/setup) for those tasks.

Find ACC sync and drag-and-drop consumers before **1 November 2026**, and treat compatibility mode
as a dated exception, not as the long-term estate position.

## After 1 November 2026

Speckle no longer offers compatibility mode after this date. New ACC sync and drag-and-drop
uploads then use the new data format. Downstream tools that still expect the old format can break
until they are updated.

Existing models stay readable. Desktop connector publish and load are not turned off by this date.

## FAQ

<AccordionGroup>
  <Accordion title="Do we need compatibility mode if we only publish from desktop connectors?">
    No. Compatibility mode is only for ACC sync and drag-and-drop uploads when another tool still
    expects the old format. See [Who should pay closer
    attention](/workspaces/data-model-migration#who-should-pay-closer-attention).
  </Accordion>
  <Accordion title="We use ACC sync, but nothing downstream reads the old format. Do we still request it?">
    No. Request it only when a script, custom report, or other tool depends on the old format and
    you cannot update that tool in time.
  </Accordion>
  <Accordion title="How do we turn compatibility mode on?">
    Ask Speckle to switch the workspace. Use in-app chat,
    [speckle.community/help](https://speckle.community/help), or your Customer Success Advisor. Wait
    until Speckle confirms the workspace is in compatibility mode.
  </Accordion>
  <Accordion title="What happens if we miss 1 November 2026?">
    Compatibility mode is no longer available. New ACC sync and drag-and-drop uploads use the new
    format. Downstream tools that still expect the old format can break until you update them.
  </Accordion>
</AccordionGroup>
