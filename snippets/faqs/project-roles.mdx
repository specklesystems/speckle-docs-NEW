<AccordionGroup>
  <Accordion title="Can non-workspace members have a project role?">
    You can add anyone to a project if your workspace security settings allow it. Someone who is not
    yet a workspace member joins the workspace as a Guest and gets the role you picked. Guests can
    also be given a single folder or file without being added to the whole project.
  </Accordion>
  <Accordion title="Can I assign roles to teams?">
    Yes, with groups. Create a group in **Team** → **Groups**, then share it on a project, folder or
    file with a role. Everyone in the group gets that role there. Groups are turned on per
    workspace.
  </Accordion>
  <Accordion title="What happened to the Contributor and Reviewer roles?">
    They are now called **Editor** and **Viewer**. Everyone who held them keeps the same access.
  </Accordion>
</AccordionGroup>
