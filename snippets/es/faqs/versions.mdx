<AccordionGroup>
  <Accordion title="¿Puedo establecer un estado de aprobación para una versión?">
    Solo puedes configurar el mensaje de versión, que puede ser algo significativo como "Aprobado para su lanzamiento".
  </Accordion>

  <Accordion title="¿Durante cuánto tiempo se almacenan las versiones?">
    Las versiones se almacenan indefinidamente, pero es posible que tengas un límite en la cantidad de versiones que puedes ver, dependiendo de tu plan de espacio de trabajo.
  </Accordion>

  <Accordion title="¿Puedo impedir que otros vean versiones específicas?">
    No, una vez publicada una versión, es visible para todos los usuarios con permiso para ver el modelo.
  </Accordion>

  <Accordion title="¿Puedo impedir que otros borren versiones?">
    Solo el propietario del modelo puede eliminar versiones.
  </Accordion>

  <Accordion title="¿Cuántas versiones puedo publicar?">
    Puedes publicar tantas versiones como quieras, pero es posible que tengas un límite en cuanto a la cantidad que puedes ver.\
  </Accordion>

  <Accordion title="Ya publiqué una versión, ¿aún puedo configurar o editar su mensaje de versión?">
    Sí, puedes configurar o editar el mensaje de versión para cualquier versión desde la página del historial de versiones.
  </Accordion>

  <Accordion title="No puedo ver versiones anteriores">
  Todas las versiones anteriores se almacenan indefinidamente, pero pueden ocultarse según los límites de tu plan de espacio de trabajo.
  </Accordion>
  
  <Accordion title="¿Cómo puedo comparar visualmente las versiones?">
    Puedes comparar dos versiones para ver las diferencias entre ellas. Esto es útil para revisar los cambios,

    o para ver qué cambió entre dos momentos específicos. Puedes hacerlo en el visor 3D; encontrarás más detalles
    en la página [comparar versiones](/3d-viewer/compare-versions).
  </Accordion>
  <Accordion title="¿Cómo elimino una versión?">
    Si publicaste una versión por error, puedes eliminarla. Esto la eliminará del modelo.
    Si eliminas la última versión, la versión anterior se convertirá en la más reciente.
  </Accordion>
  <Accordion title="¿Cómo restauro una versión?">
    No se puede promover una versión específica como la más reciente, pero se puede publicar una nueva versión,
    que se convertirá en la más reciente. O bien, eliminar todas las versiones más recientes. Recibir una versión específica
    y volver a publicarla la restaurará teóricamente, pero este proceso puede tener pérdida de datos, dependiendo del conector. Sería más fiable hacerlo mediante programación.
  </Accordion>

  <Accordion title="¿Cómo configuro un mensaje de versión?">
    En el conector se le solicitará que configure un mensaje de versión al publicar.
  </Accordion>
</AccordionGroup>
