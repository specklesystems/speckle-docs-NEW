  <Accordion title="¿Existe un límite en la cantidad de proyectos que puedo crear?">
    El número de proyectos que puedes crear solo está sujeto a los límites de tu espacio de trabajo.
  </Accordion>

  <Accordion title="¿Puedo eliminar un proyecto?">
    Sí, puedes eliminar un proyecto seleccionándolo en la lista de proyectos, en la página **Configuración** y al pie de **Configuración general**, y haciendo clic en el botón **Eliminar proyecto**.

    En el plan Enterprise, puedes archivar el trabajo inactivo en lugar de eliminarlo.

    Consulta [Archivar y desarchivar proyectos](/workspaces/archived-projects).

    <Warning>

    Eliminar un proyecto es una acción irreversible. Se borrarán todos los datos asociados.

    </Warning>
  </Accordion>
  <Accordion title="¿Puedo archivar un proyecto en lugar de eliminarlo?">
    Sí, en el plan Enterprise. El archivado elimina el proyecto de las listas activas
    sin borrar sus modelos ni versiones, y puede restaurarlo posteriormente cuando
    sea necesario. Consulte [Archivar y desarchivar proyectos](/workspaces/archived-projects).
  </Accordion>
  <Accordion title="¿Puedo cambiar el nombre de un proyecto?">
    Sí, si eres el propietario del proyecto, puedes cambiarle el nombre seleccionándolo
    en la página de la lista de proyectos y haciendo clic en el botón **Cambiar nombre del proyecto**.
  </Accordion>
  <Accordion title="¿Puedo mover un proyecto a otro espacio de trabajo?">
    No, no en la interfaz web. Si esto es algo que necesita con urgencia,
    contáctenos a través del chat de la aplicación o por correo electrónico a support@speckle.com.
    Un proyecto creado durante la época de proyectos personales se puede migrar una sola vez a un
    espacio de trabajo.

    <Warning>

    **Importante:** Todos los proyectos personales se eliminarán permanentemente el **1 de enero de 2026**.
    Si tiene proyectos personales, migrelos a un espacio de trabajo antes de esta fecha límite.

    </Warning>
  </Accordion>
  <Accordion title="Si cambio el nombre de un proyecto, ¿se estropeará algo?">
    No, no causará ningún problema. Lo único que se verá afectado es el nombre del proyecto.
  </Accordion>
  
  <Accordion title="¿Puedo imponer convenciones de nomenclatura para los nombres de los proyectos?">
    No, no se pueden imponer convenciones de nomenclatura a los nombres de los proyectos.
  </Accordion>
  
  <Accordion title="¿Puedo cambiar la descripción de un proyecto?">
    Sí, puedes cambiar la descripción de un proyecto seleccionándolo en la página de la lista de proyectos y haciendo clic en el botón **Editar proyecto**.

  <Accordion title="¿Existe un límite en el número de miembros de un proyecto?">
    No, no hay límite en el número de miembros de un proyecto. Sin embargo, dependiendo de tu **plan de espacio de trabajo**, es posible que se te cobren cargos adicionales por los miembros del proyecto que no estén ya en tu espacio de trabajo.
  </Accordion>
  
  <Accordion title="¿Cómo puedo hacer público mi proyecto (o modelo)?">
    Para hacer público un proyecto, debes cambiar su configuración de visibilidad. La visibilidad se controla a nivel de proyecto, lo que significa que todos los modelos dentro del proyecto heredarán la misma configuración de visibilidad.

    Para hacer público tu proyecto:

    1. Accede a tu proyecto en la aplicación web de Speckle.

    2. Abre la configuración del proyecto (normalmente accesible mediante un icono de configuración o un menú de engranaje).

    3. Busca la sección **Visibilidad** o **Control de acceso**.

    4. Cambia la configuración de visibilidad de **Privado** o **Espacio de trabajo** a **Público**.

    5. Guarda los cambios.

    Una vez configurado como **Público**, cualquier persona con el enlace del proyecto podrá ver y **descargar todos los datos del proyecto**, incluso sin una cuenta de Speckle. Esto incluye:

    - Visualización del proyecto en la interfaz web

    - Acceso a todos los datos del modelo mediante la API de Speckle

    - Descarga de datos mediante SDK (como `specklepy`) o conectores (como Rhino/Grasshopper)

    - Recuperación de todas las propiedades, metadatos y geometría

    <Warning>

    **Importante:** Los proyectos públicos son datos públicos. Cualquier persona con el enlace puede descargar y recuperar programáticamente todos los datos, propiedades y metadatos del modelo sin autenticación. Esto es intencional y no se puede restringir. Si necesita compartir únicamente la visualización 3D protegiendo los datos subyacentes, considere crear un proyecto independiente con solo la geometría de visualización (sin propiedades ni metadatos) antes de hacerlo público.

    </Warning>
  </Accordion>
  <Accordion title="¿Es posible descargar o acceder a proyectos públicos mediante programación?">
    Sí. Los proyectos públicos son accesibles sin autenticación, lo que significa que cualquier persona con el enlace del proyecto puede:

    - Ver el proyecto en la interfaz web

    - Descargar todos los datos del modelo mediante la API de Speckle

    - Acceder a los datos mediante programación utilizando SDK (Python, .NET, TypeScript) o conectores (Rhino, Grasshopper, Revit, etc.)

    - Recuperar todas las propiedades, metadatos e información geométrica

    Esto es intencional: los proyectos públicos son datos públicos. No hay forma de restringir el acceso programático manteniendo un proyecto público. La API de Speckle y todos los conectores pueden acceder a los datos de proyectos públicos sin necesidad de tokens de autenticación.

    Si necesitas compartir visualizaciones 3D en un sitio web protegiendo los datos subyacentes de tu modelo, considera lo siguiente:

    - Crear un proyecto independiente que contenga únicamente la geometría de visualización (sin propiedades ni metadatos).

    - Usar un proyecto **privado** con colaboradores específicos en lugar de hacerlo público.

    - Incrustar un proyecto privado con acceso mediante tokens. Ten en cuenta que los tokens de incrustación aún pueden usarse para acceder a los datos del proyecto a través de la API.

    <Warning>

    Si incrustas un modelo Speckle público en un sitio web, cualquier persona puede extraer la URL del proyecto y descargar los datos completos del modelo usando las herramientas de Speckle o la API. Asegúrate de estar conforme con que todos los datos del proyecto sean accesibles públicamente antes de hacerlo público.

    </Warning>
  </Accordion>
