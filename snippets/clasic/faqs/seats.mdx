<AccordionGroup>
  <Accordion title="How can I upgrade from a free plan?">
    You can upgrade your workspace to a paid plan from Settings -> Billing.
    Contact us at hello@speckle.systems if you need help choosing the right
    plan for your needs.
  </Accordion>
  <Accordion title="What happens if I change a user's project role?">
    Workspace admins and project owners can change project roles. Changing a
    user from **Can edit** to **Can view** removes publish/load capability, but
    the user remains in the project and workspace. This does not affect
    billing. Plans are based on total users, not project role.
  </Accordion>
  <Accordion title="Can I remove users from my workspace?">
    Yes, workspace admins can remove users from Settings -> People. Removing a
    user does not immediately free up a user slot if you're at your plan's
    limit - the user count adjusts when you add new users or upgrade your plan.
  </Accordion>
</AccordionGroup>
