<Accordion title="Why is the Speckle plugin not showing up after I installed the connector?">
    1. Make sure your version of {app} is one of the supported versions.
    2. Uninstall and [reinstall your connector](/connectors/installation).

    <Note>
      Don't select **Run as administrator** when installing: that installs the connector for the
      administrator account, not yours. Double-click the `.exe`, or right-click it and select **Open**.
    </Note>

    Installation issues can also be caused by conflicting plugins.

    If you're still experiencing problems, report it in our [Community Forum](https://speckle.community/c/help) and include:

    - Your application version
    - Your Speckle connector version

</Accordion>

<Accordion title="What should I do if the plugin UI is empty or unresponsive, or if my application crashes?">
  If your connector window is floating, **try docking it to your application** to fix blank UI
  issues. For major issues, you can sometimes find a `log` file in your directory at
  `AppData\Roaming\Speckle\Logs`. Report your problem in our [Community
  Forum](https://speckle.community/c/help) and include your application version, your Speckle
  connector version, and a copy of the log.
</Accordion>

<Accordion title="Why can't I add a new account?">
  Signing in opens a browser page for your Speckle server. If it doesn't open, or it never returns
  you to the connector, check that you can reach your server in your browser, update the connector
  to the latest version, and try again.
</Accordion>

<Accordion title="My connector asks for Speckle Desktop Services. What do I do?">
  Older connector versions sign in through Speckle Desktop Services, which is deprecated. Update the
  connector to the latest version. If you must stay on the older version, search for **Speckle
  Desktop Services** in Windows search and run it before signing in.
</Accordion>

<Accordion title="How do I uninstall my connector?">
  All Speckle connectors are installed like any other program. You can uninstall them directly from
  your system's `Applications`. For a full uninstall, also remove **Speckle Desktop Services** if it
  is installed.
</Accordion>

<Accordion title="How do I update my connector to the latest version?">
  You can always download the latest version of the connector [in the web
  app](https://app.speckle.systems/connectors). If a new version of the connector is available, you
  will also see a notification in your connector UI.
</Accordion>
