## Using Third-Party Connectors

Third-party connectors typically use the same Desktop UI (DUI) interface as Speckle's official connectors. This means the publish and load workflows are similar across applications.

For general discussions about how this integrates with the Speckle ecosystem, visit the [Speckle community forum](https://speckle.community/).
