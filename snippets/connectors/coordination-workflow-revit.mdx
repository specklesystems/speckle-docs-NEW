<Note>
  Reference point options apply only to Revit (`.rvt`) files, in uploads and in Forma Data
  Management (ACC) syncs. Other formats, including IFC and Navisworks, are placed using the
  coordinates saved in the file. To load a model into Revit at a chosen reference point, use the
  [Revit connector](/connectors/revit/revit#model-placement).
</Note>
