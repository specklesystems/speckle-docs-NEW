When an update is available, a notifications will be shown in the Connector's UI.

For IT managed environments where the end-user is not empowered to update connectors, these notifications can be
disabled by writing a registry key in either `HKEY_CURRENT_USER\Software\Speckle\Connector Config\Global` or `HKEY_LOCAL_MACHINE\Software\Speckle\Connector Config\Global`

- Value name:   `SPECKLE_IS_UPDATE_NOTIFICATION_DISABLED`
- Value type:   `REG_SZ`
- Value data:   `True`
