Speckle's legacy (v2) connectors and Speckle Manager are retired. They are no longer supported or
updated, and there is no guarantee they work with the current server. The guides for them and for
the v2-to-v3 migration have been removed.

Models you published with them stay readable in Speckle.

## Use the current connectors

Install and update connectors from the web app. See [Connectors](/connectors/overview) and
[Install connectors](/connectors/installation).

## Questions about legacy connectors

Post any question about v2 connectors, Speckle Manager or migrating older work in the
[help channel on the Speckle community forum](https://speckle.community/c/help).
