<Danger>Legacy connectors were deprecated on 1 January 2026.</Danger>

Since that date:

- Legacy connector installers and Speckle Manager are no longer available.
- Legacy connectors are not supported, and Speckle offers no forum support for them.
- Current connectors do not maintain backwards compatibility with legacy models.

[Assess your workflow](#assess-your-workflow), then [start your migration](#migration-steps) if your
workflow is supported. [Get help](#get-migration-support) if it is not.

## Assess your workflow

Before migrating, determine if your workflow is supported in V3 connectors.

### ✅ Migrate to V3 now

These workflows have full support in V3 connectors:

| Workflow                      | Migration status | Notes                                                                     |
| ----------------------------- | ---------------- | ------------------------------------------------------------------------- |
| SketchUp ↔ Revit              | ✅ Full support  | Migrate now                                                               |
| Blender (all workflows)       | ✅ Full support  | Migrate now                                                               |
| Power BI                      | ✅ Full support  | Migrate now                                                               |
| Revit ↔ Rhino (direct shapes) | ✅ Supported     | Use V3's assign category feature ([guide](/connectors/rhino/rhino-revit)) |
| Revit → Revit (direct shapes) | ✅ Supported     | Works with direct shapes only                                             |

**Next step:** [Start migration](#migration-steps)

### ⏸️ Continue with legacy connectors

These workflows have no v3 equivalent. The legacy connectors that served them are no longer
supported:

Connectors without V3 versions:

| Connector        | Status         | Action                                          |
| ---------------- | -------------- | ----------------------------------------------- |
| Excel            | ⏸️ Legacy only | No v3 connector                                 |
| QGIS             | ⏸️ Legacy only | No v3 connector                                 |
| Unity            | ⏸️ Legacy only | No v3 connector                                 |
| Unreal Engine    | ⏸️ Legacy only | No v3 connector                                 |
| Dynamo           | ⏸️ Legacy only | No v3 connector                                 |
| SAP2000          | ⏸️ Legacy only | No v3 connector                                 |
| Advance Steel    | ⏸️ Legacy only | No v3 connector                                 |
| Bentley products | ⏸️ Legacy only | MicroStation, OpenRoads, OpenRail, OpenBuilding |

Native BIM element workflows:
These workflows loaded models as native BIM elements and have no v3 equivalent:

| From                      | To                      | Status         |
| ------------------------- | ----------------------- | -------------- |
| Rhino mapper              | Revit                   | ⏸️ Legacy only |
| Grasshopper BuiltElements | Revit                   | ⏸️ Legacy only |
| Revit                     | Revit (native elements) | ⏸️ Legacy only |
| Civil 3D                  | Revit                   | ⏸️ Legacy only |

Platform limitations:

- Mac versions of Rhino and ArchiCAD had legacy connectors only

What to do:

1. Do not start new projects with legacy connectors.
2. Contact your workspace administrator if you need custom migration assistance (paid workspaces only)

## Migration steps

<Steps>
<Step title="Remove legacy connectors">  
Uninstall old Speckle plugin files from your authoring tool or remove them via your plugin manager.
</Step>

<Step title="Install V3 connectors">
  Visit the [V3 connectors page](/connectors/overview) for downloads and installation instructions.
</Step>

<Step title="Create workspace projects">
  V3 connectors require workspace-based projects. - Navigate to your workspace in the Speckle web
  interface - Create a new project for each workflow you want to upgrade
</Step>

<Step title="Send your data">
  Because legacy and V3 connectors use different data models, you need to resend your models: - Open
  your model in your authoring tool (for example, Revit, Rhino, SketchUp) - Use the V3 connector to
  send your model to the newly created project
</Step>

<Step title="Test and verify">
- Open the new project in the Speckle web interface to verify your data  
- Update any scripts or automation tools to work with the new workspace project structure  
- Test receiving workflows in destination applications to ensure compatibility
</Step>
</Steps>

## Get migration support

Visit our [Community Forum](https://speckle.community) for migration questions and tips.

Documentation:
Explore connector-specific guides in the [Connectors section](/connectors/overview).

Paid workspace support:
Contact your workspace administrator to arrange dedicated migration assistance.

## Why upgrade to V3

V3 connectors offer significant improvements:

- **Faster and more reliable** performance
- **Expanded property support** and consistent schemas across connectors
- **Workspace-based projects** that enable true team collaboration
- **Direct integration with Speckle Intelligence** to turn design data into actionable project insights
