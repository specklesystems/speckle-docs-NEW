Speckle's next-gen connectors (V3) offer faster performance, expanded features, and a unified data model. This guide helps you migrate your workflows from legacy connectors to the next-gen environment.

## Why upgrade

<Icon icon="check"/> Next-gen connectors are faster and more reliable  
<Icon icon="check"/> Expanded property support and consistent schemas  
<Icon icon="check"/> Designed for workspace-based projects, enabling true collaboration  
<Icon icon="check"/> Direct integration with **Speckle Intelligence**, turning your design data into actionable project insights

## Legacy connector deprecation

<Danger>
  On January 1, 2026, all legacy connectors will be officially deprecated.
</Danger>

After this date:
- Legacy connector installers and Speckle Manager will be removed from https://releases.speckle.systems/legacy-connectors
- Already installed legacy connectors will continue to work locally
- No active forum support will be provided
- Current connectors will no longer maintain backwards compatibility with legacy models

**If you need to continue using legacy connectors temporarily**

1. Download and save any installers you need before January 1, 2026
2. Avoid starting new projects with legacy connectors
3. Plan to complete existing legacy projects as soon as possible

<Info>
**For paid workspace users**

Contact your workspace administrator to discuss custom migration assistance options.
</Info>

## Understand your migration path

Before migrating, identify which category your workflow falls into.

### Category 1: Directly replaceable workflows

These workflows have equivalent functionality in next-gen connectors and should be migrated now:

- **Revit ↔ Rhino**  
  If you only need to map direct shapes, use V3's assign category feature (see [Rhino-Revit guide](/connectors/rhino/rhino-revit)). Workflows requiring native element mapping fall under Category 2.
  
- **Revit → Revit**  
  Supported if you're comfortable working with direct shapes. Native element workflows fall under Category 2.
  
- **SketchUp ↔ Revit**  
  Fully supported in next-gen connectors.
  
- **Blender workflows**  
  All Blender workflows can be migrated to next-gen connectors.
  
- **Power BI workflows**  
  Fully compatible with next-gen connectors.

### Category 2: Legacy-only workflows

These workflows currently don't have direct next-gen equivalents:

**Connectors without next-gen versions**
- Excel
- QGIS
- Unity
- Unreal Engine
- Dynamo
- SAP2000
- Advance Steel
- Bentley products (MicroStation, OpenRoads, OpenRail, OpenBuilding)

**Workflows requiring legacy connectors**
- Loading models into Revit as native BIM elements. Applies to:
  - Rhino mapper → Revit
  - Grasshopper BuiltElements nodes → Revit
  - Revit → Revit
  - Civil 3D → Revit
  - and similar workflows
- Any workflows using the legacy-only connectors listed above
- Workflows using Mac versions of Rhino and ArchiCAD

<Info>
  If your workflow falls under Category 2, download the necessary installers before January 1, 2026, and begin planning alternative approaches or timeline adjustments for your projects.
</Info>

## Migration steps

<Steps>
<Step title="Assess your workflows">  
Review the categories above to determine which of your workflows can be directly migrated and which may require alternative approaches.
</Step>

<Step title="Remove legacy connectors">  
Uninstall the old Speckle plugin files from your authoring tool or remove them via your plugin manager.
</Step>

<Step title="Install next-gen (V3) connectors">  
Visit the [next-gen connectors page](/connectors/overview) for downloads and installation instructions.
</Step>

<Step title="Create workspace projects">
Next-gen connectors require workspace-based projects.  
- Navigate to your workspace in the Speckle web interface  
- Create a new project for each workflow you want to upgrade
</Step>

<Step title="Send data using next-gen connectors">
Because legacy and next-gen connectors use different data models, migration requires re-sending your models:  
- Open your model in your authoring tool (for example, Revit, Rhino, SketchUp)  
- Use the next-gen connector to send your model to the newly created project
</Step>

<Step title="Validate and adjust workflows">
- Open the new project in the Speckle web interface to verify your data  
- Update any scripts or automation tools to work with the new workspace project structure  
- Test receiving workflows in destination applications to ensure compatibility
</Step>
</Steps>

## What to do during the migration period

**For Category 1 workflows**
- Begin migration testing as soon as possible
- Republish all legacy models using next-gen connectors
- Active forum support is available during this period to assist with migration questions

**For Category 2 workflows**
- Download any necessary installers and save them securely
- Complete existing projects on your current timeline
- Avoid initiating new projects with legacy connectors
- Contact us if you're part of a paid workspace to explore custom migration options

## Get migration support

We're here to help make your transition smooth:

- **Community support** Visit our [Community Forum](https://speckle.community) for migration questions and tips
- **Documentation** Explore connector-specific guides in the [Connectors section](/connectors/overview)
- **Paid workspace support** Contact your workspace administrator to arrange dedicated migration assistance
