## Getting Started

### Prerequisites

- An active Autodesk Construction Cloud account with admin access
- A Speckle account with beta access
- ACC files in `.rvt` format (only supported format currently)

### Step 1: Setup ACC Integration

1. Navigate to your Account Admin page at [acc.autodesk.eu](http://acc.autodesk.eu)
2. Go to **Custom Integrations** under the Account Admin panel
3. Click **Add custom integrations**
4. Fill in the integration details:
   - **Client ID**: `5Y2LzxsL3usaD1xAMyElBY8mcN6XKyfHfulZDV3up0jfhN5Y`
   - **Name**: `Speckle`
5. Save the integration

<Frame>
<img src="/images/beta/acc/acc-integration-setup.png"/>
</Frame>

### Step 2: Authorize ACC Account in Speckle

1. Go to your Speckle project and navigate to the **ACC** tab
2. Click **Authorize** to connect your ACC account
3. Complete the OAuth flow by clicking **Allow** in ACC
4. Verify your profile information appears

<Frame>
<img src="/images/beta/acc/acc-profile-info.png"/>
</Frame>

### Step 3: Create Sync Models

1. Click **New sync** to create a new sync model
2. Browse and select your Hub → Project → `.rvt` file
3. Confirm your selection to start the sync

<Frame>
<img src="/images/beta/acc/acc-file-selection-confirmation.png"/>
</Frame>

Watch the sync progress and view your ACC data in Speckle once complete.

## Frequently Asked Questions

<AccordionGroup>
<Accordion title="What file formats are supported?">
Currently, only `.rvt` (Revit) files are supported. Additional formats like `.dwg`, `.ifc`, and `.nwd` are planned for future releases. Contact us if you need support for other file types.
</Accordion>

<Accordion title="Is the connection read-only?">
Yes, Speckle establishes a read-only connection with ACC. This means Speckle can sync and analyze your data but cannot modify the original ACC files, ensuring data integrity and security.
</Accordion>

<Accordion title="How often do files sync?">
Once a sync model is created, it automatically syncs whenever a new version of the file is published to ACC. No manual intervention is required for ongoing synchronization.
</Accordion>

<Accordion title="Can I create multiple syncs from the same file?">
Yes, you can create multiple sync models from the same ACC file. Each sync must be linked to a single Speckle model within the project, allowing you to sync the same ACC file to different Speckle models.
</Accordion>

<Accordion title="What if my sync fails?">
Common causes include file access issues, authorization problems, or unsupported file formats. Check that the ACC file is accessible, verify your permissions, and ensure the file is in `.rvt` format. Contact support if issues persist.
</Accordion>

<Accordion title="How do I get beta access?">
Contact us at [office@speckle.systems](mailto:office@speckle.systems) to request beta testing access. We're actively looking for feedback to improve the integration.
</Accordion>

<Accordion title="What's the difference between ACC integrationand other integrations?">
The ACC cloud integration provides direct integration with Autodesk Construction Cloud, enabling automatic synchronization of construction data. Unlike other integrations that require manual file uploads or use of connectors, ACC syncs happen automatically when files are updated in the cloud.
</Accordion>

<Accordion title="Can I use ACC data with Speckle Intelligence?">
Yes! Once synced, your ACC data can be used with Speckle Intelligence for analytics, dashboard creation, and generating insights from your construction data.
</Accordion>
</AccordionGroup>
