# Autodesk Construction Cloud (ACC) Integration

<Note>
**Private Beta**: The ACC integration is currently in private beta testing. This integration will sync Autodesk Construction Cloud models to Speckle for intelligence and automation workflows.
</Note>

## What is the ACC Integration?

The ACC integration will sync models from Autodesk Construction Cloud to Speckle. This allows ACC models to be used with Speckle Intelligence for analytics and dashboard creation, and enables automation workflows using ACC data.

## Current Status

The ACC integration is currently in private beta testing. Documentation is being prepared.

**Expected Release**: Q4 2025
