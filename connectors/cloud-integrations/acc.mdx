## Setup

These steps assume the Speckle integration has already been enabled on your organisation's ACC Hub for Forma Data Management. If it hasn't, your IT administrator must complete [Enable Autodesk Forma Data Management integration](/it-admin/integrations/acc) first.

{/* IMAGE_PLACEHOLDER: Project sidebar Integrations → ACC page — Connect to ACC before sign-in; then hub and project selectors, folder tree, selected files panel with Create sync. */}

<Steps>
  <Step title="Open ACC in your project">
    Open the project in Speckle, then select **Integrations** → **ACC** in the project sidebar. You
    should see **Connect to ACC** the first time.
  </Step>
  <Step title="Sign in to Autodesk">
    Select **Connect to ACC**, sign in to your Autodesk account, and select **Allow** in the
    authorization dialog. You should see your hubs and projects in the selectors at the top.
  </Step>
  <Step title="Pick files to sync">
    Choose a hub and project, browse the folders, and select the files you want to sync. For Revit
    files, optionally set the reference point and what to publish. See [Revit
    options](#revit-options).
  </Step>
  <Step title="Create the sync">
    Select **Create sync**. Each file gets its own Speckle model, and changes in Autodesk cloud
    storage sync automatically. You should see the new syncs in the **Syncs** panel.
  </Step>
</Steps>

## Supported file formats

Cloud sync accepts the same file formats as file uploads. See [Supported file
formats](/connectors/direct-uploads/introduction#supported-file-formats).

<Note>
  ACC sync writes the 2026.9 data format. If a script or report downstream of Speckle still needs
  the earlier format, your workspace can use compatibility mode until **1 November 2026**, and it
  accepts fewer formats. See [Compatibility mode](/it-admin/compatibility-mode) and [Speckle's new
  data model](/workspaces/data-model-migration).
</Note>

<Info>
  Navisworks files (`.nwc` and `.nwd`) are supported for manual upload and Forma Data Management
  sync. Many Autodesk (and other) products can export Navisworks Cache files without requiring a
  Navisworks license, so you can upload those exports to Speckle.
</Info>

<Note>
  ACC sync has no fixed file-size limit, unlike the **2 GB** direct upload limit. Very large files
  can stress the conversion process: Speckle monitors the conversion queue and scales resources to
  demand, but a single conversion that exceeds the capacity of one conversion process can fail. If
  that happens, we follow up with you. If you plan to sync files around **5 GB** regularly, [talk to
  us](mailto:support@speckle.systems) first.
</Note>

## Import earlier versions

{/* IMAGE_PLACEHOLDER: the Import earlier versions dialog from a sync's settings — the version list with synced versions marked and a few earlier versions ticked. */}

A sync starts at the file version current when you create it. When the file already had a history in Forma Data Management, or a version failed to sync and a newer one has been published since, you can bring those earlier versions into the same Speckle model yourself.

<Note>
  The import is not offered when:

- the version is older than the version history your plan keeps
- you lack the permission to edit the sync
- the sync is paused
- the workspace runs in [compatibility mode](/it-admin/compatibility-mode)

</Note>

<Steps>
  <Step title="Open the sync's settings">
    Open the model and expand the settings on its sync card.
  </Step>
  <Step title="Select Import earlier versions">
    A dialog lists the file's versions as Forma Data Management records them, newest first. Versions
    already synced or currently syncing are marked and cannot be selected.
  </Step>
  <Step title="Select up to five versions, then Import">
    Each version runs as its own sync attempt, oldest first. You should see the runs appear in the
    sync activity below the card.
  </Step>
</Steps>

An imported version is dated when it was created in Forma Data Management, so it takes its place in the model's history and the newest file version stays the latest version in Speckle. For a longer history, repeat the import in rounds of five.

## Revit options

Expand a selected Revit (`.rvt`) file to set its options before you create the sync. These options
apply only to Revit files.

### Reference point

Choose which Revit coordinate origin the model is aligned to: **Internal Origin** (default),
**Project Base Point**, **Survey Point**, or **Shared Coordinates**. If you are aligning multiple
models, use the same reference point across related Revit syncs to avoid placement mismatches.

<Warning>
  If your workspace uses compatibility mode, do not select **Shared Coordinates**. The older
  conversion path cannot process it and the sync fails. Use **Internal Origin**, **Project Base
  Point**, or **Survey Point** instead.
</Warning>

### What to publish

**Publish method** is **Entire model** by default: all supported elements from the entire model
are synced. This is the recommended option for a complete representation of your model and the
most data for analytics and dashboards.

To sync only part of the model, change the publish method:

- **By View**: enter a view name to sync only the elements visible in that view. The name must match
  a view in your Revit model exactly (case-sensitive). Once you enter a view, you can also choose to
  append rooms, areas, or both.
- **By Category**: pick the Revit categories to sync.

<Warning>
  If the specified view name doesn't exist in the model, the sync will fail. Make sure the view name
  matches exactly.
</Warning>

<AccordionGroup>
  <Accordion title="Is the connection read-only?">
    Yes. Speckle establishes a read-only connection with Autodesk Forma Data Management (ACC), which means we can sync and analyze your data but can't modify the original files. This ensures data integrity and security.
  </Accordion>
  <Accordion title="How often do files sync?">
    Once you've created a sync model, each new version published to Autodesk Forma Data Management triggers one sync attempt. You don't need to manually trigger ongoing synchronization. A version whose attempt fails can be retried from the sync's status until a newer version is published; after that, bring it in with [Import earlier versions](#import-earlier-versions). See [Sync guarantees](/it-admin/integrations/introduction#sync-guarantees).
  </Accordion>
  <Accordion title="Why are my models in the wrong location?">
    For **Revit** ACC syncs, use the reference point in the file's options to control placement for coordination workflows. If the selected reference point does not match your downstream model setup, placement can still appear offset. Reference point options are **not** available for IFC or Navisworks ACC syncs—adjust placement in those workflows using your authoring tool or the relevant connector where applicable.
    For project-by-project control and advanced receive options, you can also use the [Revit connector](/connectors/revit/revit).
  </Accordion>
  <Accordion title="What if my sync fails?">
    Common causes include file access issues, authorization problems, or unsupported file formats. Check that:

    - The file is accessible
    - Your permissions are correct
    - The file is in a [supported format](#supported-file-formats) for your workspace's upload mode

    A failed attempt is not retried automatically. If it is the sync's most recent attempt, retry it
    from the sync's status once the cause is fixed; if a newer version has been published since,
    use [Import earlier versions](#import-earlier-versions) to sync it. See [Sync
    guarantees](/it-admin/integrations/introduction#sync-guarantees). Contact support if issues
    persist.

  </Accordion>
  <Accordion title="Can I use the integration on another plan?">
    The integration is available on the **Enterprise** plan. To use it on another plan, talk to sales at
    [sales@speckle.systems](mailto:sales@speckle.systems).
  </Accordion>
  <Accordion title="What's the difference between the Forma Data Management integration and other integrations?">
    The Forma Data Management (ACC) integration connects Speckle to Autodesk cloud construction data and enables automatic synchronization. Unlike other integrations that require manual file uploads or connectors, cloud syncs happen automatically when files are updated.
  </Accordion>
  <Accordion title="Can I use Autodesk Forma Data Management models with Speckle Intelligence?">
    Yes. Once synced, your models can be used with Speckle Intelligence for analytics, dashboard creation, and generating insights from your construction data.
  </Accordion>
</AccordionGroup>
