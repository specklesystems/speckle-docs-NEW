## Setup

<Steps>
  <Step title="Add a custom integration to ACC">
    <Info>
       You’ll need **Account Admin** access to add the Speckle Integration to ACC.
    </Info>
    1. Go to your Account Admin page at [acc.autodesk.eu](http://acc.autodesk.eu/)
    2. Select **Custom Integrations** under the Account Admin panel
    3. Select **Add custom integrations**
    4. Enter the integration details:

       <Frame>
         ![](/images/beta/integrations/acc-add custom integration.png)
       </Frame>
       - **Client ID**: `5Y2LzxsL3usaD1xAMyElBY8mcN6XKyfHfulZDV3up0jfhN5Y`
       - **Name**: `Speckle`
    5. Select **Next**.
    6. Select **Proceed Anyway** from the permission warning.

       <Frame>
         ![](/images/beta/integrations/acc-premission warning.png)
       </Frame>
  </Step>
  <Step title="Sign in to Autodesk Construction Cloud">
    1. Select **workspace settings** from the workspace dropdown (top left).

       <Frame>
         ![](/images/beta/integrations/acc-workspace settings.png)
       </Frame>
    2. Select **Log in** next to Autodesk Construction Cloud.

       <Frame>
         ![](/images/beta/integrations/acc-login.png)
       </Frame>
    3. Sign in to your ACC account and select **Allow** from the authorization dialog.

       <Frame>
         ![](/images/beta/integrations/acc-authorize app.png)
       </Frame>

    Your integration is now set up.
  </Step>
  <Step title="Sync your first model">
    1. From your project in Speckle, select **Add model \> Sync from ACC**.

       <Frame>
         ![](/images/beta/integrations/acc-add model.png)
       </Frame>
    2. Select the file you want to sync. Your hubs, projects, folders and files from ACC will be listed here. <Note>
          ACC integration currently syncs only Revit files.
       </Note>

       <Frame>
         ![](/images/beta/integrations/acc-select file.png)
       </Frame>
    3. _Optionally_, define the view to export. If you don’t specify a view name, the 3D view is used by default.
    4. Select **Create**.

    This connects your ACC file to your Speckle model. Changes in ACC sync automatically to Speckle.
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="What file formats are supported?">
    Currently .rvt (Revit) and .ifc files are supported. We're planning to add formats like .dwg and .nwd (Navisworks) in future releases.
  </Accordion>
  <Accordion title="Is the connection read-only?">
    Yes. Speckle establishes a read-only connection with Autodesk Construction Cloud, which means we can sync and analyze your data but can't modify the original files. This ensures data integrity and security.
  </Accordion>
  <Accordion title="How often do files sync?">
    Once you've created a sync model, it automatically syncs whenever a new version of the file is published to ACC. You don't need to manually trigger ongoing synchronization.
  </Accordion>
  <Accordion title="What if my sync fails?">
    Common causes include file access issues, authorization problems, or unsupported file formats. Check that:

    - The ACC file is accessible
    - Your permissions are correct
    - The file is in `.rvt` format Contact support if issues persist.
  </Accordion>
  <Accordion title="How do I get beta access?">
    Contact us at [office@speckle.systems](mailto:office@speckle.systems) to request beta access. We're actively looking for feedback to improve the integration.
  </Accordion>
  <Accordion title="What's the difference between the ACC integration and other integrations?">
    The ACC integration provides direct integration with Autodesk Construction Cloud and enables automatic synchronization of construction data. Unlike other integrations that require manual file uploads or connectors, ACC syncs happen automatically when files are updated in the cloud.
  </Accordion>
  <Accordion title="Can I use ACC data with Speckle Intelligence?">
    Yes. Once synced, your ACC data can be used with Speckle Intelligence for analytics, dashboard creation, and generating insights from your construction data.
  </Accordion>
</AccordionGroup>
