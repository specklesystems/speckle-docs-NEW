## Setup

These steps assume the Speckle integration has already been registered on your organisation's Bentley account. If it hasn't, your IT administrator must complete the steps in [Enabling the integration on ProjectWise (IT Admin)](#enabling-the-integration-on-projectwise-it-admin) first.

<Steps>
  <Step title="Sign in to Bentley ProjectWise">
    1. Select **workspace settings** from the workspace dropdown (top left).
    2. Select **Log in** next to Bentley ProjectWise.
    3. Sign in to your Bentley account and select **Allow** from the authorization dialog.

    Your integration is now set up.

  </Step>
  <Step title="Sync your first model">
    1. From your project in Speckle, select **Add model \> Sync from ProjectWise**.
    2. Select the file you want to sync. Your projects, folders and files from ProjectWise will be listed here.
    3. Select **Create**.

    This connects your ProjectWise file to your Speckle model. Changes in ProjectWise sync automatically to Speckle.

  </Step>
</Steps>

## Enabling the integration on ProjectWise (IT Admin)

If your organisation hasn't registered the Speckle integration with Bentley yet, an IT administrator must complete this step first. After that, users can sign in from Speckle workspace settings and sync projects as described in [Setup](#setup) above.

<Steps>
  <Step title="Register a Speckle application on the Bentley iTwin Portal">
    1. Go to the [Bentley iTwin Developer Portal](https://developer.bentley.com/).
    2. Sign in with your organisation's Bentley account.
    3. Navigate to **My Apps** and select **Register New**.
    4. Choose **Service** as the application type.
    5. Enter the application details:
       - **Name**: `Speckle`
       - **Description**: Speckle ProjectWise integration
    6. Once registered, note down the **Client ID** and **Client Secret** — you will need to share these with Speckle to complete the setup.
    7. Add the Speckle service account email as a member of the relevant ProjectWise projects to grant it access to those files.

    <Note>
      The Speckle service app operates with its own machine identity and only has
      access to projects you explicitly add it to. It does not inherit your
      personal permissions or see any data outside of what you grant.
    </Note>

    Contact [office@speckle.systems](mailto:office@speckle.systems) with your Client ID and Client Secret to finalise the integration setup. Users can then sign in from Speckle workspace settings and sync projects.

  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="Is the connection read-only?">
    Yes. Speckle establishes a read-only connection with Bentley ProjectWise, which means we can sync and analyze your data but can't modify the original files. This ensures data integrity and security.
  </Accordion>
  <Accordion title="How often do files sync?">
    Once you've created a sync model, Speckle automatically detects when a file is updated in ProjectWise and syncs the latest version. There may be a short delay between a file being updated and the new version appearing in Speckle.
  </Accordion>
  <Accordion title="What if my sync fails?">
    Common causes include file access issues, authorization problems, or unsupported file formats. Check that:

    - The file is accessible to the Speckle service account
    - The service account has been added to the relevant ProjectWise project
    - The file is in **.rvt** or **.ifc** format

    Contact support if issues persist.

  </Accordion>
  <Accordion title="How do I get access?">
    Contact us at [hello@speckle.systems](mailto:hello@speckle.systems) to request access.
  </Accordion>
  <Accordion title="What's the difference between the ProjectWise integration and other integrations?">
    The ProjectWise integration provides direct integration with Bentley ProjectWise and enables automatic synchronization of your files. Unlike other integrations that require manual file uploads or connectors, ProjectWise syncs happen automatically when files are updated in the cloud.
  </Accordion>
  <Accordion title="Can I use Bentley ProjectWise models with Speckle Intelligence?">
    Yes. Once synced, your Bentley ProjectWise models can be used with Speckle Intelligence for analytics, dashboard creation, and generating insights from your construction data.
  </Accordion>
</AccordionGroup>
