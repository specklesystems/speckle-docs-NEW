## When to upload files directly

Upload files directly when you:

- Want IFC data in Speckle format
- Don't have access to the source application or license
- Need to view a model quickly in your browser
- Receive files from collaborators who don't use Speckle
- Work with formats that don't have a Speckle connector

## File format details

### IFC

IFC files are converted to Speckle format with full support for attributes, property sets, and quantities.

**Supported versions**
- IFC2x3
- IFC4

**Known limitations**
- IFC2x2_FINAL and Release Candidate versions aren't supported
- Alternative formats (XML, ZIP, databases) aren't supported
- 2D types like IfcAnnotation aren't currently supported
- All geometry is converted to meters for compatibility with other Speckle models

**Features**
- Element and element type attributes
- Property sets
- Element quantities

### DWG and DXF

AutoCAD drawing files can be uploaded directly, though results may vary depending on file complexity.

<Note>
For better results with DWG files, consider using the AutoCAD connector when possible.
</Note>

**Known limitations**
- Complex files may take longer to process
- Some AutoCAD-specific features may not transfer

### Rhino (3DM)

Rhino files maintain geometry and layer structure.

**Known limitations**
- Custom Grasshopper components aren't supported
- Some advanced Rhino features may not transfer

### SketchUp (SKP)

SketchUp models are converted with geometry and basic organization.

<Note>
For better results with SKP files, consider using the SketchUp connector when possible.
</Note>

**Known limitations**
- Dynamic components may not transfer correctly
- Some SketchUp-specific features may not be preserved

## File size and processing

**Upload limits**
- Maximum file size: 1000MB (all plans, all formats)

**Processing time**
- Simple files: A few seconds
- Complex files: Up to 30 minutes
- Files are processed in a queue system

If processing fails after an extended time, the file may contain errors. Report issues in our [Community Forum](https://speckle.community/c/help) with:
- File type and version
- The failed file (if possible)
- Description of the issue

## Frequently asked questions

**Can I download uploaded files?**

File downloads aren't currently available.

**Why is my upload stuck processing?**

Complex files take longer to process. The system may retry processing multiple times before reporting a failure. If your upload fails after 30 minutes, the file may contain errors.

**Will you support additional formats?**

Let us know which formats you'd like to see supported.

**Why are some objects missing from my IFC file?**

2D annotation types aren't currently supported.

**Why are units different in my uploaded IFC model?**

All geometry is converted to meters for compatibility with other Speckle models.
