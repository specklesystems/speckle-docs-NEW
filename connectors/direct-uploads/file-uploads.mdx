Upload files directly to Speckle to quickly share models with your team. This feature lets you work with files from various CAD and 3D modeling applications without installing additional software.

## When to use file uploads

Upload files directly when you:

- Need to convert IFC data to Speckle format
- Don't have the source application or license
- Want to view a model quickly in your browser
- Receive files from collaborators who don't use Speckle connectors
- Work with file formats that don't have a dedicated Speckle connector

## File format details

### IFC

IFC files are converted to Speckle format with support for attributes, property sets, and quantities.

**Supported versions**

- IFC2x3
- IFC4

**Features**

- Element and element type attributes
- Property sets
- Element quantities

**Known limitations**

- IFC2x2_FINAL and Release Candidate versions aren't supported
- Alternative formats such as XML, ZIP, and databases aren't supported
- 2D types like IfcAnnotation aren't currently supported
- All geometry is converted to meters for compatibility with other Speckle models

### DWG and DXF

Upload AutoCAD drawing files directly. Results may vary depending on file complexity.

<Note>
For better results with DWG files, use the AutoCAD connector when possible.
</Note>

**Known limitations**

- Complex files may take longer to process
- Some AutoCAD-specific features may not transfer

### Rhino (3DM)

Rhino files maintain geometry and layer structure when uploaded.

**Known limitations**

- Custom Grasshopper components aren't supported
- Some advanced Rhino features may not transfer

### SketchUp (SKP)

SketchUp models are converted with geometry and basic organization preserved.

<Note>
For better results with SKP files, use the SketchUp connector when possible.
</Note>

**Known limitations**

- Dynamic components may not transfer correctly
- Some SketchUp-specific features may not be preserved

## File size and processing

### Upload limits

Maximum file size: 1000 MB for all plans and formats

### Processing time

- Simple files: A few seconds
- Complex files: Up to 30 minutes
- Files are processed using a queue system

If processing fails after an extended time, your file may contain errors. Report issues in the [Speckle Community Forum](https://speckle.community/c/help) and include:

- File type and version
- The failed file, if possible
- Description of the issue

## Frequently asked questions

### Can I download uploaded files?

File downloads aren't currently available.

### Why is my upload stuck processing?

Complex files take longer to process. The system may retry processing multiple times before reporting a failure. If your upload fails after 30 minutes, your file may contain errors.

### Will you support additional formats?

We're always looking to expand format support. Let us know which formats you'd like to see in future releases.

### Why are some objects missing from my IFC file?

2D annotation types aren't currently supported in IFC uploads.

### Why are units different in my uploaded IFC model?

All IFC geometry is converted to meters to ensure compatibility with other Speckle models.
