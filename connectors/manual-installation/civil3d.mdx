title: Civil 3D - Manual installation

---

<Info>
  **Install separately for each version**: Repeat these steps for each application version you want to use with Speckle.
</Info>

Before you begin, verify that Speckle Desktop Services is running. [Learn more about Desktop Services](/connectors/manual-installation/desktop-services).

## Install for a single user

### Copy connector files

1. Extract the downloaded ZIP file.
2. Copy all contents from `.\Speckle.Connectors.Civil3d{VERSION}\` to `%AppData%\Autodesk\ApplicationPlugins\Speckle.Connectors.Civil3d{VERSION}\`
   - Replace `{VERSION}` with your Civil 3D version (example: `2026`)
   - Create the directory if it doesn't exist

### Configure registry entries

Create registry entries for each Civil 3D version and language code combination you want to support.

<Info>
  **Register all language codes**: Create registry entries for all supported language codes, even if you only use one language. This ensures the connector loads properly regardless of your Civil 3D language settings.
</Info>

#### Supported language codes

- `409` (English - US)
- `407` (German)
- `40C` (French)
- `410` (Italian)
- `40A` (Spanish)
- `415` (Polish)
- `40E` (Hungarian)
- `405` (Czech)
- `419` (Russian)
- `416` (Portuguese - Brazil)
- `804` (Chinese - Simplified)
- `404` (Chinese - Traditional)
- `412` (Korean)
- `411` (Japanese)

#### Registry path structure

For each version and language combination, create registry entries at:

```
HKEY_CURRENT_USER\SOFTWARE\Autodesk\AutoCAD\{ReleaseVersion}\{AcadVersion}:{LanguageCode}\Applications\{PluginName}
```

#### Version-specific information

Use these values when creating registry paths:

| Civil 3D version | Release version | AutoCAD version code | Plugin name |
|---|---|---|---|
| 2022 | R24.1 | ACAD-5100 | Speckle.Connectors.Civil3d2022 |
| 2023 | R24.2 | ACAD-6100 | Speckle.Connectors.Civil3d2023 |
| 2024 | R24.3 | ACAD-7100 | Speckle.Connectors.Civil3d2024 |
| 2025 | R25.0 | ACAD-8100 | Speckle.Connectors.Civil3d2025 |
| 2026 | R25.1 | ACAD-9100 | Speckle.Connectors.Civil3d2026 |

#### Required registry values

For each registry path, create these values:

| Value name | Type | Value |
|---|---|---|
| **LOADER** | String (REG_SZ) | `%APPDATA%\Autodesk\ApplicationPlugins\Speckle.Connectors.Civil3d{VERSION}\Speckle.Connectors.Civil3d{VERSION}.dll` |
| **DESCRIPTION** | String (REG_SZ) | `Speckle for Civil3D v3` |
| **LOADCTRLS** | DWORD (REG_DWORD) | `2` (hexadecimal: `0x00000002`) |
| **MANAGED** | DWORD (REG_DWORD) | `1` (hexadecimal: `0x00000001`) |

**Example LOADER value for Civil 3D 2026:**

```
%APPDATA%\Autodesk\ApplicationPlugins\Speckle.Connectors.Civil3d2026\Speckle.Connectors.Civil3d2026.dll
```

## Uninstall the connector

1. Delete the `Speckle.Connectors.Civil3d{VERSION}` folder from `%AppData%\Autodesk\ApplicationPlugins\`
2. Remove all Speckle-related registry entries you created during installation

To remove all Speckle products, delete the `%AppData%\Speckle\` folder.
