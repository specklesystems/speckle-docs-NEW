<Info>  
  Repeat these steps for each version of Blender you want to use with Speckle.
</Info>

Before you begin, make sure Speckle Desktop Services is running in the background. All Speckle connectors require this service to function properly. [Learn more about Desktop Services](/connectors/manual-installation/desktop-services).

## Install for a single user

1. Extract the downloaded zip file and locate the `bpy_speckle` folder inside
2. Copy the `bpy_speckle` folder
3. Navigate to `%AppData%\Blender Foundation\Blender\{VERSION}\scripts\addons\`
   - Replace `{VERSION}` with your Blender version (for example, `4.5`)
   - Create the directory structure if it doesn't exist
4. Paste the `bpy_speckle` folder into the `addons` directory

## Install for all users

Follow the same steps as the single user install, but use this location instead:

`%ProgramFiles%\Blender Foundation\Blender\{VERSION}\scripts\addons\`

## Uninstall the connector

To remove the Blender connector, delete the `bpy_speckle` folder from the location where you installed it.

To completely remove all Speckle products from your system, you may also need to delete the `%AppData%\Speckle\` folder.
