</Warning>

<Info>
  **Install separately for each version**: Repeat these steps for each application version you want to use with Speckle.
</Info>

All current Speckle Connectors require the Speckle Desktop Services background service. [Learn more about Desktop Services](/connectors/manual-installation/desktop-services).

## Install for a single user

1. Extract the downloaded ZIP file.
2. Copy all contents from `.\speckle_connector_3\` to `%AppData%\SketchUp\SketchUp {VERSION}\SketchUp\Plugins\speckle_connector_3\`
   - Replace `{VERSION}` with your SketchUp version (example: `2025`)
   - Create the directory if it doesn't exist
3. Copy `speckle_connector_3.rb` from `.\` to `%AppData%\SketchUp\SketchUp {VERSION}\SketchUp\Plugins\`

## Install for all users

Use `%ProgramData%` instead of `%AppData%` in all file paths above.

## Uninstall the connector

Delete the `speckle_connector_3` folder and the `speckle_connector_3.rb` file from your installation location.

To remove all Speckle products, delete the `%AppData%\Speckle\` folder.
