<Info>
  **Install for each Revit version separately**: Repeat these steps for each version of Revit you want to use with Speckle. For example, if you have both Revit 2025 and 2026 installed, complete the installation process for each version. Create the directory structure if it doesn't exist.
</Info>

Before you begin, make sure Speckle Desktop Services is running in the background. All Speckle connectors require this service to function properly. [Learn more about Desktop Services](/connectors/manual-installation/desktop-services).

## Install for a single user

1. Extract the downloaded ZIP file
2. Copy all contents from `.\Speckle.Connectors.Revit{VERSION}\` to `%AppData%\Autodesk\Revit\Addins\{VERSION}\Speckle.Connectors.Revit{VERSION}\`
   - Replace `{VERSION}` with your Revit version (for example, `2026`)
   - Create the directory structure if it doesn't exist
3. Copy the `Speckle.Connectors.Revit{VERSION}.addin` file from `.\Speckle.Connectors.Revit{VERSION}\Plugin\` to `%AppData%\Autodesk\Revit\Addins\{VERSION}\`

## Install for all users

Follow the same steps as the single user install, but use `%ProgramData%` instead of `%AppData%` in all file paths.

## Uninstall the connector

To remove the Revit connector, delete the `Speckle.Connectors.Revit{VERSION}` folder and the `.addin` file from the location where you installed them.

To completely remove all Speckle products from your system, you may also need to delete the `%AppData%\Speckle\` folder.
