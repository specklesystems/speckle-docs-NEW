  **This guide is for IT administrators only.** If you are a regular user, see our [Revit installation guide](/connectors/revit) instead.
</Warning>

<Info>
  **Install separately for each version**: Repeat these steps for each application version you want to use with Speckle.
</Info>

Connector versions < 3.17.2 require the Speckle Desktop Services background service. [Learn more about Desktop Services](/connectors/manual-installation/desktop-services).
For versions ≥ 3.17.2; the desktop service is not required.

## Install for a single user

1. Extract the downloaded ZIP file.
2. Copy all contents from `.\Speckle.Connectors.Revit{VERSION}\` to `%AppData%\Autodesk\Revit\Addins\{VERSION}\Speckle.Connectors.Revit{VERSION}\`
   - Replace `{VERSION}` with your Revit version (example: `2026`)
   - Create the directory if it doesn't exist
3. Copy `Speckle.Connectors.Revit{VERSION}.addin` from `.\Speckle.Connectors.Revit{VERSION}\Plugin\` to `%AppData%\Autodesk\Revit\Addins\{VERSION}\`

## Install for all users

Use `%ProgramData%` instead of `%AppData%` in all file paths above.

<DisableUpdateNotifications />

## Uninstall the connector

Delete the `Speckle.Connectors.Revit{VERSION}` folder and the `.addin` file from your installation location.

To remove all Speckle products, also delete the `%AppData%\Speckle\` folder.
