<Warning>

**This guide is for IT administrators only.** If you are a user, see our [standard connector installation guide](/connectors/installation) instead.

Use manual ZIP installation only when you can't deploy executable installers. We recommend using the standard .exe installers whenever possible—they provide automatic dependency management and a more reliable installation experience.

</Warning>

## Download Connector ZIP Files

Download connector ZIP files from <a href="https://releases.speckle.systems/" rel="nofollow">releases.speckle.systems</a>. Select the connector and version you need for your deployment.
