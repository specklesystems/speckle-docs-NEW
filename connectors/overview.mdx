## Ways to get data into Speckle

- **Connectors** - Plugins inside your design tools for publishing and loading model data
- **Cloud integrations** - Automatic sync from platforms like Autodesk Forma Data Management and Bentley ProjectWise
- **File uploads** - Direct uploads when a connector is not available

Only connectors support loading data back into your design tools.

## Connectors

Connectors integrate directly with design tools like Revit, Rhino, Blender, and Grasshopper. Choose which objects and properties to publish for your workflow. Loading data preserves design intent where possible, not just geometry.

<Note>
  In 2026.9, new publishes use a new data format. Publish and load stay the same. See [Connectors in
  2026.9](/next/connectors/overview).
</Note>

### What you can do

- Publish selected objects or filter by category
- Load models from other tools as reference geometry
- Track changes and sync only updated objects between versions
- Manage projects, models, and versions without leaving your application
- Access settings for detail level, reference points, and geometry optimization
- Build custom workflows in Grasshopper and Blender

<Note>Need a connector we don't have? [Request it on our forum](https://speckle.community/)</Note>

## Cloud integrations

Cloud integrations connect Speckle directly to another data service. ProjectWise can connect through Bentley Cloud or a supported on-premises WSG server.

### What you can do

- Sync models automatically when source files change
- Access data without installing plugins or desktop software
- Keep teams up to date with continuous synchronization

### Available integrations

- **[Autodesk Forma Data Management (ACC)](/connectors/cloud-integrations/acc)** — Sync Revit files from Autodesk cloud projects (still often called ACC)
- **[Bentley ProjectWise](/connectors/cloud-integrations/projectwise)** — Sync supported files from Bentley Cloud or an on-premises WSG server

<Note>
  Forma Data Management and ProjectWise integrations are available on **Team** and **Enterprise**
  plans. See each integration guide for setup details.
</Note>

## File uploads

Upload files directly when a connector is not available or you do not have access to the source software.

### Supported formats

<Warning>
  **2026.9 changes upload format support.** STL and several other formats below are no longer
  accepted by the default upload path. These formats remain supported for direct uploads in
  **legacy/compatibility mode**. See [2026.9 upload format changes and compatibility
  options](/next/connectors/file-uploads#breaking-change-supported-file-formats).
</Warning>

The following list describes upload support before 2026.9:

- **IFC** (IFC2x3, IFC4)
- **BIM**: RVT (Revit), NWC and NWD (Navisworks)
- **CAD**: DWG, DXF, DGN
- **3D modeling**: 3DM (Rhino), SKP (SketchUp), SLDPRT (SolidWorks)
- **Mesh**: 3MF, 3DS, AMF, OBJ, PLY, STL
- **Interchange**: E57, IGES, FBX, STEP

Open-source self-hosted servers support IFC uploads only. Extended formats are available on
[app.speckle.systems](https://app.speckle.systems).

<Note>
  Extended formats on a self-hosted deployment require Speckle Enterprise Server and a [license
  key](/developers/server/deployment/enterprise-license#license-key). See [File imports
  setup](/developers/server/deployment/enterprise-license#file-imports-conversion-runner).
</Note>

### How it works

Each file upload creates a new version of your model, preserving complete version history. Upload new versions from the model's dropdown menu.
