## Ways to get data into Speckle

- **Connectors** - Plugins inside your design tools for publishing and loading model data
- **Cloud integrations** - Automatic sync from platforms like Autodesk Forma Data Management, Bentley ProjectWise, and Trimble Connect
- **File uploads** - Direct uploads when a connector is not available

Only connectors support loading data back into your design tools.

## Connectors

Connectors integrate directly with design tools like Revit, Rhino, Blender, and Grasshopper. Choose which objects and properties to publish for your workflow. Loading data preserves design intent where possible, not just geometry.

### What you can do

- Publish selected objects or filter by category
- Load models from other tools as reference geometry
- Track changes and sync only updated objects between versions
- Manage projects, models, and versions without leaving your application
- Access settings for detail level, reference points, and geometry optimization
- Build custom workflows in Grasshopper and Blender

<Note>Need a connector we don't have? [Request it on our forum](https://speckle.community/)</Note>

## Update connectors for 2026.9

From 2026.9, connectors publish in a new data format. Your day-to-day work stays the same: you still
publish and load through your connectors, and view and share in the web app. Models you already
published stay readable, and publish, load, and view are faster in the new format.

The 2026.9 upgrade window is open until **1 November 2026**: update your connector before then. New
publishes from an updated connector use the 2026.9 format. If you manage connectors for an
organization, see [Upgrade window for 2026.9](/it-admin/connector-updates#upgrade-window-for-2026-9).

<Warning>
  A connector from 2026.8 or earlier cannot load a version published by a 2026.9 or newer connector.
  Update together with the people you share models with.
</Warning>

Some tools change more than the data format:

- [Revit](/connectors/revit/revit#model-placement): published geometry stays in Revit's internal
  coordinates, and consumers pick the datum.
- [Grasshopper](/connectors/grasshopper/grasshopper#upgrade-to-2026-9): new Load, Publish, and
  Explore nodes. Switch existing scripts to the new nodes.
- [Power BI](/connectors/power-bi/power-bi#upgrade-from-2026-8): load models with Get Tables and a new
  3D visual. Rebuild reports that use `GetByUrl`.
- [Navisworks](/connectors/navisworks): there is no 2026.9 connector. **2026.8** is the last one.
  Upload larger NWC and NWD files instead.
- [Vectorworks](#why-cant-i-load-a-model-into-vectorworks-anymore): the Vectorworks connector cannot
  load the 2026.9 data format yet.

A 2026.8 Navisworks publish uses the data format from before 2026.9. Speckle may convert it on the
server, but that is not guaranteed.

<Note>
  Compatibility mode applies to ACC sync and file uploads only. It does not change the data format
  published or loaded by desktop connectors. See [Compatibility mode](/it-admin/compatibility-mode)
  and [Speckle's new data model](/workspaces/data-model-migration).
</Note>

## Cloud integrations

Cloud integrations connect Speckle directly to another data service. ProjectWise can connect through Bentley Cloud or a supported on-premises WSG server.

### What you can do

- Sync models automatically when source files change
- Access data without installing plugins or desktop software
- Keep teams up to date with continuous synchronization

### Available integrations

- **[Autodesk Forma Data Management (ACC)](/connectors/cloud-integrations/acc)** — Sync Revit files from Autodesk cloud projects (still often called ACC)
- **[Bentley ProjectWise](/connectors/cloud-integrations/projectwise)** — Sync supported files from Bentley Cloud or an on-premises WSG server
- **[Trimble Connect](/connectors/cloud-integrations/trimble-connect)** (beta) — Sync models from Trimble Connect projects through a workspace service account

<Note>
  Forma Data Management, ProjectWise, and Trimble Connect integrations are available on the
  **Enterprise** plan. See each integration guide for setup details.
</Note>

## File uploads

Upload files directly when a connector is not available or you do not have access to the source software.

### Supported formats

The default upload path accepts IFC, Revit (RVT), Navisworks (NWC and NWD), AutoCAD (DWG),
MicroStation (DGN), Rhino (3DM), Wavefront (OBJ), SketchUp (SKP), STEP, Vectorworks (VWX), and
Solibri (SMC) files. Tekla Structures uploads are available where enabled. For the full list and
the formats only compatibility mode accepts, see [Supported file
formats](/connectors/direct-uploads/introduction#supported-file-formats).

Open-source self-hosted servers support IFC uploads only. Extended formats are available on
[app.speckle.systems](https://app.speckle.systems).

<Note>
  Extended formats on a self-hosted deployment require Speckle Enterprise Server and a [license
  key](/developers/server/deployment/enterprise-license#license-key). See [File imports
  setup](/developers/server/deployment/enterprise-license#file-imports-conversion-runner).
</Note>

### How it works

Each file upload creates a new version of your model, preserving complete version history. Upload new versions from the model's dropdown menu.

## FAQ

<div id="why-cant-i-load-a-model-into-vectorworks-anymore" />

<AccordionGroup>
  <Accordion title="Why can't I load a model into Vectorworks anymore?">
    The model was published from a connector that has already updated to 2026.9 — Revit, Archicad,
    or any other design tool once it updates. The Vectorworks connector cannot read that format yet.
    No connector from 2026.8 or earlier can load data published by a 2026.9 or newer connector, so
    this is not specific to Vectorworks. Vectorworks Inc. maintains the Vectorworks connector: ask
    [Vectorworks support](https://www.vectorworks.net/support) when it will read the 2026.9 format.
  </Accordion>
</AccordionGroup>
