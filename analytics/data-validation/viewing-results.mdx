## What you see on the page

Orienting terminology for screenshots:

- Rollups: project **Data Validation** widget cards and **Checks** list cards with score, hints, and tracked-model totals.
- Drill-down view: aggregate score, rule summaries, expandable `WHERE` → `CHECK` counts, per-model result tiles, latest-run caption, and history/object grids.

## Practical review flow

<Steps>
  <Step title="Open latest check result">
    Highest signal: score + worst rules first.
  </Step>
  <Step title="Drill into failing rules">
    Expand for logic counters; table fills so you inspect elements directly.
  </Step>
  <Step title="Compare with history">
    Separate regression noise from chronic debt versus resolved regressions.
  </Step>
  <Step title="Share and coordinate">
    On that result route, header **Export** / **Actions** → **BCF export** bundles topic
    meta, failing refs, Speckle validation context for downstream BCF tools.
  </Step>
</Steps>

## Result states

| Status    | Meaning                                                   |
| --------- | --------------------------------------------------------- |
| `PASS`    | Pass-rate ≥ configured pass threshold.                    |
| `WARN`    | Between warn/pass band when configured.                   |
| `FAIL`    | Below thresholds.                                         |
| `PENDING` | Evaluation still running in background for that rollup across models, versions, and rules. |

Threshold tuning: [Checks — Thresholds and status](/analytics/data-validation/checks#thresholds-and-status).

## If a result looks unexpected, check:

1. Same model/version you expected auditing?
2. Predicates/threshold edits since that baseline snapshot?
3. Failures clustered by stream or timeframe (data drift) vs sporadic flake?

## Model and version context

Plans cap how many models attach. Every row references explicit version ids plus trigger +
timestamp—carry that along when debating trends.

## Coordination handoff

BCF export from validation emits topic scaffolding plus failures so coordinators triage outside
Speckle.
