Project standards are being retired from Data Validation. The Data Validation sidebar shows **Run
check** and **Checks** only, so author and save checks instead. Reuse across the workspace is
planned later as a rollup from checks into workspace standards; that flow is not available yet.

<Warning>
  If your team spent time developing Project standards, email
  [hello@speckle.systems](mailto:hello@speckle.systems).
</Warning>

## What to use instead

| You used a standard to…                  | Do this now                                                                                                                                                                             |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Import IDS, COBie, or Speckle rules      | Select **Import IDS**, **Import COBie**, or **Import Speckle** on an empty check. See [Import rules](/analytics/data-validation/checks#import-rules-from-ids-cobie-or-speckle).         |
| Keep one set of rules for several checks | Build one check with many rules, and recreate it where the same standard applies. See [Build a check with many rules](/analytics/data-validation/checks#build-a-check-with-many-rules). |
| Run the same rules on every submission   | Save the check with **auto** trigger. See [Validate incoming models automatically](/workflows/validate-incoming-models-automatically).                                                  |

## FAQ

<AccordionGroup>
  <Accordion title="What happens to checks I created from a standard?">
    A check keeps the rules it was created with, so retiring standards does not change it. A check
    saved before your project moved to the 2026.9 data format may need rebuilding; see [Default
    scope](/analytics/data-validation/checks#default-scope).
  </Accordion>
</AccordionGroup>
