Every widget you can add from the widget panel loads models in the data format introduced in
2026.9. A few older widgets were retired or replaced. Dashboards that already contain one keep its
saved configuration, but the widget either shows a card in its place or is no longer offered for
new dashboards.

For building and sharing dashboards, see [Intelligence Dashboards](/analytics/intelligence-dashboards).

## Retired widgets

A saved instance of these widgets stays on the grid with its configuration, but shows a card
instead of data. Remove it, and use the replacement where one is named.

| Widget                                          | What the saved instance shows | Use instead                                                                                |
| ----------------------------------------------- | ----------------------------- | ------------------------------------------------------------------------------------------ |
| **Parameter Updater**                           | **Moved to the model viewer** | The **Elements** panel in the 3D viewer. See [Parameter Updater](/beta/parameter-updater). |
| **Material quantities over time** (Revit group) | A **Not migrated** card       | **Material quantities over time** in the **Time series** group.                            |
| Older **Time series** widgets                   | A **Not migrated** card       | The widget of the same purpose in the **Time series** group.                               |
| **Cost Estimation** (ETABS)                     | A **Not migrated** card       | No replacement.                                                                            |
| **Render Genie**                                | **No longer supported**       | No replacement.                                                                            |

## Replaced widgets

These widgets are no longer supported, and you cannot add new ones. Saved dashboards and their
data are kept; rebuild the view with the replacement.

- **Element table** and **Pivot table**: use **Elements table**. A saved Element table shows a
  banner offering to migrate it.
- **Model Validation**: use **Property checker**, the **Elements table**, or a [Data Validation
  check](/analytics/data-validation/overview).

## FAQ

<AccordionGroup>
  <Accordion title="Why does a widget on my dashboard show Not migrated?">
    It is a retired widget with no 2026.9 version. Its saved configuration stays, but it will not
    load data again. Remove it and add the replacement from the table above, if one is named.
  </Accordion>
  <Accordion title="Do I need compatibility mode for Dashboards?">
    No. Dashboards load models in the 2026.9 data format, including earlier versions of your models.
    [Compatibility mode](/it-admin/compatibility-mode) is only for ACC sync and drag-and-drop
    uploads that must keep writing the earlier format for another tool.
  </Accordion>
  <Accordion title="Where is the Context widget?">
    **Context**, which draws a model on a map, is experimental and is not in the widget panel for
    every workspace. It is not the same as marking a model as a [context
    model](/analytics/intelligence-dashboards#context-models) in the Model Viewer.
  </Accordion>
</AccordionGroup>
